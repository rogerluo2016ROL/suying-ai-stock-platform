## 选股逻辑

六条件 AND：

| # | 条件 | 参数 |
|---|------|------|
| 1 | MACD金叉 | DIF(12,26) 上穿 DEA(9) |
| 2 | OBV金叉 | OBV 上穿 MA30 |
| 3 | 强多头趋势 | MA20 > MA60, C > MA20, MA20/MA60 > 1.03 |
| 4 | 量能达标 | V > MA(V,5) 且 V > REF(V,1) |
| 5 | K线健康 | 收阳, 上影 < 5% |
| 6 | 非涨停 | 排除封板(买不到) |

## 交易规则

```
T日收盘确认信号 → T+1开盘等权买入 → T+2收盘卖出
止损: -3% (日内最低价触发)
```
