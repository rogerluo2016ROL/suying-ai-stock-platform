# 毕师傅趋势战法 v2.0 — 完整选股规则

> MACD+OBV 六条件共振 | 超短线(2天) | T+1 制度合规

---

## 一、选股条件（六条 AND，全部满足才入选）

### 条件 1: MACD 金叉

```
EMA12 = EMA(CLOSE, 12)        # 快线指数均线
EMA26 = EMA(CLOSE, 26)        # 慢线指数均线
DIF   = EMA12 - EMA26         # 差离值
DEA   = EMA(DIF, 9)           # 讯号线

规则: DIF[T] > DEA[T]  AND  DIF[T-1] <= DEA[T-1]
```

> 快线上穿慢线，确认短线动量由弱转强。排除 DIF 已在 DEA 上方多日的股票（不是新鲜金叉）。

### 条件 2: OBV 金叉

```
VA[T]  =  +VOL[T]  if C[T] > C[T-1]
         -VOL[T]  if C[T] < C[T-1]
           0      if C[T] = C[T-1]
OBV    = 累计求和(VA)           # 累积能量潮
MA30   = MA(OBV, 30)           # OBV 30日均线

规则: OBV[T] > MA30[T]  AND  OBV[T-1] <= MA30[T-1]
```

> 能量潮突破 30 日均线，确认增量资金流入。排除 OBV 已在均线上方运行的股票。

### 条件 3: 强多头趋势

```
MA20 = MA(CLOSE, 20)           # 20日均线
MA60 = MA(CLOSE, 60)           # 60日均线

规则:
  ① MA20 > MA60               # 中短期均线多头排列
  ② CLOSE > MA20              # 价格在 MA20 上方
  ③ MA20 / MA60 > 1.015       # 趋势坡度 ≥ 1.5%（排除横盘震荡）
```

> **关键优化**: 条件 ③ 排除 MA20 与 MA60 纠缠的横盘股，只选有明确趋势坡度的股票。PG 数据库历史较长（120 天），阈值设为 1.5%；Tushare 直接取数历史较短（88 天），阈值可设为 3%。

### 条件 4: 量能达标

```
MAV5 = MA(VOL, 5)              # 5日均量

规则:
  VOL[T] > MAV5[T]             # 当日量能超过5日均量
  VOL[T] > VOL[T-1]            # 量能递增（非缩量反弹）
```

> 放量确认信号有效性，排除无量空涨。

### 条件 5: K 线形态健康

```
规则:
  CLOSE > OPEN                 # 收阳线
  HIGH / CLOSE < 1.05          # 上影线 < 5%
```

> 收阳确认买方主导；上影线短说明上方抛压轻，没有冲高回落。

### 条件 6: 非涨停

```
科创板/创业板 (688/30开头): 涨幅 < 19.5%
主板:                       涨幅 < 9.5%

规则: 信号日涨幅 < 涨停线 - 0.5%
```

> 涨停封板无法以收盘价买入，直接剔除。次日开盘再买已错失最佳入场点。

## 二、前置过滤

### 股票池过滤

| 规则 | 原因 |
|------|------|
| 排除 ST / *ST | 风险警示股 |
| 排除 退市整理 | 流动性极差 |
| 排除 8/4/9 开头 | 北交所/退市板块，流动性差 |
| 至少 60 天历史数据 | 确保 MA60 有效 |

### 换手率过滤（仅当 PG 有数据时生效）

| 参数 | 值 | 原因 |
|------|-----|------|
| 最低换手 | 0.5% | 排除僵尸股（日成交极少） |
| 最高换手 | 30% | 排除异常放量（可能是对倒） |
| 数据缺失 | 自动放行 | PG `turnover_rate=0` 时跳过 |

## 三、综合评分（0-25 分）

五维度加权，满分 25 分：

| 维度 | 权重 | 满分 | 计算逻辑 |
|------|------|------|----------|
| **MACD 强度** | 20% | 5.0 | `min(5, max(0, DIF × 5 + 2.5))` |
| **趋势坡度** | 30% | 7.5 | `min(7.5, max(0, (slope-0.02) / 0.02 × 1.5))` |
| **量能强度** | 25% | 6.25 | `min(6.25, max(0, (vol_ratio-0.8) / 0.8 × 1.25))` |
| **OBV 强度** | 15% | 3.75 | `min(3.75, max(0, (obv_ratio-0.99) / 0.02 × 0.75))` |
| **蜡烛质量** | 10% | 2.5 | `max(0, 2.5 - shadow_pct / 0.02)` |

### 评级映射

| 评级 | 分数 | 含义 | 回测胜率 | 回测均价 |
|------|------|------|----------|----------|
| **S** | ≥20 | 强共振，高确定性 | 100% | +15.5% |

## 四、交易规则

```
T日 (信号日)    收盘后 ~15:30  确认信号 → 输出选股列表
T+1日 (买入日)   09:25 开盘    等权买入（多信号资金平分）
T+2日 (卖出日)   15:00 收盘    全部卖出

止损: T+1 和 T+2 任意时刻日内最低价触及止损线即卖出
```

### 止损计算（ATR 动态）

```
ATR = 14日平均真实波幅
ATR% = ATR / CLOSE × 100
止损% = max(3%, min(8%, ATR% × 1.5))

止损价 = 买入价 × (1 - 止损%)
目标价 = 买入价 × (1 + 止损% × 2)
```

> 高波动股自动放宽止损，低波动股用底线 3%。止损区间 [3%, 8%]。

### 仓位分配

```
同日 N 只信号 → 每只分配 1/N 资金
日收益率 = 各股收益率的算术平均
累积收益 = Π(1 + 日收益率)
```
