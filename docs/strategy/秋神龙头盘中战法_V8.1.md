## 一、策略概述

### 1.1 核心理念

**14:00 盘中选股，收盘前买入，次日套利。** 选"当天最强的板块里最强的股票"，在 14:00 确认行情持续性后入场，T+1 收盘卖出。

### 1.2 与毕师傅趋势战法的差异

| 维度 | 毕师傅趋势启动 | 秋神龙头盘中 |
|---|---|---|
| **时间窗口** | 收盘后选股，次日买入 | **14:00 盘中选，收盘前买入** |
| **数据源** | daily_kline（日K） | **stk_mins（5分钟K）** |
| **持有周期** | 3~15天 | **T+1 超短线（次日收盘卖）** |
| **核心逻辑** | 趋势回踩低吸 | **龙头接力追涨** |
| **关键因子** | OBV + WR + 缩量 | **分时引领 + 板块龙头 + 午后强势** |
| **板块识别** | stocks.industry | **THS 同花顺概念（优先）→ 行业 fallback** |

## 三、硬过滤规则（任一不通过直接淘汰）

### 3.1 股票池过滤

| # | 规则 | 说明 |
|---|---|---|
| F1 | `is_st=0` 且名称不含 `ST` | 排除风险警示股 |
| F2 | `float_mv >= 20`（万元） | 排除极端小盘仙股 |
| F3 | 代码不以 `8/9/4` 开头 | 排除北交所（30% 涨跌停不可控） |
| F4 | 不在 snapshot 中 | 当日无分钟线数据 |

### 3.2 分板涨幅过滤

| 板块 | 涨幅要求 | 涨停 | 涨停阻力区 |
|---|---|---|---|
| **主板** (60/00开头) | 6.0% ~ 9.5% | 10% | 7.0%~8.0% 淘汰（接近涨停但确定性差） |
| **科创板** (688) | ≥7.0% | 20% | — |
| **创业板** (300/301) | ≥7.0% | 20% | — |
| **北交所** (8/9/4) | — | 30% | 直接淘汰 |

### 3.3 距涨停距离过滤 (P16)

| 板块 | 涨停倍数 | 距涨停最小距离 |
|---|---|---|
| 主板 | pre_close × 1.10 | **< 1.5%** 淘汰 |
| 科创/创业板 | pre_close × 1.20 | **< 2.0%** 淘汰 |

> 逻辑：距离涨停太近 = 随时可能封板买不到，或封板后次日低开。

### 3.4 封板可买性过滤 (V5.7)

| 封板状态 | 判定 | 能否买入 |
|---|---|---|
| 封死涨停（开板0次 + 封单≥3亿） | 封死可排 | ❌ 淘汰（买不到） |
| 封板涨停（开板≤1次 + 封单≥1亿） | 封板可排 | ❌ 淘汰（排板困难） |
| 炸板回封（开板≤2次） | 炸板回封 | ✅ 可买入 |
| 多次炸板（开板>2次） | 多次炸板 | ✅ 可买入（质量差） |
| 未涨停 | 拉升中 | ✅ 可买入 |

### 3.5 午后 VWAP 趋势过滤 (P3)

```
计算: 上午均价 (VWAP_am) vs 14:00 现价
规则: 14:00 现价 < 上午均价 → 午后主力撤退 → ❌ 淘汰
```

### 4.2 F1: 板块龙头 (0-24分)

```python
同板块(THS概念)涨幅≥5%的同伴数:
  peer >= 5  → sl_score = 12  (24 → 12, V7.1 降权 50%)
  peer >= 3  → sl_score = 9
  peer >= 2  → sl_score = 6
  peer == 1  → sl_score = 3
  peer == 0  → sl_score = 0
```

**板块联动加分 (R1)**:
```python
peer >= 5  → +5 分  # 强板块联动：行情级别确认
peer >= 3  → +3 分  # 中等联动：有跟风效应
```

> V7.1 近 1 月回测 corr=-0.135，龙头分降权 50% 后提升胜率。

### 4.3 F2: 分时引领性 (0-22分)

**板块内涨幅排名加分**:
```python
总龙头(第1名 + peer≥3)     → leadership_bonus = +12  # 板块总龙头，最强辨识度
前排(第2-3名 + peer≥3)     → leadership_bonus = +6   # 板块前排
跟风(第>5名 + peer≥5)      → leadership_bonus = -3   # 后排，次日最先被淘汰
```

**零板块支撑惩罚 (R2)**:
```python
peer == 0  → independent_penalty = 10  # 中等惩罚（非淘汰）
peer == 1  → independent_penalty = 3   # 独苗轻罚
```

### 4.4 F3: 涨幅质量 (0-18分)

**主板** (6.0%~9.5%):
```
gain >= 9.0%   → 14 分
gain >= 8.5%   → 12 分
gain >= 8.0%   → 14 分  # 出涨停阻力区 → 高确定性
gain >= 6.5%   → 12 分
gain < 6.5%    → 10 分
```

**科创/创业板** (≥7.0%):
```
gain >= 14.0%  → 18 分
gain >= 12.0%  → 16 分
gain >= 10.0%  → 14 分
gain >= 8.5%   → 12 分
gain < 8.5%    → 10 分
```

**形态加分**:
```python
# 光头阳线（收盘在当日最高价附近）
(close - low) / (high - low) > 0.9  → +2 分
```

### 4.5 F4: 午后强势度 (0-12分)

```
午后回升力度 = 14:00 现价 vs 下午最低价的反弹幅度
最多 +10 分 (完整数据) 或 +12 分 (仅有午后数据)

计算逻辑：
  上午 VWAP 作为基准线
  14:00 现价高于上午 VWAP → 午后维持强势 → 高分
  14:00 现价低于上午 VWAP → 午后走弱 → 低分 → P3 过滤可能淘汰
```

### 4.6 F5: 板块高潮次日惩罚 P0 (0-12分)

```python
昨日板块涨幅检测 (THS 概念优先 → index_basic fallback):
  昨日板块涨幅 > 5%   → climax_penalty = 20  # 昨天疯狂，今天绝不追
  昨日板块涨幅 > 3%   → climax_penalty = 12  # 板块加速中
  昨日板块涨幅 2~3%   → climax_penalty = 6
  昨日板块涨幅 < 2%   → climax_penalty = 0   # 安全

板块日内过热检测 (P0b):
  peer >= 30          → overheat_penalty = 18  # 极度拥挤
  peer >= 20          → overheat_penalty = 10  # 板块过热
```

### 4.7 F6: 成交额 (0-10分)

```
预估全天成交额 = 14:00 累计金额 / 0.65

倒U型评分:
  10亿 ~ 50亿  → 10 分  # 甜蜜区
  50亿 ~ 80亿  → 7 分   # 偏大
  5亿 ~ 10亿   → 6 分   # 偏小但量比足
  80亿 ~ 150亿 → 4 分   # 大盘股
  ≥150亿       → 2 分   # 巨盘股
  ≥3亿 + 量比≥3 → 3 分  # 微盘爆发
  <3亿         → 淘汰   # 成交额太小
```

### 4.8 F7: 板块动量 (0-8分)

```python
板块当日涨幅 (THS 概念优先):
  sp > 3    → sm_score = 0   # 过热，次日大概率回调
  sp > 1    → sm_score = 2   # 偏热
  sp > 0    → sm_score = 5   # 温和
  sp > -2   → sm_score = 7   # 适度回调，次日反弹概率高
  sp <= -2  → sm_score = 8   # 深跌板块，次日反弹最强
```

> IC=+0.126，V4.1 权重从 10 升到 15，是最强单因子信号。

### 4.9 F8: 板块共振 (0-8分)

```python
板块涨 + 大盘涨 + 板块跑赢  → 0 分  # 双强=过热，次日回调
板块涨 + 大盘跌             → 5 分  # 板块逆市走强
板块跌 + 大盘跌 + 板块抗跌  → 8 分  # 最佳共振！
板块超跌 (< -1%)            → 8 分  # 超跌反弹
其他                        → 5 分
```

**共振信号强化 (O1)**:

### 4.10 F9: 集中放量 (0-7分)

```python
近5根 5 分钟K线的均量 / 上午均量:
```

### 4.11 F10: 均线趋势 (0-6分)

```python
MA5/MA10 排列 (来自 stk_factor_pro 或实时计算):
  MA5 > MA10 > MA20 + 收盘 > MA20  → 6 分  # 多头排列
```

## 七、市场环境自适应

### 7.1 涨跌比 → Top-N 调整

```python
breadth < 40%  → effective_n = max(5, top_n × 0.5)   # 弱市收缩
breadth < 55%  → effective_n = max(8, top_n × 0.7)   # 中性偏弱
breadth >= 55% → effective_n = top_n                   # 正常
```

### 7.2 涨跌比 → 个股加分 (O3)

```python
breadth < 30%  → 个股 +5 分  # 极弱市稀缺溢价(日均+1.12%)
breadth < 50%  → 个股 +3 分  # 弱市溢价(日均+0.86%)
breadth < 65%  → 个股 +0 分  # 中强市无溢价
breadth >= 65% → 个股 -2 分  # 强市信号稀释
```

### 7.3 市场狂热检测

```python
if 初筛通过数 > 120:
    全市场板块爆发 → 狂热日
    effective_n = max(5, effective_n × 0.5)  # 只留最强
```

### 7.4 假活跃熔断

```python
if 20 <= 初筛通过数 < 40:
    🛑 空仓！此后次日全面回调概率极高
```

### 7.5 共振均值择时 (O1)

```python
avg_resonance = mean(所有候选的 resonance_score)
if avg_resonance <= 5:  effective_n *= 0.5  # -50%
if avg_resonance <= 4:  effective_n *= 0.3  # -70%，几乎空仓
```

### 7.6 前日强→今日弱保护 (V8.1)

```python
if 前日涨跌比 > 65% and 今日涨跌比 < 50%:
    effective_n = max(3, effective_n × 0.5)  # 回撤保护
```

### 7.7 周内效应

```python
周一: effective_n = min(top_n, int(effective_n × 1.3))  # +30%
周五: effective_n = max(3, int(effective_n × 0.7))      # -30%
```
