# 产业链层级维度 ①：产业 → 重点方向

> 基于《求是》习近平《前瞻布局和发展未来产业》+ "十五五"规划 + 工信部 2026 年新兴支柱产业部署
>
> 作为 supply_chain_bom 的第一维度，每个产业链节点归属到一个「产业 → 重点方向」

---

## 维度总览：8 战略性新兴产业 + 6 未来产业

## 战新 vs 未来产业：投资逻辑差异

| 维度 | 战略性新兴产业（8） | 未来产业（6） |
|------|---------------------|---------------|
| **投资阶段** | 成长到成熟期 | 早期到概念期 |
| **选股逻辑** | 看订单、毛利率、市占率 | 看技术路线、专利、研发管线 |
| **估值方法** | PE / PEG / PS | 管线估值 / 期权定价 |
| **关键证据** | 量产公告、客户导入、毛利率改善 | 样机验证、政策支持、专利布局 |
| **风险点** | 产能过剩、价格内卷 | 技术路线失效、商业化时间不确定 |
| **政策信号** | 工信部"打造新兴支柱产业" | 《求是》"投早、投小、投长期、投硬科技" |
