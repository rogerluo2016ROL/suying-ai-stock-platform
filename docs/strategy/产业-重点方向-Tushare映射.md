# 产业链维度 ①：产业→重点方向

> 14 个政策产业 → `stocks.industry`（申万行业，主力） + `ths_index`（同花顺概念，补 5 个死角）
>
> 策略：行业能覆盖的用行业，行业没有的用概念。5 个未来赛道（低空经济、量子科技、脑机接口、6G、核聚变）无独立行业，从 ths_member 补入。

---

## SQL：混合筛选模板

```sql
-- 模板：行业为主，概念补筛 5 个死角
-- 参数: @industry_list (行业 IN), @ths_codes (概念 ts_code IN)

WITH
-- Step 1: 行业直筛（主力，13/14 产业）
industry_stocks AS (
    SELECT code, name, industry FROM stocks
    WHERE is_st = 0 AND industry IN ('半导体','元器件','IT设备','软件服务', ...)
),
-- Step 2: 概念补筛（仅 5 个未来赛道）
concept_stocks AS (
    SELECT DISTINCT m.con_code AS code, s.name, s.industry
    FROM ths_member m
    JOIN stocks s ON s.code = m.con_code AND s.is_st = 0
    WHERE m.ts_code IN ('885730.TI','886065.TI','886067.TI','886066.TI','885564.TI',
                        '886047.TI','886037.TI','886078.TI','885574.TI')
)
-- 合并去重
SELECT * FROM industry_stocks
UNION
SELECT * FROM concept_stocks;
```

### 分产业 SQL

**F3. 低空经济**（最典型的混合查询）：
```sql
-- 行业：航空 (53 只，含大飞机/航发/中无人机等)
-- 概念补：低空经济 + 无人机 + eVTOL (共 ~550 只唯一标的)
SELECT DISTINCT s.code, s.name, s.industry,
       CASE WHEN m886067.con_code IS NOT NULL THEN 1 ELSE 0 END AS in_low_alt,
       CASE WHEN m885564.con_code IS NOT NULL THEN 1 ELSE 0 END AS in_uav,
       CASE WHEN m886066.con_code IS NOT NULL THEN 1 ELSE 0 END AS in_evtol
FROM stocks s
LEFT JOIN ths_member m886067 ON m886067.con_code = s.code AND m886067.ts_code = '886067.TI'  -- 低空经济
LEFT JOIN ths_member m885564 ON m885564.con_code = s.code AND m885564.ts_code = '885564.TI'  -- 无人机
LEFT JOIN ths_member m886066 ON m886066.con_code = s.code AND m886066.ts_code = '886066.TI'  -- eVTOL
WHERE s.is_st = 0
  AND (s.industry = '航空'
       OR m886067.con_code IS NOT NULL
       OR m885564.con_code IS NOT NULL
       OR m886066.con_code IS NOT NULL)
ORDER BY in_low_alt DESC, in_uav DESC, code;
```
