# ChatBI 正式 UAT 问题集

**日期**: 2026-07-04  
**范围**: 独立移动端 ChatBI 后端接口级 UAT。  
**目标**: 用 30 条问题覆盖产业链、证据链、选股、选债、共振、无票诊断、数据质量和报告导出。  

## 验收口径

每条问题记录：

```text
问题
期望意图
回答模式
是否返回结构化数据
是否带数据日期或证据来源
是否出现编造
耗时
验收结论
```

判定说明：

```text
通过：返回真实工具数据、明确数据口径或证据来源，并且没有原始 JSON 噪声。
部分通过：意图识别正确，但工具能力仍是占位或降级。
不通过：接口错误、无回答、明显编造或错误暴露内部异常。
```

## 必须保留的边界

```text
真实 LLM API Key 未配置时，必须显示 unavailable 或降级说明，不能伪造大模型回答。
真实平台 OAuth 未接入时，企业平台登录只能验证 identity binding，不能宣称免登完成。
工具未接入的模型问题，必须说明工具能力限制，不能编造选股/选债结果。
```
