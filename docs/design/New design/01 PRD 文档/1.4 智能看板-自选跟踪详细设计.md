## 1. 页面定位

自选跟踪是"AI 智能看板"的第四个 Tab，与市场情绪/竞价意图/信号总览并列。

与其他功能的关系：

| 功能 | 与自选跟踪的关系 |
|---|---|
| ScreenerV2 | 选股结果 → 一键加入自选（打通"发现 → 跟踪"链路） |
| Diagnosis | 点击自选股票 → 跳转诊断页（"跟踪 → 分析"） |
| Signal Service | 获取自选股的信号级别（显示在列表中） |
| 风控中心 | 自选中的风险股（距止损/审计风险）在自选跟踪中高亮 |

**核心原则**：自选跟踪是"监控页"，不承担选股和分析职责。它的职责是让用户 3 秒内知道自己关注的东西今天怎么样了。

### 4.2 排序与风险排序

```typescript
// 主排序 + 风险优先（风险股永远在列表顶部可见）
function sortStocks(stocks: WatchlistStock[], sortBy: string): WatchlistStock[] {
  // 先按风险等级分组
  const danger = stocks.filter(s => s.riskLevel === 'danger')
  const warning = stocks.filter(s => s.riskLevel === 'warning')
  const normal = stocks.filter(s => s.riskLevel === 'normal')
  
  const sortFn = (a: WatchlistStock, b: WatchlistStock) => {
    switch (sortBy) {
      case 'change_pct': return Math.abs(b.changePct) - Math.abs(a.changePct)
      case 'signal':     return b.signal.score - a.signal.score
      case 'market_cap': return b.marketCap - a.marketCap
      default:           return 0
    }
  }
  
  return [
    ...danger.sort(sortFn),
    ...warning.sort(sortFn),
    ...normal.sort(sortFn),
  ]
}
```

## 5. 5日迷你走势（SVG 实现）

不使用 ECharts（避免自选 50 只时 50 个 ECharts 实例的性能问题），改用原生 SVG：

```typescript
function MiniSparkline({ data, width = 70, height = 22, changePct }: {
  data: number[]; width?: number; height?: number; changePct: number
}) {
  if (data.length < 2) return <div style={{ width, height }} />
  
  const min = Math.min(...data)
  const max = Math.max(...data)
  const range = max - min || 1
  const padding = 2
  
  const points = data.map((v, i) => {
    const x = padding + (i / (data.length - 1)) * (width - padding * 2)
    const y = height - padding - ((v - min) / range) * (height - padding * 2)
    return `${x},${y}`
  }).join(' ')
  
  const color = changePct >= 0 ? 'var(--up)' : 'var(--down)'
  const neutral = Math.abs(changePct) < 0.5 ? 'var(--muted)' : color
  
  return (
    <div style={{ width, height, flexShrink: 0 }}>
      <svg viewBox={`0 0 ${width} ${height}`} width={width} height={height}>
        <polyline points={points} fill="none" stroke={neutral} strokeWidth="1.5"
                  strokeLinecap="round" strokeLinejoin="round" />
      </svg>
    </div>
  )
}
```

**性能说明**：50 只自选 = 50 个 SVG 元素，轻量无压力。不需要 `react-window` 虚拟列表。

## 7. 后端实现要点

### 7.1 CRUD 端点

```python
# backend/app/routers/watchlist.py
# tenantId / ownerUserId 由后端从 JWT+会话解析注入（current_user 依赖），
# API 请求 schema 不显式传，前端禁止传 X-User-Role 等身份头；
# DB 层所有读写必须带租户过滤条件。

router = APIRouter(prefix="/api/v1/watchlist", tags=["watchlist"])

@router.get("")
async def list_watchlist(current_user = Depends(get_current_user_jwt)):
    """获取当前用户的自选股代码列表"""
    rows = await db.fetch_all(
        "SELECT code, added_at FROM watchlist "
        "WHERE tenant_id=$1 AND owner_user_id=$2 ORDER BY added_at DESC",
        current_user.tenant_id, current_user.user_id)
    return {"codes": [r["code"] for r in rows], "count": len(rows)}

@router.post("")
async def add_to_watchlist(codes: list[str], current_user = Depends(get_current_user_jwt)):
    """批量添加自选股"""
    added, skipped, errors = 0, 0, []
    for code in codes:
        # 校验 code 存在于 stocks 表
        exists = await db.fetch_val("SELECT 1 FROM stocks WHERE code=$1", code)
        if not exists:
            errors.append(f"{code}: 股票代码不存在")
            continue
        # 去重 (按租户+用户)
        dup = await db.fetch_val(
            "SELECT 1 FROM watchlist WHERE tenant_id=$1 AND owner_user_id=$2 AND code=$3",
            current_user.tenant_id, current_user.user_id, code)
        if dup:
            skipped += 1
            continue
        await db.execute(
            "INSERT INTO watchlist (tenant_id, owner_user_id, code) VALUES ($1, $2, $3)",
            current_user.tenant_id, current_user.user_id, code)
        added += 1
    return {"added": added, "skipped": skipped, "errors": errors}

@router.delete("")
async def remove_from_watchlist(code: str = Query(...), current_user = Depends(get_current_user_jwt)):
    """移除自选股"""
    result = await db.execute(
        "DELETE FROM watchlist WHERE tenant_id=$1 AND owner_user_id=$2 AND code=$3",
        current_user.tenant_id, current_user.user_id, code)
    return {"removed": result == "DELETE 1", "code": code}
```

### 7.2 聚合端点

```python
# backend/app/routers/watchlist.py

@router.get("/dashboard")
async def watchlist_dashboard(current_user = Depends(get_current_user_jwt)):
    """自选跟踪看板聚合 (行情+信号+板块+风险)"""
    
    # 1. 获取自选代码 (按租户+用户过滤)
    codes = [r["code"] for r in await db.fetch_all(
        "SELECT code FROM watchlist WHERE tenant_id=$1 AND owner_user_id=$2",
        current_user.tenant_id, current_user.user_id)]
    if not codes:
        return {"status": "ok", "stocks": [], "summary": {...}, ...}
    
    # 2. 批量取行情 (最新交易日 daily_kline)
    rows = await db.fetch_all("""
        SELECT d.code, s.name, d.close as price, d.change_pct, d.volume,
               s.market_cap, s.industry, s.is_st
        FROM daily_kline d
        JOIN stocks s ON d.code = s.code
        WHERE d.code = ANY($1)
          AND d.trade_date = (SELECT MAX(trade_date) FROM daily_kline)
    """, codes)
    
    # 3. 批量取信号 (调 signal-service, 一次 batch 请求)
    signals = await batch_signal_analyze(codes)  # 内部 POST /signal/batch
    
    # 4. 取5日收盘价 (迷你走势)
    sparklines = await db.fetch_all("""
        SELECT code, close FROM daily_kline
        WHERE code = ANY($1)
        ORDER BY code, trade_date DESC
        -- 取每组最近5条
    """, codes)
    
    # 5. 风险标签 (止损/审计)
    risk_tags = await compute_risk_tags(codes)
    
    # 6. 组装返回
    return assemble_dashboard_response(rows, signals, sparklines, risk_tags)
```

## 8. 交互规范

### 8.1 添加自选

| 方式 | 触发 | 行为 |
|---|---|---|
| 输入框添加 | 输入代码 + Enter/点击"添加" | 调 `POST /watchlist`，成功 toast "已添加"，失败 toast 错误，列表自动刷新 |
| 从选股导入 | 点击"从选股导入" | `navigate('/screener')`，ScreenerV2 中勾选后加入自选 |
| 批量添加 | 逗号分隔输入 "000001,600519" | 拆分为数组，逐条 POST |

### 8.2 移出自选

| 事件 | 行为 |
|---|---|
| 点击"✕" | `Modal.confirm("确认将 000001 移出自选？")` → 确认 → `DELETE /watchlist` |
| 移出后 | 行淡出动画(200ms) → 从列表移除 → KPI 卡片数字更新 |

### 8.3 排序交互

| 排序方式 | 行为 |
|---|---|
| 涨跌幅 | 按涨跌幅绝对值降序（大涨大跌幅在前） |
| 信号 | 按 `signal.score` 降序 |
| 市值 | 按 `market_cap` 降序 |

**风险优先**：无论选择哪种排序，有风险标签的股票（止损逼近/审计风险）始终排在列表顶部。

### 8.4 空态与错误态

| 状态 | 处理 |
|---|---|
| 无自选（空态） | `Empty description="暂无自选股"` + `Button "前往选股"` 跳转 Screener |
| 行情缺失（某只股票今日无行情） | 该行显示 "--"，不报错 |
| 信号缺失（某只股票无信号） | SignalTag 显示 "--"，不报错 |
| API 请求失败 | 对应卡片 Alert "加载失败 [重试]"，已有数据保留展示 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 智能看板：三角色首页：操盘手看交易机会，个人投资者看自选解释，管理员看平台健康。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共行情/信号 + 私有自选/提醒。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 券商状态只做摘要提示。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
