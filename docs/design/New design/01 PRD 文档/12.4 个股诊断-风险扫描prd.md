- **Date**: 2026-06-26 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `12.0 个股诊断prd.md`

## 1. 定位

风险扫描是 SubTab `risk-scan` 对应的面板。回答核心问题：**"这只股票有没有隐藏的风险？"**

聚焦四个关键检查维度：

| 检查项 | 核心问题 | 数据来源 |
|---|---|---|
| 审计意见 | 财报有没有问题？ | 年报/季报审计意见 |
| 公告风险 | 近期有没有利空？ | 交易所公告爬虫 |
| ST状态 | 有退市风险吗？ | 交易所 ST/*ST 列表 |
| 业绩预告 | 业绩有没有暴雷？ | 业绩预告/快报 |

四项全部通过 → 低风险；一项警告 → 中风险；两项及以上 → 高风险。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 四项检查全部通过？任何一项有问题？ | 这只股票财务安全吗？ |
| **可见内容** | 四项完整详情 + 综合风险评级 | 四项简化图标 + 整体评级 |
| **操作** | 跳转详情页面查看原始报告 | 仅查看 |

## 3. 风险评级

| 评级 | 条件 | 图标 | 颜色 |
|---|---|---|---|
| 低风险 | 4/4 通过 | ✅ | 绿 `--down` |
| 中风险 | 3/4 通过 | ⚠️ | 黄 `--warn` |
| 高风险 | ≤2/4 通过 | 🔴 | 红 `--up` |

## 4. 交互

- 每张检查卡片可折叠/展开详情
- 综合风险徽章固定底部，实时汇总
- 单项状态变化时综合评级联动更新
- 每个卡片 hover 高亮

## 5. AC

| ID | AC |
|---|---|
| AC-1 | 四张检查卡片正确渲染，状态图标与数据一致 |
| AC-2 | 综合风险评级计算正确 (4/3/≤2 通过 → 低/中/高) |
| AC-3 | 审计意见准确显示会计师事务所名称、意见类型、报告期间 |
| AC-4 | 公告检查覆盖近30日范围，计数准确 |
| AC-5 | ST 状态正确判断 ST/*ST/正常 |
| AC-6 | 业绩预告显示营收/净利变化，趋势图表正确 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
