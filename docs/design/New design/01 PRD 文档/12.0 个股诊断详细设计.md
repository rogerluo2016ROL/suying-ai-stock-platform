## 1. 页面定位

个股诊断是**所有页面的最终目标页**——从任意菜单点击股票代码，最终跳转到此页面进行五维深度诊断。

采用 **SubTabBar 多页签架构**，4 个子 Tab 各司其职：

```
🏥 个股诊断
│
├── [SubTabBar: 📊综合诊断 | 🔬模型视角 | 📋多股对比 | ⚠️风险扫描]
│
├── 📊 综合诊断     12.1  五维雷达图+评分+关键价位+风险。默认视图
├── 🔬 模型视角     12.2  切换不同模型，看同一只股票在各模型下的K线+指标
├── 📋 多股对比     12.3  2-3只股票横向雷达图对比
└── ⚠️ 风险扫描     12.4  审计/公告/ST/业绩 四项检查
```

### 1.1 来源上下文自动切换

根据 URL 参数 `source` 自动切换到对应模型视角：

```
来源: 毕师傅趋势V13 → 默认展示"毕师傅视角"（OBV/WR/量比/强动态）
来源: 龙头战法V4.3 → 默认展示"龙头视角"（高开%/封单/竞量比/Z-score）
来源: 候选池(融合) → 默认展示"综合视角"（五维评分）
来源: 自选跟踪   → 默认展示"综合视角"
```

### 1.2 五维评分权重

| 维度 | 权重 | 说明 | 数据来源 |
|---|---|---|---|
| 技术面 | 40% | K线形态、均线系统、MACD/RSI/KDJ、量价关系 | screener-service |
| 资金面 | 25% | 主力资金流向、北向资金、融资融券、大单动向 | signal-service |
| 基本面 | 20% | PE/PB/ROE、营收增速、净利润增速、毛利率 | screener-service |
| AI预测 | 10% | Kronos 30日K线预测准确率、趋势方向、置信度 | prediction-service |
| 情绪面 | 5% | 新闻舆情、社交媒体情绪、分析师评级变化 | diagnosis-service |

## 3. 核心数据结构

```typescript
// ===== SubTab 枚举 =====
type DiagnosisTab = 'overview' | 'model-perspective' | 'compare' | 'risk-scan'

// ===== 页面状态 =====
interface DiagnosisPageState {
  activeTab: DiagnosisTab
  currentStock: string                // ts_code
  sourceContext: SourceInfo | null    // URL 来源上下文
  currentModel: ModelId               // 当前模型视角
  
  // 综合诊断
  diagnosis: DiagnosisResult | null
  
  // 模型视角
  modelPerspective: ModelPerspective | null
  
  // 多股对比
  compareStocks: string[]             // 2-3 codes
  compareResults: CompareResult[]
  
  // 风险扫描
  riskResult: RiskResult | null
  
  loading: boolean
  error: string | null
}

// ===== 来源上下文 (面包屑) =====
interface SourceInfo {
  page: string                       // "候选池"
  tsCode: string                     // "300750.SZ"
  stockName: string                  // "宁德时代"
  modelSource?: string               // "bishifu" | "longtou" | ...
}

// ===== 模型 ID =====
type ModelId = 'composite' | 'bishifu' | 'longtou' | 'feiye' | 'changxian' | 'kabozi'

// ===== 综合诊断结果 =====
interface DiagnosisResult {
  tsCode: string
  stockName: string
  overallScore: number               // 0-100
  overallRating: DiagnosisRating
  currentPrice: number
  dimensions: DimensionScore[]
  keyLevels: KeyLevels
  riskWarnings: RiskWarning[]
  aiPrediction: {
    direction: 'up' | 'down' | 'flat'
    changePct: number                // +12.5
    confidence: number               // 72
  }
  auditOpinion: string
  generatedAt: string
}

type DiagnosisRating = 'excellent' | 'good' | 'fair' | 'poor'

const RATING_MAP: Record<DiagnosisRating, { label: string; color: string; suggestion: string }> = {
  excellent: { label: '优秀', color: 'var(--down)', suggestion: '强烈推荐' },
  good:      { label: '良好', color: 'var(--accent)', suggestion: '建议关注' },
  fair:      { label: '一般', color: 'var(--warn)', suggestion: '谨慎参与' },
  poor:      { label: '较差', color: 'var(--up)', suggestion: '建议回避' }
}

interface DimensionScore {
  name: string                       // "技术面"
  key: string                        // "technical"
  weight: number                     // 0.40
  score: number                      // 0-100
  subItems: SubItem[]
}

interface SubItem {
  label: string                      // "均线多头"
  status: 'positive' | 'neutral' | 'negative'
  value?: string
}

interface KeyLevels {
  resistance: number                 // 251.00
  resistanceLabel: string            // "短线阻力"
  support: number                    // 196.50
  supportLabel: string               // "强支撑"
  stopLoss: number                   // 185.00
  stopLossLabel: string              // "强制止损"
  currentPrice: number               // 218.50
}

interface RiskWarning {
  level: 'high' | 'medium' | 'low' | 'info'
  icon: string
  message: string
  detail?: string
}

// ===== 模型视角 =====
interface ModelPerspective {
  modelId: ModelId
  modelName: string                  // "毕师傅趋势启动V13"
  stockInfo: { tsCode: string; stockName: string }
  rating: string                     // "S" | "A" | "B" | "C"
  chartData: ModelChartData          // 3-panel ECharts 数据
  indicators: ModelIndicator[]
  commentary: string                 // LLM 生成点评
}

interface ModelChartData {
  dates: string[]
  candles: number[][]                // [open, close, low, high][]
  maLines: Record<string, (number | null)[]>
  panel1: any                        // 指标面板1数据
  panel2: any                        // 指标面板2数据
}

interface ModelIndicator {
  name: string                       // "OBV趋势"
  value: string | number             // "82" | "12.5x"
  status: 'ok' | 'warn' | 'danger'
  statusText: string                 // "✅ 突破"
}

// ===== 多股对比 =====
interface CompareResult {
  stock: { tsCode: string; stockName: string }
  diagnosis: DiagnosisResult
}

interface CompareConclusion {
  text: string                       // LLM 生成对比结论
  winner?: string                    // 综合优胜股票
  advantageMap: Record<string, string[]> // 各维度优势股
}

// ===== 风险扫描 =====
interface RiskResult {
  tsCode: string
  stockName: string
  
  audit: {
    passed: boolean
    opinion: string                  // "标准无保留"
    auditor: string                  // "安永华明"
    reportPeriod: string             // "2025年报"
    icon: string                     // "✅" | "⚠️" | "🔴"
  }
  
  announcement: {
    passed: boolean
    hasRisk: boolean
    riskCount: number
    recentDays: number               // 30
    icon: string
    detail?: string
  }
  
  stStatus: {
    passed: boolean
    isST: boolean
    statusText: string               // "正常上市"
    icon: string
    detail?: string
  }
  
  performance: {
    passed: boolean
    trend: 'pre_increase' | 'pre_decrease' | 'loss' | 'uncertain'
    icon: string                     // "🟢" | "🟡" | "🔴"
    detail: string                   // "2026Q1 营收+38.5% · 预增"
  }
  
  overallRisk: {
    level: 'low' | 'medium' | 'high'
    passedCount: number              // 4
    label: string                    // "四项全通过"
    icon: string                     // "✅" | "⚠️" | "🔴"
  }
}
```

```
┌──────────────────────────────────────────────────────────────┐
│                       个股诊断数据流                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  入口方式1: URL直接跳转                                       │
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
