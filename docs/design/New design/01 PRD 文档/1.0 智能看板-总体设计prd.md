# PRD — 智能看板·总体设计

- **Date**: 2026-06-26 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

智能看板是**日常总览入口**。用户打开平台后的第一屏，2 个 Tab：

| Tab | 定位 | 操盘手 | 个人投资者 |
|---|---|---|---|
| 🌡️ 市场情绪 | 全局背景 | 看八维分解→判断今天进攻/防御 | 看一句话操作建议→决定要不要交易 |
| ⭐ 自选跟踪 | 个性化监控 | 看自选池整体表现+板块分布 | 看我的股票涨了没 |

## 2. 已迁出内容

| 原 Tab | 迁入 | 原因 |
|---|---|---|
| 📋 竞价意图 (1.2) | 开盘决策·竞价分析 (2.2) | 竞价分析需要可操作（选股/选债/锁定板块），不是只读浏览 |
| ⚡ 信号总览 (1.3) | 开盘决策·信号扫描 (2.3) | 信号扫描需要可操作（确认/降级/排除），不是只读浏览 |
| ◎ 运行状态 (1.5) | 模型/系统管理·运行状态 (menu 16) | 系统监控，不是行情数据 |

## 3. 数据来源

| Tab | 端点 | 刷新 |
|---|---|---|
| 市场情绪 | `GET /signal/sentiment-index` | 60s |
| 自选跟踪 | `GET /watchlist/dashboard` | 60s |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 智能看板：三角色首页：操盘手看交易机会，个人投资者看自选解释，管理员看平台健康。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共行情/信号 + 私有自选/提醒。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 券商状态只做摘要提示。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
