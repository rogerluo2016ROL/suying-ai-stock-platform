# 详细设计 — K线预测·单股预测

> **关联 PRD**: `5.1 K线预测-单股预测prd.md` | **Date**: 2026-06-27

## 1. 组件树

```
SingleStockView
├── QuickSelectBar (常驻: 自选Chip/候选池Chip/最近Chip/搜索框)
├── ChartPanel (ECharts candlestick, 60%宽度)
│   ├── CandlestickSeries (60日历史K线, 红涨绿跌)
│   ├── PredictionSeries (30日预测, 虚线+浅色)
│   ├── ConfidenceBand (置信区间±1σ, areaStyle浅色带)
│   ├── KeyLevels (markLine: 阻力红/支撑绿/止损橙)
│   └── SignalMarkers (markPoint: ★买入/▼卖出/⚡拐点)
└── DetailPanel (右侧40%)
    ├── PredictionSummary (目标价/涨幅/置信度/信号一致性Badge)
    ├── FactorContribution (4进度条: 技术/资金/基本面/情绪)
    ├── ModelInfo (折叠: Kronos版本/训练日期)
    ├── HistoricalAccuracy (折叠: 近30次72%)
    └── ActionButtons ([设预警] [跳转诊断] [跳转交易])
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | K线预测：公共 Kronos 预测能力与用户私有关注/对比任务分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共预测快照 + 私有预测任务。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 预测不可绕过风控直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
