# PRD — 产业链拆解·产业链解构

- **Date**: 2026-06-27 | **Status**: Draft

## 1. 设计问题

当前 ECharts 树图方案的问题：

| 问题 | 表现 |
|---|---|
| 节点信息少 | 纯文字节点，看不出公司规模/卡脖子级别/财务概况 |
| 展开不直观 | 左到右展开 + ECharts 默认折叠，操盘手找不到想看的环节 |
| 交互弱 | 点击节点只是高亮，没有上下文信息 |

## 2. 参考方案：股权结构图式卡片树

参考 Figma 股权结构图的设计模式：

```
                        半导体设备
                    ┌──────┼──────┐
                原材料    零部件    设备
                ┌─┴─┐   ┌─┴─┐   ┌─┴─┐
              ┌──┐ ┌──┐┌──┐┌──┐┌──┐┌──┐
              │硅│ │光││光││物││刻││PV│
              │片│ │刻││源││镜││蚀││D │
              │  │ │胶││  ││  ││机││  │
              └──┘ └──┘└──┘└──┘└──┘└──┘
              沪硅  南大 ASML 蔡司 中微 北方
                              (卡)    华创
```

**核心改进**：每个末端节点是**公司卡片**，不是文字。卡片含：代码/名称/市值/卡脖子级别/毛利率。

### 交互规则

| 操作 | 效果 |
|---|---|
| 点击**环节卡片** | 展开/折叠该环节的子节点 |
| 点击**公司卡片** | 右侧面板展示公司详情：财务/竞争地位/关联公司 |
| 悬停公司卡片 | 浮层显示更多指标 |
| 双击公司卡片 | 跳转个股诊断 |
| 筛选 [仅看卡脖子] | 非卡脖子环节半透明, 卡脖子公司高亮 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 产业链拆解：公共产业链图谱与用户私有研究笔记分离，证据型标的进入候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共图谱/政策 + 私有研究标注。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接交易，只输出 Candidate 证据。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
