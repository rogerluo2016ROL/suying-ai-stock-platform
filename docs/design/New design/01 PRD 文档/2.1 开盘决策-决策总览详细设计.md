## 1. 页面定位

决策总览是开盘决策的**首页 Tab**，操盘手 9:00 打开平台后的第一屏。它的作用是回答一个根本问题：**"今天能不能做？做什么方向？"**。

| 顺序 | 问题 | 对应面板 | 数据来源 |
|---|---|---|---|
| Q1 | 昨晚发生了什么？ | 隔夜新闻速览 | `stock_news` / `announcements` / `cctv_news` |
| Q2 | 昨天市场怎么样？ | 昨日复盘 | `daily_kline(t-1)` / `stk_limit(t-1)` |
| Q3 | 候选池准备好了吗？ | 候选池预加载 | `screening_snapshots` / `watchlist` |
| Q4 | 今天能不能做？ | 情绪+风控 KPI | `market_regime_v2` / `circuit_breaker` |
| Q5 | 做什么方向？ | 板块热度预告 | 昨日强势板块 + 竞价倒计时 |

与竞价分析的区别：

| 维度 | 决策总览 | 竞价分析 |
|---|---|---|
| **回答的问题** | 今天能不能做？做什么方向？ | 哪只股票在竞价中被抢筹？ |
| **核心指标** | 情绪指数 + 熔断器状态 + 新闻风险 | 抢筹力度 + 竞价量比 + 四维评分 |
| **时间维度** | T-1 复盘 + T 日盘前 | 实时竞价数据 (09:25) |
| **操作导向** | 择时 + 仓位 + 风险排除 | 选股 → 候选池 |
| **用户场景** | 9:00 开屏第一眼 | 9:25 竞价数据到达后 |

### 4.2 隔夜新闻

```typescript
interface OvernightNews {
  announcements: Announcement[]     // 重大公告
  overseas: OverseasMarket           // 外盘表现
  hotKeywords: string[]              // 舆情热词
  cctvSummary: string               // 新闻联播摘要(最近一期)
  updatedAt: string
}

interface Announcement {
  id: string
  tsCode: string                    // 关联股票代码
  name: string                      // 股票名称
  title: string                     // 公告标题
  summary: string                   // 摘要(100字)
  category: AnnouncementCategory   // 公告类型
  riskLevel: 'high' | 'medium' | 'low' | 'positive'
  publishDate: string               // 发布日期
  source: 'sse' | 'szse' | 'cninfo' | 'other'
}

type AnnouncementCategory =
  | 'investigation'      // 立案调查
  | 'performance'        // 业绩预告/快报
  | 'st_risk'            // ST/退市风险
  | 'major_asset'        // 重大资产重组
  | 'shareholder'        // 股东增减持
  | 'dividend'           // 分红送转
  | 'lawsuit'            // 重大诉讼
  | 'regulatory'         // 监管措施
  | 'other'              // 其他

interface OverseasMarket {
  // 美股
  usDow: IndexSnapshot          // 道指
  usNasdaq: IndexSnapshot       // 纳指
  usSP500: IndexSnapshot        // 标普500
  // 期货
  a50Futures: IndexSnapshot     // A50 期货
  hsiFutures?: IndexSnapshot    // 恒指期货(可选)
  // 商品
  gold?: IndexSnapshot
  oil?: IndexSnapshot
  // 汇率
  usdCny?: number
  updatedAt: string
}

interface IndexSnapshot {
  value: number                  // 最新价
  changePct: number              // 涨跌幅 %
  changeDirection: 'up' | 'down' | 'flat'
}
```

### 4.5 情绪+风控 KPI

```typescript
interface SentimentKPI {
  sentimentIndex: SentimentIndexSummary
  circuitBreaker: CircuitBreakerStatus
  dataStatus: DataStatus
  operationHint: OperationHint
  updatedAt: string
}

interface SentimentIndexSummary {
  score: number                  // 0-100
  level: SentimentLevel
  label: string                  // "极牛" | "偏牛" | "中性" | "偏熊" | "极熊"
  change: number                 // 较前日变化
  changeDirection: 'up' | 'down' | 'flat'
  topDimensions: DimensionHighlight[]  // 影响最大的前3维
}

type SentimentLevel = 'BULL' | 'NEUTRAL_BULL' | 'NEUTRAL' | 'NEUTRAL_BEAR' | 'BEAR' | 'BLACK_SWAN'

interface DimensionHighlight {
  name: string                   // 维度名
  score: number                  // 0-100
  weight: number                 // 权重
  contribution: number           // 贡献度
}

interface CircuitBreakerStatus {
  isTriggered: boolean           // 是否触发
  triggeredReasons: string[]     // 触发原因
  dailyLossBudget: number        // 日亏损预算总额
  dailyLossBudgetRemaining: number // 剩余亏损预算
  dailyLossBudgetPct: number     // 剩余百分比
  perOrderLossLimit: number      // 单笔亏损上限
}

interface DataStatus {
  dailyKline: DataItemStatus
  minuteKline: DataItemStatus
  auctionData: DataItemStatus
  newsData: DataItemStatus
  screenerData: DataItemStatus
}

interface DataItemStatus {
  label: string                  // 显示标签
  available: boolean             // 是否可用
  lastUpdate?: string            // 最后更新时间
  coverage?: string              // 覆盖范围描述
}
```

### 6.1 CountdownBanner — 竞价倒计时

```
功能:
├── 盘前时段显示倒计时到 09:25:00
├── 每秒更新一次 (setInterval 1s)
├── 到达 09:25 时自动隐藏
└── 自动切换开关: 竞价开始后自动 navigate 到竞价分析 Tab
```

```typescript
// hooks/useCountdown.ts
function useCountdown(targetTimeStr: string = '09:25'): CountdownState {
  const [state, setState] = useState<CountdownState>({
    targetTime: targetTimeStr,
    remainingSeconds: 0,
    isExpired: false,
    progress: 0
  })

  useEffect(() => {
    const calculate = () => {
      const now = new Date()
      const [h, m] = targetTimeStr.split(':').map(Number)
      const target = new Date(now)
      target.setHours(h, m, 0, 0)

      const diff = Math.max(0, Math.floor((target.getTime() - now.getTime()) / 1000))
      const totalSeconds = h * 3600 + m * 60 // 从 00:00 算起

      setState({
        targetTime: targetTimeStr,
        remainingSeconds: diff,
        isExpired: diff <= 0,
        progress: diff <= 0 ? 1 : 1 - diff / totalSeconds
      })
    }

    calculate()
    const timer = setInterval(calculate, 1000)
    return () => clearInterval(timer)
  }, [targetTimeStr])

  return state
}
```

**关键状态**:
- 倒计时文本格式: `"距竞价数据采集还有 12:45"` (MM:SS)
- 倒计时 < 5 分钟时: 文字变为 `var(--warn)` 橙色，加闪烁动画
- 倒计时归零: 隐藏组件，可选触发 `autoSwitchAuction`

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 开盘决策：操盘手默认入口，输出私有 Candidate 与 DecisionContext。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共竞价/行情 + 私有候选池。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 实盘前必须进入方案与风控。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
