## 2. 模型详情卡注册系统

```typescript
// model-detail-cards/registry.ts

interface ModelDetailCardConfig {
  modelKey: string
  component: React.FC<{ stock: ScreenerPick }>
  title: string
  indicatorGroups: IndicatorGroup[]
  evaluationTemplate: (stock: ScreenerPick) => string
}

interface IndicatorGroup {
  name: string                    // "技术指标" / "竞价指标" / "财务指标"
  indicators: Indicator[]
}

interface Indicator {
  key: string                     // "obv_trend" / "wr_value" / "volume_ratio"
  label: string                   // "OBV趋势强度" / "WR超卖程度"
  value: (stock: ScreenerPick) => number
  max: number                     // 进度条最大值
  unit?: string                   // "%" / "x" / "亿"
}

const registry = new Map<string, ModelDetailCardConfig>()

// 注册示例
registry.set('bi_trend_launch', {
  modelKey: 'bi_trend_launch',
  component: BiTrendDetailCard,
  title: '毕师傅趋势启动分析',
  indicatorGroups: [
    {
      name: '技术指标',
      indicators: [
        { key: 'obv_trend', label: 'OBV趋势强度', value: s => s.factors?.obv_trend, max: 100 },
        { key: 'wr_oversold', label: 'WR超卖程度', value: s => s.factors?.wr_oversold, max: 100 },
        { key: 'vol_ratio', label: '量比(20日)', value: s => s.factors?.vol_ratio, max: 40, unit: 'x' },
      ]
    },
    {
      name: '质量信号',
      indicators: [
        { key: 'strong_dynamic', label: '强动态分', value: s => s.factors?.strong_dynamic, max: 10 },
        { key: 'ret_20d', label: '近20日涨幅', value: s => s.factors?.ret_20d, max: 50, unit: '%' },
        { key: 'volatility', label: '波动率(60d)', value: s => s.factors?.volatility, max: 60, unit: '%' },
      ]
    }
  ],
  evaluationTemplate: (s) =>
    `OBV趋势突破+WR超卖反弹+量能放大，符合趋势启动特征。近20日涨幅${s.factors?.ret_20d?.toFixed(1)}%${s.factors?.ret_20d > 30 ? '偏高，注意短期回调风险' : '适中'}。`
})
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 智能选股：公共模型能力与用户私有筛选条件分离，结果可保存到个人候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模型评分 + 私有筛选参数。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接下单，只生成候选/方案。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
