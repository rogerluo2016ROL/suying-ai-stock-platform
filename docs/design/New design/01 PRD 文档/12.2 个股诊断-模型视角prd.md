# PRD — 个股诊断 · 模型视角

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

模型视角是 12.0 个股诊断的二级子功能（标签 `🔬 模型视角`），为不同量化模型提供**专属 K线+指标联动视图**。核心差异在于：同一只股票在不同模型眼中关注的指标完全不同——毕师傅看趋势启动（OBV/WR/量比），龙头战法看竞价强度（高开/封单/竞量比），匪爷短线看超买超卖（BB/RSI/MACD）。

## 2. 核心功能：K线+指标联动面板

每个模型视角展示一个 **3 面板 ECharts 图表**，所有面板共享同步 X 轴 + 底部 dataZoom 滑块：

```
┌─ 🔬 毕师傅视角 — 3 Panel ECharts (500px total) ──────────────────┐
│                                                                    │
│ Panel 1 (250px): 日K线 蜡烛图 (60日)                               │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ 红涨绿跌 candle + MA20 (蓝实线) + MA60 (橙实线)               │  │
│ │ cross-hair → tooltip 显示当日 O/H/L/C/MA20/MA60              │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│ Panel 2 (125px): OBV 能量潮                                       │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ OBV曲线 (蓝实线) + OBV MA10 (橙色虚线)                        │  │
│ │ OBV上穿MA10 交叉点 ▼ 标注                                     │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│ Panel 3 (125px): WR 威廉指标                                      │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ WR曲线 (紫色实线)                                             │  │
│ │ — 超买线 -20 (红色虚线, 标注"超买")                           │  │
│ │ — 超卖线 -80 (绿色虚线, 标注"超卖")                           │  │
│ │ WR < -80 区域浅绿色填充                                       │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│ [═══════ dataZoom 底部滑块 60日范围 ═══════]                      │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 各模型指标对照表

| 模型 | K线面板 | 指标面板1 | 指标面板2 |
|---|---|---|---|
| **毕师傅** 趋势启动V13 | 日K + MA20(蓝)/MA60(橙) | OBV + OBV MA10(橙虚线) + 交叉箭头 | WR + 超买线-20(红)/超卖线-80(绿) + 填充色 |
| **龙头战法** V4.3 | 日K + MA5(青)/MA10(紫) | 成交量柱 + VOL MA5(橙) | 竞价标记 (9:25 竖线 + 竞量比标注) |
| **匪爷短线** V2.1 | 日K + BB布林带(上中下三轨) | RSI(14) + 超买70(红)/超卖30(绿)线 | MACD柱 + Signal线 + 零轴 |

### 3.1 图表交互

- **Cross-hair 联动**: 鼠标悬停任一面板 → 三面板同步竖线 + 顶部 tooltip 显示该日所有指标值
- **dataZoom**: 底部滑块支持 20/40/60/120 日范围拖拽，三面板 X轴同步缩放
- **数据标签**: K线面板标注最近一根K线的 MA20/MA60 数值；WR 面板标注当前 WR 值

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
