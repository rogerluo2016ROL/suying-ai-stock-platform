## 1. 页面定位

模型视角是 SubTab `model-perspective` 对应的面板。核心差异：同一只股票在不同量化模型眼中关注的指标完全不同。Panel 以 **3-panel 同步 ECharts 图表** 为中心展示 K线+模型专属指标联动。

## 2. 各模型指标对照

| 模型 | K线面板 (Panel 1) | 指标面板2 (Panel 2) | 指标面板3 (Panel 3) |
|---|---|---|---|
| **毕师傅** 趋势启动V13 | 日K + MA20(蓝)/MA60(橙) | OBV + OBV MA10(橙虚线) + 交叉箭头 | WR + 超买线-20(红)/超卖线-80(绿) |
| **龙头战法** V4.3 | 日K + MA5(青)/MA10(紫) | 成交量柱 + VOL MA5(橙) | 竞价标记 (9:25 竖线 + 竞量比) |
| **匪爷短线** V2.1 | 日K + BB布林带(上中下三轨) | RSI(14) + 超买70/超卖30线 | MACD柱 + DIF/DEA线 + 零轴 |

## 4. 核心数据类型

```typescript
interface ModelPerspectiveProps {
  tsCode: string
  stockName: string
  activeModel: ModelId
  perspective: ModelPerspective | null
  onModelChange: (model: ModelId) => void
}

type ModelId = 'bishifu' | 'longtou' | 'feiye'

interface ModelPerspective {
  modelId: ModelId
  modelName: string
  rating: string                     // "S" | "A" | "B" | "C"
  chartData: ModelChartData
  indicators: ModelIndicator[]
  commentary: string
}

interface ModelChartData {
  dates: string[]
  candles: number[][]                // [open, close, low, high][]
  ma20?: (number | null)[]           // 毕师傅用
  ma60?: (number | null)[]
  ma5?: (number | null)[]            // 龙头战法用
  ma10?: (number | null)[]
  obv?: (number | null)[]            // 毕师傅 panel2
  obvMa10?: (number | null)[]
  obvCrossPoints?: { coord: [number, number]; value: number }[]
  wr?: (number | null)[]             // 毕师傅 panel3
  volumes?: number[]                 // 龙头 panel2
  volMa5?: (number | null)[]
  rsi?: (number | null)[]            // 匪爷 panel2
  bbUpper?: (number | null)[]        // 匪爷 panel1
  bbLower?: (number | null)[]
  dif?: number[]                     // 匪爷 panel3
  dea?: number[]
  macdHist?: number[]
}

interface ModelIndicator {
  name: string
  value: string | number
  status: 'ok' | 'warn' | 'danger'
  statusText: string
}
```

## 6. 图表交互

### 6.1 Cross-hair 联动

- 鼠标悬停任一面板 → 三面板同步竖线 (axisPointer type: 'cross')
- tooltip 显示该日期所有指标值 (K线 OHLC / MA值 / OBV / WR / RSI / MACD)

### 6.2 dataZoom

- 底部滑块支持 20/40/60/120 日范围拖拽
- 三面板 X 轴通过 `xAxisIndex: [0, 1, 2]` 同步缩放
- 同时支持内置缩放 (`type: 'inside'`)

### 6.3 模型切换

```
ModelSelector button click
│
├── setActiveModel(modelId)
├── chart.dispose() → chart.init()
├── chart.setOption(build{Model}Option())
├── updateIndicatorCards(modelId)   // 更新6格卡片
├── updateCommentary(modelId)        // 更新点评段落
└── 埋点: model_perspective_switch
```

## 7. 数据流

```
ModelPerspectiveView mount
│
├── 读取 props.tsCode + props.activeModel
│   (由父 DiagnosisPage 通过 ModelContext 提供)
│
├── GET /api/v1/diagnosis/model-perspective/{tsCode}?model={activeModel}
│   │
│   ├── Response: ModelPerspective
│   │   ├── chartData → build{Model}Option() → ECharts 渲染
│   │   ├── indicators → 6格卡片渲染
│   │   └── commentary → CommentaryBox 渲染
│   │
│   └── Error: 显示错误提示
│
└── 模型切换 →
    ├── 检查 perspectiveCache[tsCode][modelId]
    │   ├── Hit: 直接渲染缓存
    │   └── Miss: GET /model-perspective/{code}?model={newModel}
    └── 重新渲染 ECharts (dispose + init)
```

| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
