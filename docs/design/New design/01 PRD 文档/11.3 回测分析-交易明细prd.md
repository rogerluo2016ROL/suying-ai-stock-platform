# PRD — 回测分析·交易明细

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `11.0 回测分析prd.md`

## 1. 定位

交易明细是回测分析的**第三个 Tab**。回答核心问题：**"每次交易赚了多少？为什么卖？"** 以逐笔交易记录的形式，提供策略执行的完整回溯。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 哪几次交易最成功/失败？原因是止盈还是止损？平均持有天数？ | 策略最近买了什么？赚了还是亏了？ |
| **可见内容** | 完整交易记录 + 筛选 + 统计 + 导出CSV/Excel | 交易记录 + 盈亏统计 |
| **操作** | 筛选 + 导出CSV/Excel | 仅查看 |

> **角色映射（项目 RBAC 4 角色）**：操盘手 → `internal_analyst`；个人投资者 → `user`；系统管理员 → `admin`。金额打码/数据过滤一律由服务端按 JWT 角色执行，前端禁止传 `X-User-Role` 等身份头。

## 3. 筛选规则

| 筛选项 | 条件 | 颜色 |
|---|---|---|
| 全部 | 无筛选 | fg-2 |
| 盈利 | returnPct > 0 | down (绿色) |
| 亏损 | returnPct < 0 | up (红色) |

## 4. 原因标签

| 原因 | 含义 | 标签颜色 |
|---|---|---|
| 止盈 | 到达止盈价 | 绿色 (take-profit) |
| 止损 | 触及止损线 | 红色 (stop-loss) |
| 到期 | 持有天数到期自动平仓 | 灰色 (expire) |

## 5. 交互

- 策略下拉：切换策略时重新加载该策略**最近一次完成回测**的交易记录（round-trip 成对交易）
- 单行展开：查看该笔交易的原始逐笔成交（buy/sell legs）
- 筛选标签：点击切换，当前筛选条件下高亮
- 交易列表：按卖出日倒序排列，分页 20 条/页
- 导出CSV：下载当前筛选条件下的交易记录为 CSV 文件
- 导出Excel：下载为 .xls（前端生成 HTML 表格方案，与 CSV 共用已加载数据；操盘手 `internal_analyst` 专用——按钮按角色显示，数据内容由服务端按 JWT 角色过滤）

## 6. AC

| ID | AC |
|---|---|
| AC-1 | 策略下拉切换时正确加载对应策略的交易记录 |
| AC-2 | 筛选标签正确过滤盈利/亏损/全部，数量统计正确 |
| AC-3 | 交易列表按卖出日倒序，包含完整字段：代码/日期/价格/盈亏%/持有天/原因 |
| AC-4 | 原因标签颜色正确：止盈绿/止损红/到期灰 |
| AC-5 | 底部统计汇总正确：盈利/亏损笔数、平均盈亏、最大盈利/亏损、胜率 |
| AC-6 | 导出CSV 按钮可下载当前筛选结果的 CSV 文件 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 回测分析：回测引擎公共，参数、结果、报告默认私有。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共因子/行情 + 私有回测结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 复盘写回 Plan，不直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
