# PRD — 量化交易·策略日志

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **Estimated effort tier**: Small（日志列表 + 筛选 + 导出）

## 1. Background

策略日志是量化交易的**执行审计记录**。操盘手在此查看策略的每一次操作记录：下单、止损触发、止盈触发、暂停/恢复、报错等，支持按类型筛选和导出 CSV。当前痛点：

1. 缺少统一的策略日志视图——操作记录散落在各服务日志中
2. 无法按事件类型筛选（只看止损 / 只看报错）
3. 无法导出日志用于审计或分析

**本次更新**：页面顶部新增**策略选择器下拉框**（与 8.3 策略监控共享逻辑），操盘手可切换不同策略的日志视图。

## 2. Goal & Non-Goals

**目标**：
- 日志列表：时间/级别图标/事件描述/详情
- 按类型筛选：全部/下单/止损/止盈/暂停/错误/信息
- 日志级别颜色区分（蓝色=下单/红色=止损/绿色=止盈/橙色=暂停/灰色=信息）
- [📥导出日志] 导出 CSV

**Non-Goals**：
- 不做策略参数配置 → 8.2 策略配置
- 不做净值曲线/持仓 → 8.3 策略监控
- 不做日志全文搜索 → Phase 2

## 3. User Stories

| ID | As a | I want to | So that |
|---|---|---|---|
| US-1 | 操盘手 | 看到策略全部操作日志（下单/止损/止盈/暂停/错误） | 审计策略执行过程 |
| US-2 | 操盘手 | 按事件类型筛选日志 | 聚焦关注的事件（如只看止损） |
| US-3 | 操盘手 | 看到不同级别的颜色图标 | 快速区分事件严重性 |
| US-4 | 操盘手 | 点击[导出日志]下载 CSV | 离线分析或存档 |

## 6. Technical Constraints

- 数据来源：`GET /api/v1/strategy/auto/{id}/logs?type=all&limit=50`
- 策略选择器数据源：`GET /api/v1/strategy?status=running,paused,stopped`（与 8.3 共享逻辑）
- 导出：`GET /api/v1/strategy/auto/{id}/logs/export?type=all` → 返回 CSV 流
- 日志不可编辑，仅只读展示
- 轮询间隔：30s

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 量化交易：策略模板可公共，策略实例、参数和运行日志必须私有隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模板 + 私有策略实例。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 自动执行绑定账户并经过 RiskGate。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
