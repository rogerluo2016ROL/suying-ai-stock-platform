- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `11.0 回测分析prd.md`

## 1. 定位

策略对比是回测分析的**第二个 Tab**。回答核心问题：**"哪个策略表现最好？好在哪里？"** 通过多策略叠加权益曲线 + 核心指标对比表，直观比较不同策略的优劣。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 4个策略各自表现如何？谁夏普最高谁收益最大？ | 折叠（个人投资者通常不需要对比） |
| **可见内容** | 4策略叠加曲线 + 7项指标对比表 + 🥇标注 | 折叠 |
| **操作** | 勾选策略 + 运行对比 | 不展示 |

## 3. 指标高亮规则

| 指标 | 最优方向 | 标注方式 |
|---|---|---|
| 年化收益 | 最大 | 🥇 金色标注, 单元格高亮 |
| 最大回撤 | 最小 (绝对值) | 🥇 标注, 绿色 |
| 夏普比率 | 最大 | 🥇 标注, 蓝色高亮 |
| 胜率 | 最大 | 🥇 标注 |
| Calmar | 最大 | 🥇 标注 |
| 交易次数 | 最多 | 🥇 标注 |

## 4. 交互

- 策略复选框：最少选2个，最多选4个，少于2时禁用 [运行对比]
- 颜色分配：按选中顺序分配 [蓝 #3d8bff, 红 #ff4d4f, 绿 #2ec27e, 橙 #f5a623]
- 运行对比：POST `/backtest/compare` → 并行计算 → 返回 CompareResult
- 权益曲线：legend 点击切换显示/隐藏单条曲线
- 对比表格：每列最优值 🥇 + 高亮，底部汇总最优标注
- 空状态：首次进入显示 "请选择至少2个策略并运行对比"

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 回测分析：回测引擎公共，参数、结果、报告默认私有。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共因子/行情 + 私有回测结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 复盘写回 Plan，不直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
