# PRD — 量化交易·策略监控

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **Estimated effort tier**: Large（ECharts 净值曲线 + 回撤覆盖 + 持仓表 + 交易记录 + 操作按钮）

## 1. Background

策略监控是量化交易的**运行状态仪表盘**。操盘手在此实时查看运行中策略的净值变化、当前持仓、当日交易记录，并执行暂停、调参、结算等操作。

**本次更新**：页面顶部新增**策略选择器下拉框**，操盘手可一键切换监控不同运行中的策略，无需离开页面。

当前痛点：

1. 一次只能看一个策略，缺少切换入口
2. 缺少策略级别的净值可视化——只有数字没有曲线
3. 缺少回撤覆盖图——不知道回撤风险
4. 当前持仓和当日交易分散在不同页面
5. 缺少暂停/恢复/结算的一键操作入口

## 2. Goal & Non-Goals

**目标**：
- 策略选择器下拉框：`GET /strategy?status=running,paused`，默认选中最新运行的策略
- KPI 条：净值/今日盈亏/累计收益/最大回撤 4 个核心指标
- ECharts 净值曲线：累计收益（蓝色面积）+ 回撤覆盖（红色半透明）+ 基准（灰色虚线）
- 当前持仓表：代码/名称/持仓/现价/浮盈/仓位%/止损价
- 当日交易列表：时间/方向/代码/数量/价格
- 操作按钮：[⏸️暂停/▶️恢复][⚙️调整参数][🏁结算]

**Non-Goals**：
- 不做策略日志详情 → 8.4 策略日志
- 不做策略参数编辑 → 8.2 策略配置
- 不做多策略对比 → 9.3 方案对比

## 3. User Stories

| ID | As a | I want to | So that |
|---|---|---|---|
| US-1 | 操盘手 | 看到净值曲线 + 回撤面积图 | 直观判断策略表现与风险 |
| US-2 | 操盘手 | 看到 4 个 KPI 指标（净值/日盈亏/累计收益/最大回撤） | 快速 grasp 核心数据 |
| US-3 | 操盘手 | 看到当前持仓表和当日交易记录 | 了解仓位和今日操作 |

| US-6 | 操盘手 | 点击[结算]手动终止策略并平仓 | 主动结束策略 |

## 6. Technical Constraints

- 数据来源：`GET /api/v1/strategy/auto/{id}/nav` + `GET /api/v1/strategy/auto/{id}/positions` + `GET /api/v1/strategy/auto/{id}/trades`
- 策略选择器数据源：`GET /api/v1/strategy?status=running,paused`，默认选中最新运行的策略
- 轮询间隔：30s
- 净值曲线数据量：支持 60-180 个交易日
- ECharts 渲染：SVG 模式（数据量 < 500 点保证性能）

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 量化交易：策略模板可公共，策略实例、参数和运行日志必须私有隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模板 + 私有策略实例。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 自动执行绑定账户并经过 RiskGate。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
