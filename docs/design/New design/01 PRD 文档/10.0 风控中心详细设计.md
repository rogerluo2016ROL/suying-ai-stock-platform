## 1. 页面定位

风控中心是**多层防御体系的监控中枢**。覆盖 25 个风险维度，横跨四层防御：交易前置 → 策略执行 → 全局熔断 → 市场环境。

采用 **SubTabBar 多页签架构**，5 个子 Tab 各司其职：

```
🛡️ 风控中心
│
├── [SubTabBar: 📊风控总览 | 📋持仓风险 | 🤖策略风险 | 🌍市场风险 | 📜事件审计]
│
├── 📊 风控总览     10.1  熔断器横幅 + 四层防御状态 + KPI + 告警摘要
├── 📋 持仓风险     10.2  止损逼近排序 + 审计/公告/ST 风险标签 + 调整止损
├── 🤖 策略风险     10.3  策略运行状态 + 日亏损 + 强制卖出 + 暂停/恢复
├── 🌍 市场风险     10.4  市场风向 + 黑天鹅信号 + 板块风险热力
└── 📜 事件审计     10.5  风险事件时间线 + 审计摘要统计
```

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 风控闸门还开着吗？哪些持仓最危险？哪个策略出问题了？ | 我的持仓安全吗？ |
| **可见 Tab** | 5 个全可见 | 2 个：风控总览 + 持仓风险 |
| **操作** | 从风控中心直接调整止损/暂停策略 | 仅查看，跳转交易中心操作 |
| **频率** | 盘中持续监控（30s刷新） | 按需查看 |

### 4.3 风险评分算法（持仓排序）

```typescript
function calcRiskScore(pos: PositionRisk): number {
  let score = 0

  if (pos.distanceToStopPct !== null) {
    if (pos.distanceToStopPct < 1)  score += 50
    else if (pos.distanceToStopPct < 3) score += 30
    else if (pos.distanceToStopPct < 5) score += 15
  }

  for (const tag of pos.riskTags) {
    if (tag.level === 'danger')  score += 40
    else if (tag.level === 'warning') score += 20
    else score += 5
  }

  if (pos.pnlPct < 0 && (pos.distanceToStopPct ?? 99) < 5) score += 20

  if (pos.exposurePct > 25) score += 15
  else if (pos.exposurePct > 15) score += 5

  return score
}
```

## 5. 数据流

```
页面加载 (useEffect [])
│
├── GET /api/v1/trade/risk-dashboard       ← trade-service 聚合端点
│   ├── circuitBreaker → BreakerBanner
│   ├── defenseLayers → 四层防御条
│   ├── riskKpis → KPI 行
│   ├── recentAlerts → 告警列表
│   ├── positions → PositionRiskTable (按 riskScore 排序)
│   ├── strategies → StrategyRiskTable
│   ├── marketRegime → 市场风向卡片
│   ├── blackSwan → 黑天鹅检测
│   ├── keyEvents → 关键事件列表
│   ├── sectorRisks → 板块热力条
│   ├── auditSummary → 审计摘要
│   └── auditTimeline → 事件时间线
│
├── SubTabBar 切换仅影响渲染区域，不重新请求
│
└── 自动刷新 (30s, 盘中)
    └── setInterval → GET /risk-dashboard (整页刷新)
```

### 后端聚合端点

```python
# trade-service/app/routers/risk.py
@router.get("/risk-dashboard")
async def risk_dashboard():
    result = {}
    
    # 1. 熔断器 (本地内存)
    cb = get_circuit_breaker()
    result["circuit_breaker"] = await cb.get_status()
    
    # 2. 四层防御状态 (本地计算)
    result["defense_layers"] = compute_defense_layers(result["circuit_breaker"])
    
    # 3. 账户 + 持仓 (本地 broker)
    account = await broker.get_account()
    positions = await broker.get_positions()
    result["risk_kpis"] = compute_kpis(account, positions)
    result["positions"] = enrich_with_risk_tags(positions)
    
    # 4. 策略状态 (DB)
    result["strategies"] = await db.get_active_strategies_risk()
    
    # 5. 市场数据 (调用 signal-service)
    market = await fetch_from_signal_service("/market-regime")
    result["market_regime"] = market.regime
    result["black_swan"] = market.black_swan
    result["sector_risks"] = market.sector_risks
    result["key_events"] = market.key_events
    
    # 6. 审计日志 (DB 聚合)
    logs = await db.get_today_audit_logs()
    result["audit_summary"] = aggregate_audit(logs)
    result["audit_timeline"] = build_timeline(logs)
    result["recent_alerts"] = build_recent_alerts(logs, positions)
    
    return result
```

## 6. 操盘手 vs 个人投资者差异

| 特性 | 操盘手 | 个人投资者 |
|---|---|---|
| **可见 SubTab** | 5 个全可见 | 风控总览 + 持仓风险 (2个) |
| **风控总览** | 四层防御+KPI+告警 (完整) | 熔断器+风险持仓数 (简化) |
| **持仓风险** | 全部持仓+调整止损/减仓 | 仅我的持仓+只读 |
| **策略风险** | 全部策略+暂停/恢复 | 不展示 |
| **市场风险** | 完整风向+板块+黑天鹅 | 不展示 |
| **事件审计** | 完整时间线+审计统计 | 折叠(仅显示告警数) |
| **金额显示** | 完整数字 | ¥*** 屏蔽 |
| **刷新频率** | 30s 自动刷新 | 手动刷新 |
| **权限检查** | SubTabBar 按 role 过滤 visible=false 的 Tab |

## 7. 交互规范

### 7.1 SubTabBar 切换

- Pill 风格，active tab 蓝色高亮 (`var(--accent-dim)` 背景 + `var(--accent)` 文字)
- 切换不重新请求数据（数据已在父组件）
- URL 同步：`/risk-control?tab=overview`

### 7.2 熔断器横幅

| 状态 | 视觉 | 行为 |
|---|---|---|
| NORMAL | 绿色背景 🟢 | 无特殊交互 |
| TRIGGERED | 红色背景 🔴 | 点击展开详情：触发时间、亏损明细、冷却倒计时 |
| HALF_OPEN | 橙色背景 🟡 | 点击查看：剩余探测次数、上次探测结果 |

### 7.3 持仓行交互

- 行 hover: 背景高亮 (`--surface-2`)
- 行 click: 跳转 `/diagnosis?code={code}` (新标签页)
- 止损进度条 hover: Tooltip 显示当前价/成本价/止损价/距离
- 风险标签 hover: Tooltip 展示详细原因

### 7.4 空态与错误态

| 状态 | 处理 |
|---|---|
| 无持仓 | Empty "暂无持仓 · 前往选股页面发现机会" |
| 无策略 | Empty "暂无活跃策略 · 前往量化交易页创建" |
| 无风险事件 | "今日无风险事件 ✅" |
| 熔断器状态不可用 | "熔断器状态获取失败 [重试]" |
| 市场风向不可用 | 默认值显示，标注"数据暂不可用" |

| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
