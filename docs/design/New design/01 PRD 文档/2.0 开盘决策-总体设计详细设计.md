### 1.2 跨 Tab 状态管理

```typescript
// OpeningDecisionContext.tsx

interface OpeningDecisionState {
  // 跨 Tab 共享
  activeTab: TabKey
  timeSlot: TimeSlot
  
  // 竞价分析 → 信号扫描
  selectedAuctionSectors: string[]           // 竞价中选中的板块
  auctionPicks: AuctionPick[]                // 竞价选股结果
  auctionCbPicks: CbPick[]                   // 竞价选债结果
  
  // 信号扫描 → 候选池
  confirmedSignals: SignalStock[]            // 信号确认的股票
  
  // 候选池 (多源融合)
  candidatePool: CandidateStock[]            // 融合后的最终候选
  candidateSources: Record<string, string[]> // 每个候选的来源追踪
  
  // 执行监控
  activeOrders: OrderRecord[]                // 今日订单

type TabKey = 'overview' | 'auction' | 'signal' | 'candidate' | 'execution'
type TimeSlot = 'pre-market' | 'auction' | 'intraday' | 'post-market' | 'non-trading'
```

### 1.3 时段感知与默认 Tab

```typescript
// hooks/useTimeSlot.ts
function useTimeSlot(): TimeSlot {
  const [timeSlot, setTimeSlot] = useState<TimeSlot>(detectTimeSlot())
  
  useEffect(() => {
    const timer = setInterval(() => setTimeSlot(detectTimeSlot()), 30_000)
    return () => clearInterval(timer)
  }, [])
  
  return timeSlot
}

function detectTimeSlot(): TimeSlot {
  const now = new Date()
  const hour = now.getHours()
  const minute = now.getMinutes()
  const time = hour * 100 + minute
  const isTradingDay = getIsTradingDay() // 从 trading_calendar 判断
  
  if (!isTradingDay) return 'non-trading'
  if (time < 925)    return 'pre-market'
  if (time < 930)    return 'auction'
  if (time < 1500)   return 'intraday'
  return 'post-market'
}

// 默认 Tab 映射
const DEFAULT_TAB: Record<TimeSlot, TabKey> = {
  'pre-market':   'auction',    // 盘前默认看竞价分析
  'auction':      'auction',
  'intraday':     'execution',  // 盘中默认看执行监控
  'post-market':  'candidate',  // 盘后默认看候选池
  'non-trading':  'overview',   // 非交易日看决策总览
}
```

## 4. 关键交互流程

### 4.1 竞价分析 → 信号扫描 联动

```
竞价分析 Tab:
  用户看到 "半导体 板块竞价共振12只" 卡片
    ↓ 点击卡片上的 [锁定板块→信号扫描]
  
dispatch({ type: 'SET_SELECTED_SECTORS', payload: ['半导体'] })
dispatch({ type: 'NAVIGATE_TO_TAB', payload: 'signal' })
    ↓
信号扫描 Tab 激活:
  SignalMatrix 组件检查 context.selectedSectors
    ↓ 有锁定板块 → 矩阵只显示半导体的色块
    标题变为 "⚡ 信号扫描 [已锁定: 半导体(12)]"
    ↓ 显示 [清除锁定] 按钮
```

### 4.2 多 Tab → 候选池 融合

```
CandidatePoolManager 内部:

addSource('auction', auctionPicks)     ← 竞价分析 Tab 调用
addSource('signal', confirmedSignals)  ← 信号扫描 Tab 调用
addSource('screener', screenerPicks)   ← 页面加载时自动调用
addSource('watchlist', watchlistCodes) ← 上下文初始化时调用

compute():
  1. 取并集 (所有来源的 code 去重)
  2. 计算共识度 = 出现在几个来源中
     ★★★ = 3个来源以上
     ★★☆ = 2个来源
     ★☆☆ = 1个来源
  3. 计算综合评分 = avg(竞价评分, 信号评分, 选股评分)
  4. 自选共振标记 = code ∈ watchlist
  5. 风险排除: 审计/公告/ST/止损 → 标记为 excluded
  6. 排序: 共识度降序 → 综合评分降序
```

### 4.3 候选池 → 方案生成

```
候选池 Tab:
  用户勾选 3 只共识度★★★的股票
    ↓ 点击 [生成方案]
  
调用 POST /api/v1/strategy/generate-from-picks
  body: { codes: [...], mode: "opening_decision" }
    ↓ 成功返回 strategy_id
  跳转 /strategy?plan={strategy_id}
    ↓ strategy 页面展示: 
    标的 + 仓位分配 + 止损止盈 + 风控闸门
    ↓ 用户确认后
  提交到执行监控 Tab (或交易中心)
```

| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共竞价/行情 + 私有候选池。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 实盘前必须进入方案与风控。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
