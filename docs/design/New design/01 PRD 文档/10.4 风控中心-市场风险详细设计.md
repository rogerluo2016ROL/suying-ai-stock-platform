## 1. 页面定位

市场风险是风控中心**第四个 SubTab**（SubTab key: `market`）。展示市场宏观环境评估，包括市场风向评分、八维指标、黑天鹅检测和板块风险热力。

## 3. 核心数据结构

```typescript
interface MarketRiskData {
  marketRegime: MarketRegime
  blackSwan: BlackSwanStatus
  keyEvents: MarketKeyEvent[]
  sectorRisks: SectorRisk[]
}

interface MarketRegime {
  regime: string           // "NEUTRAL_BULL"
  label: string            // "偏牛"
  score: number            // 72
  suggestedPosition: string // "7-8成"
  dimensions: MarketDimension[]
}

interface MarketDimension {
  name: string             // "趋势"
  score: number            // 75
  maxScore: number         // 100
  inverted: boolean        // true=低分安全 (如风险维度)
}

interface BlackSwanStatus {
  level: 'none' | 'warning' | 'triggered'
  label: string
  detail: string
  recentConcerns: string[]
}

interface MarketKeyEvent {
  date: string
  title: string
}

interface SectorRisk {
  sector: string
  level: number            // 0-100, 越高越牛
  label: string            // "偏牛" / "中性" / "偏弱" / "偏熊"
}
```

## 4. 颜色映射

```typescript
function regimeColor(score: number): string {
  if (score >= 70) return 'var(--down)'     // 强牛 = 绿
  if (score >= 50) return 'var(--accent)'   // 偏牛 = 蓝
  if (score >= 30) return 'var(--warn)'     // 偏熊 = 橙
  return 'var(--up)'                         // 极熊 = 红
}

function dimBarColor(score: number, inverted: boolean): string {
  const s = inverted ? (100 - score) : score
  if (s >= 70) return 'var(--down)'
  if (s >= 50) return 'var(--accent)'
  if (s >= 30) return 'var(--warn)'
  return 'var(--up)'
}

const SWAN_COLORS = {
  none:      { bg: 'var(--down-bg)', color: 'var(--down)', icon: '🟢' },
  warning:   { bg: 'var(--warn-bg)', color: 'var(--warn)', icon: '🟡' },
  triggered: { bg: 'var(--up-bg)',   color: 'var(--up)',   icon: '🔴' },
}
```

## 5. 空态与降级

| 状态 | 处理 |
|---|---|
| 市场数据不可用 | 显示占位卡片，标注 "数据暂不可用 · 请检查 signal-service" |
| 黑天鹅检测超时 | "检测服务超时 [重试]" |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 风控中心：规则分全局/租户/账户，RiskVerdict 按账户和上下文归档。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
