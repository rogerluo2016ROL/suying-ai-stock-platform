## 3. 核心数据结构

```typescript
interface TradesState {
  selectedStrategyId: string
  strategies: Strategy[]
  filterMode: 'all' | 'win' | 'loss'
  trades: TradeRecord[]
  filteredTrades: TradeRecord[]
  pagination: {
    current: number
    pageSize: number      // 20
    total: number
  }
}

interface TradeRecord {
  id: number
  tsCode: string
  name: string
  buyDate: string          // "2025-01-03"
  sellDate: string         // "2025-01-10"
  buyPrice: number         // 195.00
  sellPrice: number        // 218.50
  returnPct: number        // +12.1
  holdingDays: number      // 5
  reason: 'take_profit' | 'stop_loss' | 'expire'
}

interface TradeSummary {
  totalTrades: number
  winningTrades: number
  losingTrades: number
  avgWinPct: number        // +8.5
  avgLossPct: number       // -4.2
  maxWinPct: number        // +22.1
  maxWinName: string       // "宁德"
  maxLossPct: number       // -9.8
  maxLossName: string      // "中芯"
  avgHoldingDays: number   // 6.3
  winRate: number          // 0.681
}
```

## 4. 数据流

```
TradesPanel
│
├── 初始化
│   ├── 加载策略列表 (同 BacktestRunPanel)
│   ├── 默认选中上次回测使用的策略
│   └── GET /backtest/{backtestId}/trades → trades[]
│
├── 用户操作: 切换策略
│   ├── selectedStrategyId 变更
│   ├── GET /backtest/{newStrategyId}/trades → trades[]
│   └── 重置筛选 + 分页到第一页
│
├── 用户操作: 切换筛选
│   ├── filterMode = 'win' | 'loss' | 'all'
│   └── 本地过滤: trades.filter(t => ...)
│       ├── 'win': t.returnPct > 0
│       └── 'loss': t.returnPct < 0
│
├── 用户操作: 翻页
│   └── 本地切片: filteredTrades.slice(offset, offset + pageSize)
│
├── 用户操作: 导出CSV
│   ├── 将 filteredTrades 转 CSV 字符串
│   ├── Blob + URL.createObjectURL → download
│   └── 文件名: `回测明细_${strategyName}_${date}.csv`
│
└── 统计计算
    └── 遍历 trades 计算 TradeSummary
        ├── winningTrades = trades.filter(t => t.returnPct > 0)
        ├── avgWinPct = mean(winningTrades.map(t => t.returnPct))
        ├── maxWin = winningTrades.sort((a,b) => b.returnPct - a.returnPct)[0]
        └── ...
```

## 5. CSV 导出格式

```typescript
function exportToCSV(trades: TradeRecord[], strategyName: string) {
  const BOM = '\uFEFF'; // 中文兼容
  const header = '编号,代码,名称,买入日期,卖出日期,买入价,卖出价,盈亏%,持有天数,原因\n';
  const rows = trades.map((t, i) =>
    `${i + 1},${t.tsCode},${t.name},${t.buyDate},${t.sellDate},${t.buyPrice},${t.sellPrice},${t.returnPct.toFixed(1)}%,${t.holdingDays}天,${REASON_MAP[t.reason]}`
  ).join('\n');

  const csv = BOM + header + rows;
  const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `回测明细_${strategyName}_${new Date().toISOString().slice(0,10)}.csv`;
  a.click();
  URL.revokeObjectURL(url);
}

const REASON_MAP = {
  take_profit: '止盈',
  stop_loss: '止损',
  expire: '到期',
};
```

## 6. 实施顺序

1. TradesTable 组件 → 表格 + 分页
2. FilterBar → 策略选择 + 筛选标签
3. ReasonTag 组件 → 原因标签 (3色)
4. SummaryBar → 统计汇总 + 导出按钮
5. TradesPanel 容器 → 状态管理 + API 调用
6. CSV 导出功能 → Blob 下载

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 回测分析：回测引擎公共，参数、结果、报告默认私有。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共因子/行情 + 私有回测结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 复盘写回 Plan，不直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
