- **Date**: 2026-06-26 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

综合诊断是个股诊断的**默认 Tab**（Tab key: `overview`）。回答核心问题：**"这只股票在五个维度上综合表现如何？什么价位进场/止损？"**

以左雷达图 + 右详情面板的双栏布局，自上而下呈现五维评分 → 关键价位 → 风险提示 → 操作建议。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 五维综合得分？关键技术/资金指标？ | 这只股票好不好？什么价买卖？ |
| **可见内容** | 完整雷达图 + 五维分解 + 关键价位 + AI预测 + 操作建议 | 综合评分 + K线预测按钮 |
| **操作** | 跳转K线预测 / 交易中心 / 加入自选 | 跳转K线预测 |

## 3. 五维评分

| 维度 | 权重 | 评分源 |
|---|---|---|
| 技术面 | 40% | K线形态/均线/MACD/RSI/KDJ/量价关系 |
| 资金面 | 25% | 主力净流入/北向资金/大单动向 |
| 基本面 | 20% | PE/PB/ROE/营收增速/净利增速 |
| AI预测 | 10% | Kronos 30日预测趋势+置信度 |
| 情绪面 | 5% | 新闻舆情/社交媒体/研报评级 |

### 综合评分等级

| 得分 | 等级 | 颜色 | 建议 |
|---|---|---|---|
| ≥80 | 优秀 | 绿 `--down` | 强烈推荐 |
| 60-80 | 良好 | 蓝 `--accent` | 建议关注 |
| 40-60 | 一般 | 黄 `--warn` | 谨慎参与 |
| <40 | 较差 | 红 `--up` | 建议回避 |

## 4. 关键价位

| 价位 | 含义 | 计算公式 | 颜色 |
|---|---|---|---|
| 当前价 | 实时成交价 | — | 白 |
| 阻力位 | 短线阻力 | 近期高点 + ATR*2 | 红 `--up` |
| 支撑位 | 强支撑 | 近期低点 - ATR*1.5 | 绿 `--down` |
| 止损线 | 强制止损 | 支撑位 - 5% | 绿虚线 `--down` |

## 5. 交互

- 输入股票代码 → 自动触发 GET /diagnosis/{code}，雷达图 + 右侧详情联动更新
- 雷达图 tooltip 悬停显示维度名 + 分数
- 右侧维度卡片可折叠子项明细
- 操作按钮跳转其他页面或添加到自选
- 面包屑显示来源页面，可点击返回

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
