- **Date**: 2026-06-26
- **Owner**: product-lead

- **Estimated effort tier**: Medium（新建模块 + 订单/持仓/策略三合一视图）

## 1. 定位

执行监控是开盘决策的**盘中持续监控** Tab。操盘手在 9:30 开盘后切换至此，持续跟踪订单执行和持仓风险。

与风控中心的关系：执行监控展示"执行层"信息（订单/持仓/策略状态），风控中心展示"规则层"信息（熔断/止损规则/审计/公告）。两者互补。

## 2. 数据来源

| 数据 | 来源 |
|---|---|
| 今日订单列表 + 状态 | `GET /trade/orders?date=today` |
| 实时持仓 + 盈亏 | `GET /trade/positions` |
| 账户总览 | `GET /trade/account` |
| 熔断器状态 | `GET /trade/circuit-breaker/status` |
| 策略执行状态 | `GET /strategy` (列表，筛选 active/paused) |

## 4. 方案状态流转

```
候选池 [确认提交→自动交易] → 状态: running → 出现在"活跃策略" + "今日方案"
候选池 [保存为手动方案]    → 状态: draft   → 出现在"今日方案"
                             │
                             ├── [🚀 一键启动] → 变为 running → 移到"活跃策略"
                             ├── [📝 去手动下单] → 跳转交易中心
                             └── [🗑 删除] → 删除方案

方案结束后 → 状态: closed → 归档到"历史方案"（折叠）
```

## 5. 操盘手 vs 个人投资者

| 区域 | 操盘手 | 个人投资者 |
|---|---|---|
| 订单状态 | 全部订单 + 撤单/改单操作 | 仅"我的订单" + 只读 |
| 持仓盈亏 | 全部持仓 + 止损/加仓/减仓 | 仅"我的持仓" + 只读+止损建议 |
| 活跃策略 | 全部策略 + 启动/暂停操作 | 只读 + "策略今日盈亏"摘要 |
| **今日方案** | **全部方案 + 启动/删除** | **仅我的方案 + 启动/手动下单** |
| 金额显示 | 完整金额 | 金额打码 `¥***` |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 开盘决策：操盘手默认入口，输出私有 Candidate 与 DecisionContext。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共竞价/行情 + 私有候选池。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 实盘前必须进入方案与风控。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
