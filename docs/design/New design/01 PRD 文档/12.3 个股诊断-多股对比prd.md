# PRD — 个股诊断·多股对比

- **Date**: 2026-06-26 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `12.0 个股诊断prd.md`

## 1. 定位

多股对比是 SubTab `compare` 对应的面板。回答核心问题：**"这几只股票谁更好？差在哪里？"**

支持 2-3 只股票横向对比，雷达图叠加显示，核心指标对比表 + 自动生成对比结论。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 同一行业哪只股票综合最优？各项指标差异多大？ | 这两只股票哪个好？ |
| **可见内容** | 叠加雷达图 + 完整指标对比表 + 差异行 + 对比结论 | 叠加雷达图 + 简化对比表 |
| **操作** | 添加/删除对比股票 (max 3) + 跳转诊断 | 2 只固定对比 |

## 3. 对比规则

- 最少 2 只，最多 3 只
- 同行业 Top3 自动推荐 (可选)
- 雷达图 3 色: 蓝色 `#3d8bff`、红色 `#ff4d4f`、绿色 `#2ec27e`
- 差异行颜色: 绿色 = 左侧更好, 红色 = 右侧更好
- 对比结论由 diagnosis-service LLM 自动生成

## 4. 交互

- 股票选择器 Dropdown 切换对比股票
- [+ 添加第3只] 按钮 (最多3只)
- 雷达图可点击 Legend 切换显示/隐藏某只
- Hover 对比表行高亮
- 差异行单元格单击跳转该股票诊断详情

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
