## 1. 页面定位

量化交易是**策略全生命周期管理台**，操盘手在此浏览策略广场、创建/编辑自动交易策略、监控净值曲线和持仓变化、查看策略日志。通过 4 个 SubTab（子标签页）组织：

| SubTab | Key | 功能 | 使用者 |
|---|---|---|---|
| 🏪 策略广场 | `market` | 浏览全部可用策略，按类型/收益筛选，一键跟单 | 所有用户 |
| ⚙️ 策略配置 | `config` | 创建/编辑策略参数（risk_rules/position_rules/sell_conditions） | 操盘手/量化交易员 |
| 📈 策略监控 | `monitor` | 运行中策略的净值曲线 + 持仓 + 今日交易 | 操盘手 |
| 📜 策略日志 | `log` | 执行记录：下单/止损/止盈/暂停/错误完整审计 | 操盘手 |

与方案管理的关系：

| 维度 | 方案管理 (menu 9) | 量化交易 (menu 8) |
|---|---|---|
| **策略来源** | 候选池一键生成方案 | 策略广场浏览 + 手动创建 |
| **复杂度** | 简化（仓位/止损/止盈） | 完整（risk_rules / position_rules / sell_conditions） |
| **生命周期** | 日度 (早盘→收盘结算) | 长期 (可跨日/跨周运行) |
| **净值监控** | 无 | ECharts NAV 曲线 + 回撤覆盖 |

## 3. 核心数据结构

### 3.1 策略广场

```typescript
type StrategyType = 'all' | 'trend' | 'mean_reversion' | 'grid' | 'dragon'

interface MarketStrategy {
  id: string
  name: string
  tags: string[]                    // "热门" "趋势跟踪" "🔥"
  type: StrategyType
  annualReturn: number              // +32.5%
  maxDrawdown: number               // -12.3%
  sharpeRatio: number               // 2.15
  winRate: number                   // 68%
  userCount: number                 // 156
  desc: string
}

interface MarketState {
  strategies: MarketStrategy[]
  filter: StrategyType
  sortBy: 'annualReturn' | 'maxDrawdown' | 'sharpeRatio' | 'userCount'
  sortDir: 'asc' | 'desc'
}
```

### 3.2 策略配置

```typescript
type StrategyStatus = 'active' | 'paused' | 'stopped'

interface Strategy {
  id: string
  name: string
  desc: string
  status: StrategyStatus
  stocks: string[]                   // ts_code[]
  riskRules: RiskRules
  positionRules: PositionRules
  sellConditions: SellConditions
  executorId?: string
  navHistory: NavPoint[]
  positions: StrategyPosition[]
  logs: StrategyLog[]
  createdAt: string
  startedAt?: string
  stoppedAt?: string
  dailyPnl?: number
  dailyPnlPct?: number
  totalReturn?: number
  totalReturnPct?: number
  maxDrawdown?: number
  annualReturn?: number
}

interface RiskRules {
  maxDrawdown: number               // -15%
  dailyLossLimit: number            // -5%
  singleStockCap: number            // 15%
  totalPositionCap: number          // 60%
}

interface PositionRules {
  entrySignal: string               // "MA20上穿MA60"
  positionSizing: 'equal' | 'market_cap' | 'kelly'
  rebalanceInterval: number         // 天
}

interface SellConditions {
  stopLoss: number                  // -8%
  takeProfit: number                // +15%
  trailingStop: boolean
  trailingStopPct?: number          // -5%
  timeStop: number                  // 30天
}

interface NavPoint {
  date: string                      // "2026-06-01"
  nav: number                       // 1.000 起始
  dailyReturn: number               // +0.021 = +2.1%
  cumReturn: number                 // +0.185 = +18.5%
  benchmarkReturn?: number          // 基准累计收益
}

interface StrategyPosition {
  tsCode: string
  name: string
  holdQty: number
  currentPrice: number
  costPrice: number
  pnl: number
  pnlPct: number
  allocationPct: number
  stopLoss: number
}

type LogType = 'order' | 'stop_loss' | 'take_profit' | 'pause' | 'error' | 'info'

interface StrategyLog {
  id: string
  time: string                      // "09:32:15"
  type: LogType
  icon: string                      // 📝 🛑 ✅ ⏸️ ℹ️ ❌
  message: string
  detail?: string
}
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 量化交易：策略模板可公共，策略实例、参数和运行日志必须私有隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模板 + 私有策略实例。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 自动执行绑定账户并经过 RiskGate。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
