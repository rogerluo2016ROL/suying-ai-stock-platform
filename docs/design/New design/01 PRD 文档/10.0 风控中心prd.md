# PRD — 风控中心

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

风控中心是**多层防御体系的监控中枢**。覆盖 25 个风险维度，横跨四层防御：交易前置 → 策略执行 → 全局熔断 → 市场环境。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 风控闸门还开着吗？哪些持仓最危险？哪个策略出问题了？ | 我的持仓安全吗？ |
| **操作** | 从风控中心直接调整止损/暂停策略 | 仅查看，跳转交易中心操作 |
| **频率** | 盘中持续监控（30s刷新） | 按需查看 |

## 2. 行业最佳实践参考

| 原则 | 说明 | 实现 |
|---|---|---|
| **多层防御可视化** | 每层防御状态一目了然 | 四层颜色条（绿/黄/红） |
| **热力排序** | 风险最高的排最前 | 持仓按风险分排序 |
| **可操作告警** | 看到风险→立即行动 | 直接在风控中心暂停策略/调整止损 |
| **角色差异化** | 操盘手全功能，个人投资者简化 | 5 Tab vs 2 Tab |


**止损进度条**：0%→止损线。颜色从绿→黄→橙→红。

**风险排序算法**：距止损<1%加50分 + 审计/公告风险各加40分 + 亏损加20分。

## 5. 操盘手 vs 个人投资者

| Tab | 操盘手 | 个人投资者 |
|---|---|---|
| 风控总览 | ✅ 四层防御+KPI+告警 | ✅ 简化：熔断器+风险持仓数 |
| 持仓风险 | ✅ 全部持仓+调整止损 | ✅ 仅我的持仓+只读 |
| 策略风险 | ✅ 全部策略+暂停/恢复 | ❌ 不展示 |
| 市场风险 | ✅ 完整风向+板块 | ❌ 不展示 |
| 事件审计 | ✅ 完整时间线 | 折叠(仅显示告警数) |

## 6. AC

| ID | AC |
|---|---|
| AC-1 | 熔断器状态实时展示（正常/触发/半开） |

| AC-3 | 策略风险展示全部策略状态+暂停原因 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 风控中心：规则分全局/租户/账户，RiskVerdict 按账户和上下文归档。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
