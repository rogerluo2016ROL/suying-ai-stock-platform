## 1. 页面定位

信号扫描 = **可操作验证工作台**，不是 1.3 的只读看板。操盘手在此 Tab 完成板块锁定筛选 → 信号甄别 → Kronos 预测交叉验证 → 逐条确认/降级/排除。

| 维度 | 1.3 信号总览（AI智能看板） | 2.3 信号扫描（开盘决策） |
|---|---|---|
| **性质** | 只读浏览 | **可操作验证工作台** |
| **主视图** | 信号矩阵（色块矩阵） | **验证列表（表格行 + 操作按钮）** |
| **范围** | 全市场信号矩阵 | **锁定板块内**的信号 + 候选池已有标的 |
| **操作** | 点击跳转诊断 | **筛选→Kronos预测验证→逐条确认→加入候选池** |
| **上下文** | 无 | **接收竞价分析的板块锁定** |
| **输出** | 无 | **确认信号→写入候选池** |
| **设计哲学** | BROWSING（浏览发现） | DECIDING（验证决策） |

操盘手核心流程：

| 顺序 | 操作 | 对应面板 |
|---|---|---|
| 步骤1 | 查看锁定板块的信号列表 | VerificationList（由竞价分析板块锁定 → 自动筛选） |
| 步骤2 | 筛选信号类型 | FilterTabs ([全部] [仅买入] [仅自选]) |
| 步骤3 | 排序切换 | SortSelector (信号评分▼ / 一致性 / 风险) |
| 步骤4 | 逐条验证：信号+Kronos预测+风险 | VerificationRow（行内直接查看预测方向、一致性标记、风险标签） |
| 步骤5 | 点击行选中 → 右侧深度分析 | RightColumn（六维评分 + Kronos预测 + 风险检查 + 决策分类） |
| 步骤6 | 逐条确认/降级/排除 | ActionButtons（每行 3 按钮，推荐按钮高亮） |
| 步骤7 | 批量处理 + 一键推送 | BatchActions + PushButton |

## 3. 核心数据结构

### 3.1 VerificationRow

```typescript
/**
 * 验证列表中每一行的数据。
 * 聚合了信号、Kronos 预测、风险检查的摘要信息。
 */
interface VerificationRow {
  /** 股票代码 */
  code: string
  /** 股票简称 */
  name: string

  // ---- 信号 ----
  /** 信号级别 */
  signalLevel: SignalLevel          // STRONG_BUY | BUY | HOLD | REDUCE | SELL
  /** 信号评分 0-100 */
  signalScore: number
  /** 信号标签 */
  signalLabel: string               // "强买" | "买入" | "持有" | "减仓" | "卖出"

  // ---- Kronos 预测 ----
  /** 预测方向 */
  predDirection: 'up' | 'down' | 'flat'
  /** 预测涨跌幅百分比 (e.g. 8.2 表示 +8.2%) */
  predChgPct: number
  /** 预测目标价 */
  predTargetPrice: number
  /** 预测时间窗口 (日) */
  predDays: number                  // 5 | 10 | 20 | 30
  /** 预测置信度 0-100 */
  predConfidence: number

  // ---- 一致性 ----
  /** 信号-Kronos 方向一致性 */
  consistency: ConsistencyResult

  // ---- 风险 ----
  /** 风险标签列表 */
  riskTags: RiskTag[]
  /** 是否通过全部风险检查 */
  riskPassed: boolean

  // ---- 决策 ----
  /** 当前决策状态 */
  decision: DecisionType

  // ---- 六维评分（选中后加载详情） ----
  components?: {
    kronos: number
    technical: number
    fundFlow: number
    fundamental: number
    eventRisk: number
    marketAdapt: number
  }

  /** 当前最新价 */
  price?: number
  /** 涨跌幅 */
  changePct?: number
  /** 所在板块 */
  sector?: string
  /** 是否自选 */
  inWatchlist: boolean
}
```

## 4. 推荐按钮高亮逻辑

每行 3 个操作按钮，系统根据信号 + Kronos 预测 + 风险综合判断推荐哪个按钮，该按钮高亮（filled color），其余按钮为 outlined。

### 4.1 推荐规则

```typescript
/**
 * 判断某只股票当前推荐的默认操作。
 *
 * 优先级: 风险检查 > 一致性判断 > 信号级别
 */
function getRecommendedAction(row: VerificationRow): DecisionType {
  const { signalLevel, consistency, riskPassed, riskTags } = row

  // ---- 第1优先级: 风险检查 ----
  if (!riskPassed) {
    // 有任何风险未通过 → 推荐排除
    return 'excluded'
  }

  // 止损警告 → 推荐降级
  if (riskTags.some(t => t.type === 'stopLoss')) {
    return 'downgraded'
  }

  // ---- 第2优先级: 一致性判断 ----
  if (consistency.consensusType === 'conflict') {
    // 信号-Kronos 方向相悖 → 推荐降级（暂缓确认）
    return 'downgraded'
  }

  if (consistency.consensusType === 'neutral') {
    // 中性 → 推荐降级（观望）
    return 'downgraded'
  }

  // ---- 第3优先级: 信号级别 ----
  if (consistency.consensusType === 'confirmed') {
    // 双确认 → 按信号级别区分
    if (signalLevel === 'STRONG_BUY' || signalLevel === 'BUY') {
      return 'confirmed'
    }
    if (signalLevel === 'SELL' || signalLevel === 'REDUCE') {
      return 'downgraded'             // 双确认但信号为卖出 → 降级
    }
  }

  // 默认: 降级（需要人工判断）
  return 'downgraded'
}

/**
 * 按钮视觉映射
 */
const BUTTON_STYLE: Record<DecisionType, {
  label: string
  icon: string
  bg: string
  color: string
  border: string
}> = {
  confirmed: {
    label: '✅ 确认→候选池',

    color: 'var(--down)',
    border: '1px solid var(--down)'
  },
  downgraded: {
    label: '⬇ 降低优先级',
    icon: 'ArrowDown',
    bg: 'var(--warn-bg)',
    color: 'var(--warn)',
    border: '1px solid var(--warn)'
  },
  excluded: {
    label: '❌ 排除',
    icon: 'CloseCircle',
    bg: 'var(--up-bg)',
    color: 'var(--up)',
    border: '1px solid var(--up)'
  },
  pending: {
    label: '—',
    icon: '',
    bg: 'transparent',
    color: 'var(--muted)',
    border: '1px solid var(--border)'
  }
}

/** 推荐按钮 = filled (背景着色的 primary 按钮) */
const RECOMMENDED_CLASS = 'btn-recommended'

/** 非推荐按钮 = outlined (边框镂空) */
const NORMAL_CLASS = 'btn-outlined'
```

## 5. 数据流

```

│   ├── ② 并行获取 Kronos 预测

│   ├── ③ 计算一致性
```

### 5.1 computeConsistency 算法

```typescript
/**
 * 计算信号级别与 Kronos 预测方向的一致性。
 *
 * 映射规则:
 *   - 信号 → 方向: STRONG_BUY/BUY → 'buy'
 *                  REDUCE/SELL → 'sell'
 *                  HOLD → 'hold'
 *   - Kronos → 方向: up/down/flat (直接使用)
 *
 * 判断规则:
 *   - Kronos flat (震荡) → 中性
 *   - 信号 hold → 中性
 *   - 置信度 < 50 → 中性
 *   - |predictedChgPct| < 3 → 中性
 *   - 信号 buy + Kronos up → 双确认
 *   - 信号 sell + Kronos down → 双确认
 *   - 信号 buy + Kronos down → 相悖
 *   - 信号 sell + Kronos up → 相悖
 */
function computeConsistency(
  signalLevel: SignalLevel,
  kronosPrediction: { direction: 'up' | 'down' | 'flat'; predictedChgPct: number; confidence: number }
): ConsistencyResult {
  const signalDirection =
    signalLevel === 'STRONG_BUY' || signalLevel === 'BUY' ? 'buy' :
    signalLevel === 'REDUCE' || signalLevel === 'SELL' ? 'sell' : 'hold'

  const { direction: kronosDirection, predictedChgPct, confidence } = kronosPrediction

  // 边界: Kronos 震荡
  if (kronosDirection === 'flat') {
    return createNeutral('Kronos预测震荡区间，信号方向待观察')
  }
  // 边界: 信号持有
  if (signalDirection === 'hold') {
    return createNeutral('信号为持有，无明确方向')
  }
  // 边界: 置信度低
  if (confidence < 50) {
    return createNeutral(`Kronos预测置信度较低(${confidence}%)`)
  }
  // 边界: 幅度太小
  if (Math.abs(predictedChgPct) < 3) {
    return createNeutral(`Kronos预测幅度太小(${predictedChgPct.toFixed(1)}%)`)
  }

  // 核心判断
  const isConsistent =
    (signalDirection === 'buy' && kronosDirection === 'up') ||
    (signalDirection === 'sell' && kronosDirection === 'down')

  if (isConsistent) {
    return {
      consensusType: 'confirmed',
      label: '✅双确认',
      color: '#2ec27e',
      bg: 'rgba(46,194,126,0.12)',
      border: '#2ec27e',
      description: '信号与Kronos预测方向一致',
      signalDirection,
      kronosDirection,
      recommendConfirm: true
    }
  }

  return {
    consensusType: 'conflict',
    label: '⚠️相悖',
    color: '#ff4d4f',
    bg: 'rgba(255,77,79,0.12)',
    border: '#ff4d4f',
    description: `信号建议${signalDirection === 'buy' ? '买入' : '卖出'}，但Kronos预测${kronosDirection === 'up' ? '上涨' : '下跌'}，方向相悖`,
    signalDirection,
    kronosDirection,
    recommendConfirm: false
  }
}

function createNeutral(description: string): ConsistencyResult {
  return {
    consensusType: 'neutral',
    label: '➖中性',
    color: '#5e6a7d',
    bg: '#161c28',
    border: '#1f2733',
    description,
    signalDirection: 'hold',
    kronosDirection: 'flat',
    recommendConfirm: false
  }
}
```
