## 1. 页面定位

持仓风险是风控中心**第二个 SubTab**（SubTab key: `position`）。按综合风险评分降序排列持仓，用止损进度条可视化危险程度，提供止损/减仓/一键平仓操作。

## 3. 核心数据结构

```typescript
interface PositionRiskData {
  positions: PositionRisk[]
  canOperate: boolean           // 操盘手=true, 投资者=false
}

interface PositionRisk {
  code: string
  name: string
  quantity: number
  avgCost: number
  currentPrice: number
  marketValue: number
  pnl: number
  pnlPct: number
  exposurePct: number
  stopLossPrice: number | null
  distanceToStopPct: number | null
  riskTags: RiskTag[]
  riskScore: number
}

interface RiskTag {
  type: 'stop_loss_close' | 'stop_loss_critical'
       | 'audit_opinion' | 'announcement_risk' | 'st_delist_risk'
  level: 'danger' | 'warning' | 'info'
  label: string
}

type SortField = 'riskScore' | 'distanceToStop' | 'pnlPct'
type SortDir = 'asc' | 'desc'
```

## 4. 止损进度条组件

```typescript
function StopLossBar({ pnlPct, stopLossPct, distanceToStopPct }: {
  pnlPct: number
  stopLossPct: number
  distanceToStopPct: number | null
}) {
  const ratio = distanceToStopPct !== null
    ? Math.max(0, 100 - (distanceToStopPct / stopLossPct) * 100)
    : 0
  const color = distanceToStopPct !== null
    ? (distanceToStopPct < 1 ? 'var(--up)' :
       distanceToStopPct < 3 ? 'var(--warn)' :
       distanceToStopPct < 5 ? '#73d13d' : 'var(--down)')
    : 'var(--down)'

  return (
    <div style={{ position:'relative', flex:1, minWidth:60, height:6,
                  borderRadius:3, background:'var(--surface-2)', overflow:'hidden' }}>
      <div style={{
        position:'absolute', left:0, top:0, height:'100%',
        width:`${Math.min(ratio, 100)}%`, borderRadius:3,
        background:`linear-gradient(90deg, var(--down), ${color})`,
        transition:'width 0.4s ease'
      }} />
      <div style={{
        position:'absolute', top:-3, left:'97%',
        width:2, height:12, background:'var(--fg)', borderRadius:1
      }} />
    </div>
  )
}
```

## 5. 交互规范

### 5.1 行背景色

| 风险分 | 背景色 |
|---|---|
| ≥ 70 | `var(--up-bg)` 红色 |
| ≥ 40 | `var(--warn-bg)` 橙色 |
| < 40 | 默认透明 |

### 5.2 止损操作

- 点击 [⏹止损] → Modal 确认 "确认对 000858 五粮液执行止损？将以市价 ¥148.30 卖出。"
- 点击 [减仓] → Modal 输入减仓数量，显示剩余仓位
- 点击 [一键平仓风险标的] → Modal 列出所有红色标签持仓，批量确认

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 风控中心：规则分全局/租户/账户，RiskVerdict 按账户和上下文归档。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
