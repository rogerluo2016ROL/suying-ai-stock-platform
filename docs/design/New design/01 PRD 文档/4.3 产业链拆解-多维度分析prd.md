# PRD — 产业链·多维度分析 (Phase 3)

- **Date**: 2026-06-28 | **Owner**: product-lead | **Status**: Draft
- **上游**: `4.0 产业链拆解prd.md` Phase 2 产业链解构 → 候选公司

## 1. 定位

多维度分析是产业链研究工坊的**决策终点站**。承上启下：

```
板块2(产业链解构) → 候选公司(12只) → 三大分析 → 决策输出 → 候选池/自选/报告/开盘决策
```

| 维度 | 说明 |
|---|---|
| **输入** | 板块2 下钻筛选的候选公司列表（默认 12 只，含公司代码/行业位置/市值/PE） |
| **处理** | 护城河+不可替代性评分 → 卡脖子分级 → 商业化进程(三重共振) |
| **输出** | 综合评分排序 + 共振标签 + [加入候选池]/[加入自选]/[导出报告]/[关联开盘决策] |

目标用户：

| 角色 | 需求 | 决策动作 |
|---|---|---|
| **操盘手** | 锁定最受益环节 + 确认龙头 + 判断介入时机 | 加入候选池 + 关联开盘决策 |
| **个人投资者** | 看评分排序 + 看"推荐关注"标签 | 加入自选 |

## 2. 分析一：护城河 + 不可替代性

### 2.1 五维度评分模型

| 维度 | 权重 | 子指标 | 数据来源 |
|---|---|---|---|
| 🏰 护城河 | **30%** | 技术壁垒(0.3) + 市场份额(0.25) + 专利数量(0.2) + 客户粘性(0.15) + 品牌溢价(0.1) | `fina_indicator` + 券商研报 |
| 📈 增长力 | **20%** | 营收增速(0.4) + 净利润增速(0.3) + ROE趋势(0.3) | `fina_indicator` |
| 💰 利润率 | **15%** | 毛利率(0.4) + 净利率(0.35) + 经营现金流/营收(0.25) | `fina_indicator` |
| ⭐ 不可替代性 | **25%** | 技术独特性(0.4) + 客户切换成本(0.3) + 供应链地位(0.3) | LLM评估 + 行业研报 |
| 🔄 国产替代 | **10%** | 国产化进度(0.5) + 政策扶持强度(0.3) + 进口替代空间(0.2) | 政策文件 + 行业分析 |

**综合评分公式**：

```
综合分 = 护城河×0.30 + 增长力×0.20 + 利润率×0.15 + 不可替代性×0.25 + 国产替代×0.10
```

所有子维度归一化到 0-100 分，加权求和。

### 2.2 展示形式

- **表格视图**：每行一家公司，5 个维度各列 + 综合分，总分高亮（≥85 绿，≥70 蓝，<70 灰）
- **星标可视化**：护城河/不可替代性 用 ★★★★★ 表示（每 20 分一星）
- **雷达图可选**：切换到雷达图对比模式下，5 维度雷达叠加显示

## 3. 分析二：卡脖子分级

### 3.1 三级分类标准

| 级别 | 定义 | 判定依据 | 示例 |
|---|---|---|---|
| 🔴 **一级卡脖子** | 核心技术完全被海外垄断，国内无替代方案或替代品性能差距极大 | 国产化率 < 10%，技术差距 ≥ 2 代 | 高端光刻机(ASML垄断)、5nm以下EDA |
| 🟡 **二级卡脖子** | 核心技术受制于人，但国内已有部分突破或替代方案在研 | 国产化率 10%-50%，技术差距 1-2 代 | 高端光刻胶、先进刻蚀机 |
| 🟢 **非卡脖子** | 国内技术成熟，或本身不涉及核心技术瓶颈 | 国产化率 > 50%，技术自主可控 | 封装测试、成熟制程设备 |

### 3.2 分级流程

```
候选公司 → 匹配产业链节点 → 查询节点卡脖子级别(预置映射表) → 展示分类
```

- 卡脖子映射表由「产业-重点方向-卡脖子清单」md 文件预维护
- LLM 辅助判断边缘案例（二级/非边界模糊时触发）

### 3.3 展示形式

- **三分区面板**：左侧非卡脖子 / 中间二级 / 右侧一级，公司卡片拖放
- **一级卡脖子**：红色高亮区域，展示对应上市公司 + 卡脖子根源 + 国产替代进度
- 点击展开详情：技术差距说明 / 国内替代企业 / 突破时间预估

## 4. 分析三：商业化进程（三重共振）

### 4.1 三重共振模型

> 产品开始量产，才是爆发的源动力。

| 维度 | 评分范围 | 数据来源 | 说明 |
|---|---|---|---|
| 🏭 **产业周期** | 导入期=0.2 / 成长期=0.8 / 成熟期=0.5 / 衰退期=0.1 | 行业研报 + 收入增速 | 成长期最优 |
| 📋 **政策强度** | 0-1 (归一化) | 政策文件评估(文件数量×金额×频率) | LLM评估 +
Tushare概念政策关联 |
| 💵 **业绩兑现** | 已兑现=1.0 / 部分兑现=0.5 / 亏损/未兑现=0.1 | `fina_indicator` (营收增速/净利润) | 财报数据驱动 |

### 4.2 共振公式

```
共振分 = 产业周期得分 × 政策强度得分 × 业绩兑现得分
```

| 共振分区间 | 标签 | 含义 |
|---|---|---|
| ≥ 0.40 | ✅ **三重共振** | 产业/政策/业绩三者同时向上，最优介入时机 |
| 0.15 ~ 0.40 | ⚠️ **等待拐点** | 尚缺一到两个条件，需继续跟踪 |
| < 0.15 | ❌ **暂不共振** | 三者至少两个不满足，暂不宜介入 |

### 4.3 展示形式

- **表格行**：每家公司 产业周期 / 政策支持 / 业绩兑现 / 共振分 / 共振标签
- 共振标签用 ✅ / ⚠️ / ❌ 大图标
- 💡 底部提示：「产品开始量产，才是爆发的源动力」

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 产业链拆解：公共产业链图谱与用户私有研究笔记分离，证据型标的进入候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共图谱/政策 + 私有研究标注。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接交易，只输出 Candidate 证据。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
