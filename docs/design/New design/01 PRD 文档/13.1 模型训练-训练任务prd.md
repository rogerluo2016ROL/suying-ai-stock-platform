# PRD — 模型训练·训练任务

- **Date**: 2026-06-27 | **Status**: Draft | **角色**: Admin only

## 1. 定位

训练任务是模型训练的**默认主视图**。展示训练任务全生命周期管理：创建任务 → 启停监控 → 查看指标。

| 维度 | 管理员 (ML工程师) |
|---|---|
| **核心问题** | 哪些任务在跑？效果怎么样？怎么创建新任务？ |
| **操作** | 创建/启动/停止/重跑/删除 |

> **角色映射（收口决策）**：管理员（ML 工程师，含系统管理员/模型管理员）→ RBAC `admin`；操盘手 → `internal_analyst`；个人投资者 → `user`；`external_analyst` → 外部只读。权限与数据过滤由服务端按 JWT 角色执行，前端禁止传 `X-User-Role` 等身份头。

## 2. 核心功能

- 任务列表按状态分组展示：运行中 → 排队中 → 已完成 → 失败 → 草稿
- 任务卡片含：状态圆点、任务名、模型类型标签、超参数 chips、指标条、进度条、操作按钮
- 筛选栏：模型类型/状态/搜索
- 创建任务 Modal：选择模型类型(Kronos/LightGBM/CatBoost)、数据集、超参数、时间窗口
- 按状态差异化操作：运行中 → 停止；已完成 → 重跑/注册模型；失败 → 查看日志/重跑

## 3. AC

| ID | AC |
|---|---|
| AC-1 | 任务列表按状态分组正确排序 |
| AC-2 | 运行中任务显示实时进度条+指标 |
| AC-3 | 创建任务表单根据模型类型动态渲染超参数 |
| AC-4 | 非 admin 返回 403 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 模型训练：仅模型管理员/系统管理员可操作，训练资源、实验和产物要隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 管理域数据。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不触达券商。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
