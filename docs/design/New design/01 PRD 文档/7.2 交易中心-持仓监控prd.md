# PRD — 交易中心·持仓监控

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **Estimated effort tier**: Medium（持仓列表 + 排序 + 风险标签 + 批量操作 + 止损/减仓）

## 1. Background

持仓监控是交易中心的**仓位风险仪表盘**。操盘手在此总览全部持仓的盈亏、仓位占比与距止损距离，并执行止损、加仓、减仓、一键清仓等批量操作。

当前痛点：
1. 缺少持仓列表 UI——操盘手无法一览仓位全貌
2. 缺少风险标签（距止损距离）——容易错过止损时机
3. 无一键清仓/批量止损——紧急情况下操作效率低
4. 个人投资者无只读持仓视图

## 2. Goal & Non-Goals

**目标**：
- 构建持仓列表：代码/名称/持仓/现价/成本/浮盈%/仓位%/距止损/风险标签/操作
- 多维度排序（盈亏%/仓位%/市值）
- 风险行高亮（红/橙背景）
- 一键清仓 + 批量止损

**Non-Goals**：
- 不做持仓历史回溯
- 不做持仓成本曲线
- 不做担保品/融资持仓区分

## 3. User Stories

| ID | As a | I want to | So that |
|---|---|---|---|
| US-1 | 操盘手 | 看到所有持仓的浮盈/仓位%/距止损距离 | 快速识别风险持仓 |
| US-2 | 操盘手 | 风险行（距止损<3%）有红色/橙色高亮 | 立即注意到需要处理的持仓 |
| US-3 | 操盘手 | 点击[一键清仓]全部卖出 | 紧急情况下快速离场 |
| US-4 | 操盘手 | 点击[批量止损]对风险持仓批量挂止损单 | 保护剩余利润 |
| US-5 | 操盘手 | 单只持仓可操作[止损][加仓][减仓] | 灵活调整仓位 |
| US-6 | 个人投资者 | 看到"我的持仓"只读视图 | 了解当前持仓状态 |

## 4. Acceptance Criteria

| ID | Priority | AC | Verification method |
|---|---|---|---|
| AC-1 | P0 | 持仓列表正确显示：代码/名称/持仓量/现价/成本价/浮盈金额+%/仓位%/距止损/风险标签 | 对照 API 返回数据验证 |
| AC-2 | P0 | 风险标签正确：距离 ≤1% = danger(红), 1-3% = warning(橙), >3% = safe | 构造不同止损距离数据验证 |
| AC-3 | P0 | 排序功能正常：点击表头排序，支持盈亏%/仓位%/市值升降序 | 点击切换验证 |
| AC-4 | P0 | [一键清仓]弹出确认弹窗"将以市价卖出全部 N 只持仓，预计回收约 ¥xxx" | 点击验证弹窗文案 |
| AC-5 | P1 | [批量止损]仅对风险标签 danger+warning 的持仓操作 | 构造含不同风险等级的持仓数据验证 |
| AC-6 | P1 | 个人投资者视图：只读持仓列表，无[止损][加仓][减仓][一键清仓]按钮 | 切换角色验证 |

## 6. Technical Constraints

- 数据来源：`GET /api/v1/trade/position`，30s 轮询
- 批量操作需逐个提交，前端展示每笔结果
- 止损单为限价单（止损价 = 当前价 × (1 - 止损%)），默认止损比例 5%

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 交易中心：账户、订单、持仓、成交全部按 tenant/account/user 隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 强私有交易数据。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | paper/QMT/多券商统一 BrokerAdapter。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
