# PRD — 交易信号

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

交易信号是**下单前的最终验证页**。一只股票在进入候选池、通过竞价分析、被信号扫描确认之后，操盘手在此做最后四个检查。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 信号有多强？可信吗？资金在跟吗？有雷吗？ | 这只股票能不能买？ |
| **输入来源** | 候选池带入 / 自选带入 / 搜索 / 任意页面跳转 | 自选带入 / 搜索 |
| **决策输出** | [加入候选池] / [跳转交易中心下单] / [设预警] | [加入自选] / [查看诊断] |

## 2. 与信号扫描(2.3)的分工

| | 信号扫描 | 交易信号 |
|---|---|---|
| **场景** | 多只股票快速对比验证 | 一只股票全面深度分析 |
| **问题** | "这三只里谁信号最强？" | "这只到底能不能买？" |
| **输出** | 确认/降级/排除 → 候选池 | 六维评分 → 资金流 → 趋势 → 审计 → 下单决策 |

## 3. 二级功能

```
📡 交易信号

├── 📊 信号总览     6.1  默认视图。六维评分+雷达图+资金流+操作建议
├── 📈 信号历史     6.2  30日信号评分变化趋势+同级别命中率
├── ⚠️ 风险扫描     6.3  审计/公告/ST/业绩 四项检查→一票否决
└── 🔗 快速操作     6.4  常驻底部栏：[候选池][下单][诊断][预警]
```

## 5. 操盘手 vs 个人投资者

| 子模块 | 操盘手 | 个人投资者 |
|---|---|---|
| 信号总览 | 完整六维雷达图+资金流向详情 | 综合评分+一句话操作建议 |
| 信号历史 | 30日趋势+命中率 | 折叠(可选展开) |
| 风险扫描 | 四项检查完整 | 简化: "风险: ✅低/⚠️中/🔴高" |
| 快速操作 | [候选池][下单][诊断][预警] | [自选][诊断] |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 交易信号：公共信号规则与用户私有订阅、处理状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共信号 + 私有已读/订阅/处置。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 信号只作为订单依据之一。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
