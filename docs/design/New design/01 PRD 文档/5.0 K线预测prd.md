# PRD — K线预测

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

K线预测 = **预测结果消费 + 可信度评估 + 择时决策**。不训模型，只评估和使用预测。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 预测和信号一致吗？什么时候进场？这个预测可信吗？ | 这只股票会涨还是跌？现在能买吗？ |
| **决策** | 确认入场时机 → 比对多只候选 → 选择最优标的 | 看方向 → 看建议 → 决定买不买 |
| **输入** | 候选池带入 / 自选带入 / 搜索 | 自选带入 / 搜索 |

## 2. 二级功能

```
📈 K线预测

├── 📊 单股预测       ← 主视图。K线+预测路径+关键价位+信号标记+模型透明度
├── 📋 多股对比       ← 候选池3-5只横向对比：预测涨幅/置信度/信号一致性
├── 📈 准确率回测    ← 历史预测 vs 实际走势对比，方向正确率统计
├── ⭐ 快速带入       ← 顶部常驻栏：候选池/自选/最近看过 一键切换
└── 🔔 预测预警       ← 价格触及支撑/阻力/止损时提醒（可设多条）
```

### 功能优先级

| 功能 | 操盘手 | 个人投资者 | 优先级 |
|---|---|---|---|
| 单股预测 | ✅ 核心 | ✅ 核心 | P0 |
| 多股对比 | ✅ 核心（对比候选池） | — | P0 |
| 快速带入 | ✅ | ✅ | P0 |
| 准确率回测 | ✅ | 折叠 | P1 |
| 模型透明度 | ✅ | 折叠 | P1 |
| 预测预警 | ✅ | 1条（止损） | P2 |

## 3. 交互流程

### 操盘手典型流程

```
候选池勾选 4 只 → 点击[K线预测]
  ↓
进入多股对比视图:
  顶部: 4只股票的预测核心指标对比表
  底部: 叠加预测曲线
  排序: 按"信号一致性+预测涨幅"排序
  ↓
选出最优 1-2 只 → 点击进入单股预测
  ↓
单股预测视图:
  看K线+预测路径 → 判断趋势形态
  看支撑阻力 → 看当前价在什么位置
  看信号标记 → 确认信号触发时点
  看模型透明度 → 评估可信度
  看准确率回测 → 历史表现
  ↓
决策: [加入候选池(已有)] [设价格预警] [跳转交易中心]
```

### 个人投资者典型流程

```
自选跟踪中看到宁德+8.2% → 点击进入K线预测
  ↓
默认单股预测视图:
  看方向: "预测未来30天 ↑+12.5%"
  看建议: "可在支撑位196.50附近关注"
  看可信度: 预测方向正确率72%（折叠，可选展开）
  ↓
决策: [加入自选] [设止损预警]
```

```
设置:
  □ 价格跌破支撑位 196.50 → 提醒
  □ 价格突破阻力位 251.00 → 提醒

  → 智能看板顶部通知徽章
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | K线预测：公共 Kronos 预测能力与用户私有关注/对比任务分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共预测快照 + 私有预测任务。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 预测不可绕过风控直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
