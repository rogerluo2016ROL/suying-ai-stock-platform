## 3. 状态机

```
                     ┌───────────────────┐
                     │                   │
                     ▼                   │
  ┌─────────┐   [🚀 启动]   ┌─────────┐  │  [▶️ 恢复]
  │  draft  │ ────────────→ │ running │──┘
  │ (草稿)   │               │ (运行中) │
  └────┬─────┘               └────┬─────┘
       │                          │
       │ [✏️ 编辑]                │ [⏸️ 暂停] / [止损触发]
       │ (保持 draft)             │
       │                          ▼
       │                     ┌─────────┐
       │                     │ paused  │
       │                     │ (暂停)   │
       │                     └────┬────┘
       │                          │
       │ [🗑 删除]                │ [🏁 结算]
       │ (仅 draft)               │
       │                          │
       ▼                          ▼
  ┌─────────┐               ┌──────────┐
  │ (移除)   │               │  closed   │
  └─────────┘               │ (已归档)   │
                            │ 终态·不可逆│
                            └──────────┘

状态转换校验规则:
  draft → running  : stocks.length > 0 && totalPosition > 0 && riskCheck.passed
  draft → 删除      : 仅 draft 状态 + Popconfirm 二次确认
  draft → draft     : PUT 更新参数后保持 draft
  running → paused  : 暂停 executor (asyncio.Event.set), 保留持仓
  running → closed  : 平仓所有未平仓标的 + 结算收益 + 归档
  paused → running  : 恢复 executor (asyncio.Event.clear), 继续下单
  paused → closed   : 同 running→closed
  closed → (终态)   : 不可逆, 仅支持 [查看详情] / [导出报告]
```

### 4.1 API 端点清单

| 方法 | 端点 | 用途 | 调用方 |
|---|---|---|---|
| `GET` | `/api/v1/strategy` | 方案列表（支持 status 筛选 + 分页） | PlanList |
| `GET` | `/api/v1/strategy/{id}` | 方案详情 + 关联订单 | PlanDetail |
| `POST` | `/api/v1/strategy/from-picks` | 从候选池批量创建方案 | 候选池 → 方案管理 |
| `POST` | `/api/v1/strategy` | 手动新建方案 | PlanManager |
| `POST` | `/api/v1/strategy/{id}/start` | 启动自动交易 | PlanCard / ActionPanel |
| `POST` | `/api/v1/strategy/{id}/stop` | 暂停方案 | PlanCard / ActionPanel |
| `POST` | `/api/v1/strategy/{id}/settle` | 结算归档方案 | PlanCard / ActionPanel |
| `PUT` | `/api/v1/strategy/{id}` | 编辑方案参数 | PlanCard (draft) |
| `DELETE` | `/api/v1/strategy/{id}` | 删除 draft 方案 | PlanCard (draft) |
| `GET` | `/api/v1/strategy/{id}/report` | 结算报告 | SettlementReport |
| `GET` | `/api/v1/strategy/compare` | 两方案对比数据 | PlanCompare |

### 4.2 外部触发入口

| 来源 | 触发方式 | 携带数据 |
|---|---|---|
| 候选池 (2.4) | [生成方案] 按钮 → navigate | `?fromPicks=true&picksData=<encoded>` |
| 执行监控 (2.5) | 点击方案名 → navigate | `?planId=xxx` → 自动选中该方案详情 |
| 风控中心 (10.0) | 止损触发 → WebSocket 推送 | `{event: "risk_breach", planId: xxx, reason: "日亏损≥3%"}` |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 方案管理：Plan 是私有交易意图承载对象，可授权共享但默认仅本人可见。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 私有 Plan + 公共模型引用。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | Plan 启动前必须绑定账户/模式。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
