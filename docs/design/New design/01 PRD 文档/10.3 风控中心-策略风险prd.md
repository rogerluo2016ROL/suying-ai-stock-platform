- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `10.0 风控中心prd.md`

## 1. 定位

策略风险回答：**"哪个策略出问题了？需要暂停还是恢复？"** 展示全部策略的运行状态，对异常策略（暂停、日亏损过大）突出显示，提供直接的控制操作。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 哪个策略触发了风控？该暂停还是恢复？ | 不展示此 Tab |
| **操作** | 暂停/恢复策略、调整参数 | — |

## 3. 策略状态定义

| 状态 | 图标 | 说明 |
|---|---|---|
| 🟢 活跃 | 绿色脉动圆点 | 策略正常运行中 |
| 🟡 暂停 | 橙色静态圆点 | 触发风控规则自动暂停或手动暂停 |
| 🔴 停止 | 灰色圆点 | 策略已停止 |

## 4. 暂停原因

- **日亏损触发**：当日亏损达到策略设置的 daily_max_loss_pct
- **连续亏损触发**：连续 N 日亏损
- **手动暂停**：操盘手手动暂停
- **熔断级联**：因全局熔断触发所有策略暂停

## 5. 交互

- 暂停行高亮橙色背景
- 展开暂停原因详情（点击行或默认展开）
- [▶️ 恢复策略]：确认后恢复运行
- [⚙️ 调整参数]：跳转策略配置页 (8.2)

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 风控中心：规则分全局/租户/账户，RiskVerdict 按账户和上下文归档。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
