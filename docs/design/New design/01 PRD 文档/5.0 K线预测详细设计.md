### 2.2 置信区间带 (Band) 实现原理

ECharts stacked area 技巧: 两条 line series 用同一个 `stack` 名, 第一条设为透明, 第二条用 `upperBound - lowerBound` 差值, 着色区域恰好落在两条曲线之间。

```typescript
// lowerBound 保持原值, areaStyle 透明 → 只占位不显色
const lowerSeries = {
  type: 'line', name: 'band-lower',
  data: lowerBounds,                    // [190, 192, 195, ...]
  stack: 'confidence',
  lineStyle: { opacity: 0 },
  areaStyle: { opacity: 0 },
  symbol: 'none',
}

// upperBound 用差值, areaStyle 着色 → 可见区间 = [lower, upper]
const upperSeries = {
  type: 'line', name: 'band-upper',
  data: upperBounds.map((v, i) => v - lowerBounds[i]),  // [16, 16, 17, ...]
  stack: 'confidence',
  lineStyle: { opacity: 0 },
  areaStyle: { color: 'rgba(61,139,255,0.08)' },
  symbol: 'none',
}
```

### 3.1 TypeScript 接口

```typescript
// ── 预测 K 线数据点 ────────────────────────────────────
interface PredictionCandle {
  date: string                            // '2026-06-26'
  open: number
  close: number
  high: number
  low: number
  volume: number
  isPrediction: boolean                   // true → 预测区间 (虚线)
}

// ── 单股预测结果 (API: GET /prediction/{code}) ─────────
interface PredictionResult {
  tsCode: string                          // '300750.SZ'
  name: string                            // '宁德时代'
  currentPrice: number                    // 218.50
  targetPrice: number                     // 242.30
  predictedHigh: number                   // 251.00
  predictedLow: number                    // 196.50
  changePct: number                       // +12.5 (百分比)
  confidence: number                      // 0-100
  supportLevel: number                    // 196.50
  resistanceLevel: number                 // 251.00
  stopLossLevel: number                   // 185.00
  signalConsistency: 'consistent' | 'contradict' | 'weak'
  candles: PredictionCandle[]             // 60 历史 + 30 预测
  confidenceUpper: number[]               // 置信上界 (与 candles 同长)
  confidenceLower: number[]               // 置信下界
  signals: PredictionSignal[]             // 信号标记
  factorContribution: FactorContribution
  modelInfo: ModelInfo
  historicalAccuracy: number              // 近30次方向正确率
  accuracyRecords: AccuracyRecord[]
}

// ── 多股对比项 (API: POST /prediction/batch) ───────────
interface CompareItem {
  tsCode: string
  name: string
  currentPrice: number
  targetPrice: number
  changePct: number
  confidence: number
  signalConsistency: 'consistent' | 'contradict' | 'weak'
  accuracy: number                        // 方向正确率
  rating: number                          // 1-5 星
  predictionCurve: { day: number; value: number }[]   // 归一化涨跌幅%
  color?: string                          // ECharts 色号
}

// ── 回测记录 (API: GET /prediction/{code}/backtest) ───
interface BacktestRecord {
  date: string                            // 预测日期
  predictedPath: { date: string; price: number }[]
  actualPath: { date: string; price: number }[]
  directionCorrect: boolean
  avgError: number                        // 平均误差 %
  maxError: number                        // 最大误差 %
}

// ── 快速选择 Chip ──────────────────────────────────────
interface QuickSelectChip {
  tsCode: string
  name: string
  changePct?: number                      // 自选 Chip 涨跌幅
  score?: number                          // 候选池 Chip 评分
  source: 'watchlist' | 'candidate' | 'recent'
}

// ── 因子贡献 ───────────────────────────────────────────
interface FactorContribution {
  technical: number                       // 技术面 % (e.g. 45)
  fundFlow: number                        // 资金面 %
  fundamental: number                     // 基本面 %
  sentiment: number                       // 情绪面 %
}

// ── 模型信息 ───────────────────────────────────────────
interface ModelInfo {
  version: string                         // 'Kronos V2.3'
  trainedAt: string                       // '2026-06-20'
  architecture?: string                   // 'Transformer + Multi-Head Attention'
  featureCount?: number                   // 128
}

// ── 预测信号 ───────────────────────────────────────────
interface PredictionSignal {
  date: string
  type: 'buy' | 'sell' | 'inflection'
  price: number
  label: string                           // '金叉' | '放量突破'
}

// ── 准确率记录 ─────────────────────────────────────────
interface AccuracyRecord {
  date: string
  accuracy: number
  predictedDirection: 'up' | 'down'
  actualDirection: 'up' | 'down'
  error: number
}

// ── 页面状态 ───────────────────────────────────────────
interface PredictionPageState {
  activeTab: 'single' | 'compare' | 'backtest'
  activeStock: string | null              // 当前选中股票代码

  // 快速选择
  watchlistChips: QuickSelectChip[]

  recentChips: QuickSelectChip[]

  prediction: PredictionResult | null
  predictionCache: Map<string, PredictionResult>

  // 多股对比
  compareItems: CompareItem[]

  // 回测
  backtestRecords: BacktestRecord[]

  // UI
  isLoading: boolean
  error: string | null
  showFactorDetail: boolean               // 因子贡献折叠
  showModelInfo: boolean                  // 模型信息折叠
  showAccuracyDetail: boolean             // 准确率折叠
}
```

## 4. 数据流

### 4.1 页面初始化

```
PredictionPage mount
│
├── GET /api/v1/watchlist?limit=10
│   └── → watchlistChips[] 渲染自选行
│
├── GET /api/v1/candidate-pool/quick-entries
│   └── → candidateChips[] 渲染候选池行
│
├── localStorage.getItem('recent_prediction_stocks')
│   └── → recentChips[] 渲染最近行 (FIFO, max 10)
│
└── URL params ?code=300750
    └── 自动触发单股预测 (→ 4.2)
```

### 4.2 单股预测

```
GET /api/v1/prediction/{code}?days=30
│
├── Response: PredictionResult
│   ├── 写入 predictionCache
│   ├── 渲染 KLineChart + DetailPanel
│   ├── 追加到 localStorage recent 列表 (FIFO)
│   └── 更新 URL: ?code={code}
│
└── Error: 显示错误提示, 不清空已有数据
```

### 4.3 多股对比

```
POST /api/v1/prediction/batch
Request: { codes: ["300750.SZ", "688981.SH", "603986.SH", "002371.SZ"], days: 30 }

Response: CompareItem[]
│
├── 渲染 CompareTable (按 rating 降序)
└── 渲染 OverlayChart (4 色曲线叠加)
```

### 4.4 准确率回测

```
GET /api/v1/prediction/{code}/backtest?count=30

Response: BacktestRecord[]
│
├── 渲染 BacktestChart (最新一次预测 vs 实际)
└── 渲染 AccuracyStats (方向正确率/平均误差/连对连错)
```

### 4.5 快速带入交互

```
QuickSelectChip click
│
├── setActiveStock(chip.tsCode)
├── setActiveTab('single')
├── 检查 predictionCache
│   ├── Hit → 直接渲染缓存
│   └── Miss → 触发 GET /prediction/{code}
└── 记录埋点: prediction_from_{chip.source}
```

### 4.6 搜索框

```
SearchInput Enter
│
├── 输入支持: 代码 (300750) / 拼音缩写 (NDSD) / 中文 (宁德)
├── GET /api/v1/stocks/search?q={keyword}
├── 下拉建议列表 (最多 8 条)
└── 选中后 → 同 4.5
```

## 5. 快速带入数据来源

| 来源 | 数据接口 | 缓存策略 | 渲染格式 |
|------|---------|---------|---------|
| ⭐ 自选股票 | `GET /api/v1/watchlist` | 页面加载时请求, 60s poll | `宁德时代 300750 +8.2%` (彩色) |
| 🎯 候选池 | `GET /api/v1/candidate-pool/quick-entries` | 候选池变更时清理缓存 | `宁德时代 300750 90分` (评分 Badge) |
| 📋 最近查看 | `localStorage key: recent_prediction_stocks` | FIFO, max 10 条 | `宁德时代 300750` (无额外数据) |

### 最近查看 实现细节

```typescript
const RECENT_KEY = 'recent_prediction_stocks'
const MAX_RECENT = 10

function addToRecent(chip: QuickSelectChip): void {
  const list: QuickSelectChip[] = JSON.parse(localStorage.getItem(RECENT_KEY) || '[]')
  const filtered = list.filter(c => c.tsCode !== chip.tsCode)
  filtered.unshift(chip)
  if (filtered.length > MAX_RECENT) filtered.pop()
  localStorage.setItem(RECENT_KEY, JSON.stringify(filtered))
}
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | K线预测：公共 Kronos 预测能力与用户私有关注/对比任务分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共预测快照 + 私有预测任务。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 预测不可绕过风控直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
