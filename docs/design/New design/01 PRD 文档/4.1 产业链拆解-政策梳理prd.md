# PRD — 产业链拆解·政策梳理

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

政策梳理是产业链拆解研究工坊的**入口板块**（Phase 1），核心链路为：

```
政策输入 → LLM深度解读 → 核心方向提取 → 重点方向→行业映射
```

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 政策力度够不够？利好哪些产业环节？对应哪些上市公司？ | 当前热门题材有哪些？有什么股票可以关注？ |
| **工作流** | 输入政策原文→LLM解读+人工修正→行业映射→进入产业链解构 | 从预制热门题材中选择→直接看映射结果→加入自选 |
| **决策产出** | 锁定政策受益方向 + 确认映射行业和概念 + 推进到下一板块 | 了解题材对应股票列表 |
| **默认入口** | 粘贴文章/URL/PDF/政策库 | 热门题材标签选择 |

**与产业链拆解总体PRD的关系**：本PRD是 `5.0 产业链拆解prd.md` 中"板块1：政策梳理"的细化展开。

## 3. 四种输入方式详解

### 3.1 粘贴文章

- 用户直接粘贴政策全文/摘要/新闻
- 字数限制: 5000 字（超出部分截断并提示）
- 支持 Markdown 格式（保留标题层级）
- [提交] 按钮触发 LLM 解读
- 支持 [清空] 重置输入

### 3.2 输入URL

- 用户输入政策原文 URL
- 后端抓取网页内容（需处理各类网站编码）
- 抓取后先展示提取的纯文本摘要（300 字预览），确认后提交 LLM
- 常见政策来源: 国务院/发改委/工信部/证监会官网
- 白名单域名优先（gov.cn / cs.com.cn / stcn.com）

### 3.3 上传PDF

- 支持 PDF 文件上传（≤10MB）
- 后端解析 PDF 提取文本
- 解析后展示纯文本预览，确认后提交 LLM
- 支持批量上传（最多 3 个 PDF，视为同一主题合并解读）

### 3.4 从政策库选择

- 预置政策库: 从 `policy_law` 表加载近期政策法规
- 可搜索/筛选: 按关键词、发布日期、发文机构
- 显示列表: 标题 + 发文机构 + 日期 + [选择]
- 选择后自动填入内容区并触发解读

## 4. LLM解读结果编辑

### 4.1 可编辑字段

| 字段 | 编辑方式 | 默认值来源 |
|---|---|---|
| 核心方向 (多条) | 新增/删除/修改 方向名+描述 | LLM 提取 |
| 政策强度 (1-5星) | 星级选择器 或 手动输入 | LLM 评估 |
| 资金支持 | 文本框 | LLM 提取 |
| 时间窗口 | 文本框 + 日期范围选择器 | LLM 提取 |

### 4.2 编辑状态追踪

- 每个字段修改后标记 `已修正` 角标（区别于 LLM 原始输出）
- 支持 [还原 LLM 原始结果] 单字段恢复
- 支持 [全部还原] 一键恢复所有 LLM 原始结果
- 编辑历史不入库（仅保存最终版本）

## 5. 方向→行业映射机制

### 5.1 映射优先级

```
1. 精确匹配: 方向关键词 → 《产业-重点方向-Tushare映射》精确查找
2. 模糊匹配: 方向关键词 → 映射表模糊搜索 (编辑距离 ≤ 2)
3. LLM兜底: 无匹配 → LLM 语义推断映射 → 标记「LLM推断」
```

### 5.2 映射表结构 (`产业-重点方向-Tushare映射.md`)

```markdown
| 重点方向 | 映射行业 | Tushare概念代码 | 说明 |
|---|---|---|---|
| 半导体设备国产替代 | 半导体设备 | ths_半导体设备 | 光刻机/刻蚀机/薄膜沉积 |
| AI算力自主可控 | AI芯片+算力 | ths_AI芯片 | GPU/FPGA/ASIC |
| ... | ... | ... | ... |
```

### 5.3 映射结果展示

- 每行映射结果包含: 核心方向 → 映射行业 → Tushare概念 → 上市公司数量
- [🔬] 按钮跳转到产业链解构板块，携带当前映射行业
- 未映射的方向高亮显示（橙色边框），提示用户手动关联或使用 LLM 兜底
- [刷新] 按钮重新执行全部映射

### 5.4 LLM兜底

- 调用 `POST /api/v1/supply-chain/policy/industry-map`
- 输入: 未匹配的方向描述 + 候选行业列表
- 输出: 最佳匹配行业 + 置信度 (0-1)
- 置信度 < 0.6 的结果标记「低置信度」，建议人工确认

## 6. 模板保存与加载

### 6.1 模板保存

| 模板字段 | 说明 |
|---|---|
| 模板名称 | 用户自定义，如"大基金三期-2026Q1" |
| 政策来源 | 原始文本/URL/PDF摘要（前200字） |
| 核心方向 | 编辑后的方向列表 |
| 政策强度 | 1-5 星 |
| 资金支持 | 文本 |
| 时间窗口 | 文本 |
| 行业映射结果 | 方向→行业→概念映射表 |
| 创建时间 | 自动记录 |
| 标签 | 用户自定义标签，如"半导体""政策" |

### 6.2 模板加载

- 政策梳理页顶部显示「📋 已保存模板: N 个」
- 点击展开模板列表，按时间/标签筛选
- 选择模板 → 自动填充所有字段（标记来源「模板: xxx」）
- 同政策不重复解读: 输入文本与已保存模板源文本相似度 > 80% 时，自动提示「检测到相似政策，是否加载已有模板？」

### 6.3 模板API

| 端点 | 用途 |
|---|---|
| `POST /api/v1/supply-chain/policy/template/save` | 保存模板 |
| `GET /api/v1/supply-chain/policy/templates` | 模板列表（分页+筛选） |
| `GET /api/v1/supply-chain/policy/template/{id}` | 单个模板详情 |
| `DELETE /api/v1/supply-chain/policy/template/{id}` | 删除模板 |
| `POST /api/v1/supply-chain/policy/template/check-similar` | 相似度检测 |

## 7. 操盘手 vs 个人投资者差异

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| 默认输入方式 | 粘贴文章 (上次使用方式记忆) | 热门题材选择 |
| 四Tab顺序 | 粘贴文章 \| URL \| PDF \| 政策库 | 热门题材 \| 粘贴文章 \| URL \| 政策库 |
| LLM解读 | 完整深度解读，提取多条方向+细节 | 简化解读，1-2条核心方向 |
| 编辑权限 | 全部字段可编辑 | 仅政策强度可修正 |
| 行业映射 | 完整映射表 + LLM兜底 | 简化：只看映射结果 |
| 模板功能 | 完整 CRUD | 仅加载（不能保存/删除） |
| 操作按钮 | [保存模板] [进入产业链解构] | [加入自选] [查看股票列表] |

## 8. 数据来源

| 数据 | 表/服务 | 用途 |
|---|---|---|
| 政策文本 | `policy_law` + `cctv_news` + 用户输入 | LLM解读原文 |
| 行业映射 | `产业-重点方向-Tushare映射.md` + `ths_concept_map` | 方向→概念映射 |
| 上市公司 | `stocks` | 映射结果中的股票数量统计 |
| LLM | DeepSeek | 政策解读 + 方向提取 + 兜底映射 |

## 9. AC

| ID | AC |
|---|---|
| AC-1 | 支持四种输入方式(粘贴文章/URL/PDF/政策库)，切换Tab不丢失已输入内容 |
| AC-2 | LLM解读正确提取核心方向(≥2条)、政策强度、资金支持、时间窗口 |
| AC-3 | 解读结果的每个字段可独立编辑，修改后显示「已修正」标签，支持单字段还原和全部还原 |
| AC-4 | 核心方向自动映射到行业/Tushare概念/上市公司数量，未匹配方向触发LLM兜底并标记 |
| AC-5 | 解读结果可保存为模板，下次相同政策文本相似度>80%时自动提示加载已有模板 |
| AC-6 | 操盘手/个人投资者视角正确切换，包括Tab顺序、编辑权限、操作按钮差异 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 产业链拆解：公共产业链图谱与用户私有研究笔记分离，证据型标的进入候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共图谱/政策 + 私有研究标注。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接交易，只输出 Candidate 证据。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
