# PRD — 智能选股·选股工作台

- **Date**: 2026-06-26
- **Owner**: product-lead
- **Status**: Draft
- **Estimated effort tier**: Large（模型选择面板 + 结果表格 + 模型专属详情卡注册系统 + 批量操作）

## 1. 定位

选股工作台是智能选股的**核心操作区**，操盘手在此完成"选择模型 → 配置参数 → 运行选股 → 查看结果 → 操作标的"完整工作流。它替代了此前分散在多个菜单中的盘后选股入口，统一为单页面操作。

| 角色 | 场景 | 操作路径 |
|---|---|---|
| 量化分析师 | 盘后（15:30）例行跑模型 | 选模型 → 调参数 → 运行 → 看结果 → 加入候选池 |
| 交易员 | 次日盘前筛选昨日结果 | 打开工作台 → 查看昨日快照 → 操作标的 |
| 研究员 | 研究某个模型的因子表现 | 选模型 → 运行 → 看详情卡指标 → 记录分析 |

与开盘决策的关系：选股工作台产出结果 → [加入候选池] → 次日开盘决策·候选池 Tab 预加载。

### 交互规则

- 模型以**视觉卡片**展示，每张卡片包含模型名、风格标签、运行周期
- 每次只能**单选**一个模型（运行选股时以选中模型为准）
- 卡片悬停显示模型简介 Tooltip（因子体系、适用市场、历史胜率）
- 选中卡片有蓝色边框 + 浅蓝色背景高亮

## 3. 参数配置

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 日期 | DatePicker | 最近交易日 | 选择回测/筛选的基准日期 |
| Top N | Select (10/20/30/50) | 20 | 返回排名前 N 的结果 |
| 市值过滤 | RangeSlider | 全部 | 市值范围过滤（亿） |
| ST 过滤 | Switch | 排除 ST | 是否排除 ST/*ST |
| 行业过滤 | MultiSelect | 全部 | 按申万一级行业过滤 |

参数栏位于模型选择器下方，单行紧凑排列。

### 点击行 → 右侧展示模型专属详情卡

- 行选中高亮（浅蓝色背景）
- 右侧详情卡标题随选中模型动态切换
- 默认（刚跑完结果）展示第一行的详情

### 批量操作栏（表格下方）

- [全选] / [清除] 复选框控制
- [加入候选池 →] 主按钮
- [加入自选 ⭐] 次按钮
- [导出 CSV] 文本按钮

## 5. 操作

| 操作 | 行为 | 确认 |
|---|---|---|
| 加入候选池 | 选中股票写入 CandidatePoolManager，标记来源 `screener:${modelKey}` | Toast "已添加 3 只到候选池" |
| 加入自选 | 选中股票写入 watchlist 表 | Toast "已添加 3 只到自选" |
| 触发回测 | 打开回测配置 Modal（日期范围/初始资金/滑点），提交到 backtest-service | Modal → 跳转回测页面 |
| 导出 CSV | 下载当前结果表格的 CSV 文件（含通用列+选中模型的专属指标列） | 浏览器下载 |
| 查看诊断 | 跳转个股诊断页面（diagnosis-service） | 新 Tab / 同页跳转 |

### 右键菜单（单行右键）

```
加入候选池
───────
加入自选
───────
触发回测
查看诊断
复制代码
```

## 6. 模型专属详情卡

详情卡通过 `ModelDetailCardRegistry` 注册，根据当前选中的模型 `model_key` 动态渲染。每个模型的详情卡包含：

| 区域 | 说明 |
|---|---|
| 标题栏 | "毕师傅趋势启动分析" / "秋神盘后龙头分析" 等 |
| 指标矩阵 | 按 IndicatorGroup 分组，每项显示标签 + 进度条 + 数值 |
| 评价文本 | 模型专属的自然语言评价（含风险提示） |
| 操作按钮 | [加入候选池] [触发回测] [查看诊断] |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 智能选股：公共模型能力与用户私有筛选条件分离，结果可保存到个人候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模型评分 + 私有筛选参数。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接下单，只生成候选/方案。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
