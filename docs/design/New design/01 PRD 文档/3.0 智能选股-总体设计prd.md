# PRD — 智能选股·总体设计

- **Date**: 2026-06-26
- **Owner**: product-lead
- **Status**: Draft
- **Estimated effort tier**: Large（1 个主页面 + 3 个新建二级功能 + 模型专属详情卡系统）

## 1. Background

速赢AI 有 12 个选股/选债模型，覆盖竞价、盘中、盘后三个阶段。当前问题：

| 问题 | 表现 |
|---|---|
| 模型入口分散 | leader_auction/cb_auction 在竞价分析，bi_trend 智能选股，leader_intraday 盘中——用户需要在三个菜单间跳转 |
| 结果展示统一 | 所有模型结果用相同的列，bi_trend 的 OBV/WR 因子和 leader_scalp 的封单/Z-score 无法区分展示 |
| 无模型对比 | 跑完 bi_trend 再跑 short，不知道两只都选中的重叠股 |
| 无因子分析 | 选股结果出来了，但不知道哪个因子最近有效 |

## 6. 技术约束

- 前端: React 18 + TS 5.6 + Ant Design 5.22 + ECharts 5.5
- 路由: `/screener/workbench` `/screener/compare` `/screener/factors`
- 模型专属详情卡: 通过 `ModelDetailCardRegistry` 注册，根据 `model_key` 动态渲染
- API P95 ≤ 500ms (screening_snapshots 缓存)

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 智能选股：公共模型能力与用户私有筛选条件分离，结果可保存到个人候选池。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模型评分 + 私有筛选参数。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不直接下单，只生成候选/方案。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
