## 1. 页面定位

风险扫描是 SubTab `risk-scan` 对应的面板。以四张大卡片纵向排列，每张卡片对应一个风险检查维度：审计意见、公告风险、ST状态、业绩预告。底部展示综合风险评级徽章。

## 3. 核心数据类型

```typescript
interface RiskScanViewProps {
  tsCode: string
  stockName: string
  riskResult: RiskResult | null
  loading: boolean
}

interface RiskResult {
  tsCode: string
  stockName: string

  audit: AuditCheck
  announcement: AnnouncementCheck
  stStatus: STCheck
  performance: PerformanceCheck

  overallRisk: OverallRisk
}

// 单项检查
interface AuditCheck {
  passed: boolean
  opinion: string                  // "标准无保留意见" | "保留意见" | "无法表示意见" | "否定意见"
  auditor: string                  // "安永华明会计师事务所"
  reportPeriod: string             // "2025年报"
  reportDate: string               // "2026-03-15"
  summary: string                  // 审计意见摘要
  icon: '✅' | '⚠️' | '🔴'
}

interface AnnouncementCheck {
  passed: boolean
  hasRisk: boolean
  riskCount: number                // 0
  startDate: string                // "2026-05-26"
  endDate: string                  // "2026-06-26"
  riskTypes: string[]              // ["减持", "质押", "诉讼", "违规", "ST警示"]
  risks: AnnouncementRisk[]        // 风险公告列表
  icon: '✅' | '⚠️' | '🔴'
}

interface AnnouncementRisk {
  date: string
  type: string                     // "减持" | "质押" | "诉讼" | ...
  title: string
  summary: string
}

interface STCheck {
  passed: boolean
  isST: boolean
  statusText: string               // "正常上市" | "*ST" | "ST"
  recentSTHistory: boolean         // 近5年是否有ST记录
  delistRisk: 'none' | 'warning' | 'high'
  icon: '✅' | '⚠️' | '🔴'
}

interface PerformanceCheck {
  passed: boolean
  trend: 'pre_increase' | 'pre_decrease' | 'loss' | 'uncertain'
  latestPeriod: string             // "2026Q1"
  revenue: number                  // 258.4 (亿)
  revenueYoY: number               // +38.5 (%)
  netProfit: number                // 42.6 (亿)
  netProfitYoY: number             // +25.3 (%)
  faceChange: boolean              // 是否业绩变脸
  quarters: QuarterTrend[]         // 近4季趋势
  icon: '🟢' | '🟡' | '🔴'
}

interface QuarterTrend {
  period: string                   // "2026Q1"
  revenueYoY: number               // +38.5
  netProfitYoY: number             // +25.3
  icon: '🟢' | '🟡' | '🔴'
}

interface OverallRisk {
  level: 'low' | 'medium' | 'high'
  passedCount: number              // 4
  totalCount: number               // 4
  label: string                    // "四项检查全部通过"
  icon: '✅' | '⚠️' | '🔴'
  color: string                    // 'var(--down)' | 'var(--warn)' | 'var(--up)'
}
```

## 4. 风险评级计算

```typescript
function computeOverallRisk(checks: {
  audit: boolean
  announcement: boolean
  stStatus: boolean
  performance: boolean
}): OverallRisk {
  const passedCount = [checks.audit, checks.announcement, checks.stStatus, checks.performance]
    .filter(p => p).length

  if (passedCount === 4) {
    return {
      level: 'low',
      passedCount: 4, totalCount: 4,
      label: '四项检查全部通过',
      icon: '✅', color: 'var(--down)'
    }
  } else if (passedCount === 3) {
    return {
      level: 'medium',
      passedCount: 3, totalCount: 4,
      label: `${4 - passedCount} 项需关注`,
      icon: '⚠️', color: 'var(--warn)'
    }
  } else {
    return {
      level: 'high',
      passedCount, totalCount: 4,
      label: `${4 - passedCount} 项存在风险`,
      icon: '🔴', color: 'var(--up)'
    }
  }
}
```

## 5. 数据流

```
RiskScanView mount
│
├── 读取 props.tsCode (由父 DiagnosisPage 提供)
│
├── GET /api/v1/diagnosis/risk-scan/{tsCode}
│   │
│   ├── Response: RiskResult
│   │   ├── audit → AuditCheckCard 渲染
│   │   ├── announcement → AnnouncementCheckCard 渲染
│   │   ├── stStatus → STCheckCard 渲染
│   │   ├── performance → PerformanceCheckCard 渲染
│   │   └── overallRisk → OverallRiskBadge 渲染
│   │
│   └── Error: 显示错误提示
│
└── 切换股票时重新请求 (同 GET /risk-scan/{newCode})
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
