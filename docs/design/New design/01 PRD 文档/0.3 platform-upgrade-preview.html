操盘手工作台

围绕 P0 主链路组织信息，强调交易机会、方案承接、审单风控、实盘状态和复盘闭环。

  • 顶部固定账户/券商/风控状态
  • 候选池、方案、下单、复盘共享 DecisionContext
  • 实盘动作强确认与审计

个人投资者助理

弱化复杂模型和后台能力，突出自选解释、个股诊断、风险提醒和模拟交易。

  • 默认模拟盘
  • 隐藏训练、注册、全量数据表
  • 所有建议带解释和风险说明

系统管理员控制台

管理租户、用户、权限、数据、模型、券商通道和审计，面向平台运营而非投资决策。

  • 跨租户操作必须留痕
  • 模型发布、数据同步、券商网关集中治理
  • 服务健康和任务调度全量可见
