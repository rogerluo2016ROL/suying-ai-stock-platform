## 1. 页面定位

多股对比是 SubTab `compare` 对应的面板。支持 2-3 只股票叠加雷达图 + 核心指标对比表 + LLM 自动生成对比结论。

## 3. 核心数据类型

```typescript
interface CompareViewState {
  stocks: string[]                    // 2-3 ts_code

interface CompareResult {
  stock: { tsCode: string; stockName: string }
```

```typescript
          fontFamily: 'var(--font-mono)',

      }

  }
```

## 5. 对比表渲染

```typescript
function renderCompareTable(results: CompareResult[]): JSX.Element {
  const dimensions = ['技术面', '资金面', '基本面', 'AI预测', '情绪面']

  return (
    <table className="compare-table">
      <thead>
        <tr>
          <th></th>
          <th>综合</th>
          {dimensions.map(d => <th key={d}>{d}</th>)}
          <th>阻力</th>
          <th>支撑</th>
          <th>止损</th>
        </tr>
      </thead>
      <tbody>
        {results.map((r, i) => (
          <tr key={r.stock.tsCode}>
            <td>
              <span className="stock-dot" style={{ background: COLORS[i] }}></span>
              {r.stock.stockName}
            </td>
            <td className="mono">{r.diagnosis.overallScore}</td>
            {r.diagnosis.dimensions.map((dim, j) => (
              <td key={j} className="mono">{dim.score}</td>
            ))}
            <td className="mono">{r.diagnosis.keyLevels.resistance}</td>
            <td className="mono">{r.diagnosis.keyLevels.support}</td>
            <td className="mono">{r.diagnosis.keyLevels.stopLoss}</td>
          </tr>
        ))}

        {/* 差异行 */}
        {results.length === 2 && (
          <tr className="diff-row">
            <td>差异</td>
            <td className={`mono ${getDiffClass(results[0].diagnosis.overallScore, results[1].diagnosis.overallScore, 0)}`}>
              {results[0].diagnosis.overallScore - results[1].diagnosis.overallScore >= 0 ? '+' : ''}
              {results[0].diagnosis.overallScore - results[1].diagnosis.overallScore}
            </td>
            {dimensions.map((_, j) => {
              const diff = results[0].diagnosis.dimensions[j].score - results[1].diagnosis.dimensions[j].score
              return (
                <td key={j} className={`mono ${getDiffClass(results[0].diagnosis.dimensions[j].score, results[1].diagnosis.dimensions[j].score, j)}`}>
                  {diff >= 0 ? '+' : ''}{diff}
                </td>
              )
            })}
            <td className="mono muted">—</td>
            <td className="mono muted">—</td>
            <td className="mono muted">—</td>
          </tr>
        )}
      </tbody>
    </table>
  )
}

function getDiffClass(a: number, b: number, idx: number): string {
  return a > b ? 'better' : a < b ? 'worse' : 'equal'
}
```

## 6. 数据流

```
CompareView mount
│
├── 读取 props.compareStocks (由父 DiagnosisPage 提供)
│   └── 默认 2 只 (可从 URL 读取 ?compare=300750,600519)
│
├── GET /api/v1/diagnosis/compare?codes={codes.join(',')}
│   │
│   ├── Response: { diagnoses: DiagnosisResult[], conclusion: CompareConclusion }
│   │
│   ├── 渲染叠加雷达图 (buildCompareRadarOption)
│   ├── 渲染对比表 (每只一行 + 差异行)
│   └── 渲染对比结论 (CompareConclusion)
│
├── 添加股票 →
│   ├── POST /api/v1/diagnosis/compare (更新 codes 数组)
│   ├── 重新渲染雷达图 (2→3 条线)
│   ├── 重新渲染对比表 (2→3 行 + 差异行变为多维对比)
│   └── 重新生成对比结论
│
└── 删除股票 (从 chips 移除) → 同添加流程
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 个股诊断：公共诊断模型与个人备注、报告、关注状态分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共诊断 + 私有笔记/报告。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 诊断不构成直接下单指令。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
