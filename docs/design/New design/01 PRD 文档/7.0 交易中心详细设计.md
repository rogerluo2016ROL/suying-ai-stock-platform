## 1. 页面定位

交易中心是**手动交易操作台**，操盘手在此完成下单/撤单/改单、持仓管理、订单追踪、账户总览、券商连接管理。采用 **SubTabBar + 5 TabPanel** 架构，五个子面板（7.1–7.5）独立路由。

| 维度 | 交易中心 (menu 7) | 量化交易 (menu 8) | 方案管理 (menu 9) |
|---|---|---|---|
| **操作模式** | 逐笔手动下单 | 自动化策略执行 | 批量方案管理 |
| **核心流程** | 代码→价格→数量→风控→下单 | 策略→信号→自动触发 | 方案→启动→自动交易→结算 |
| **使用者** | 操盘手 + 个人投资者 | 操盘手为主 | 操盘手为主 |
| **联动** | 接收方案管理跳转带入参数 | — | 提供[手动下单]跳转入口 |

## 4. 数据流

### 4.1 placeOrder 6步流程

```
步骤1: 输入代码 → GET /trade/quote → 自动填充 StockInfoBar
步骤2: 选择方向 + 设价格/数量 → 实时计算预计金额 + 手续费
步骤3: [🔍预检] / 自动触发 → runRiskChecks(6项)
步骤4: 查看风控结果 → ✅通过直接下单 / ⚠️大额二次确认 / ❌拒绝
步骤5: [确认下单] → POST /trade/order → trade-service 二次校验
步骤6: 订单反馈 → toast + 刷新订单列表 + 30s轮询同步
```

### 4.2 方案管理跳转自动填充

```
方案管理 [📝手动下单]
  │ URL: /trade-center?tab=order&plan=xxx&code=300750&price=218.50&allocation=15
  ▼
TradeCenter 挂载:
  1. 读取 query params
  2. 自动切换到 "📝下单" tab
  3. GET /trade/quote?ts_code=300750.SZ
  4. 填入代码 300750 + 方向=买入 + 价格=218.50
  5. 根据 allocation=15% + account.totalAsset 计算建议手数
  6. 显示 PlanImportChip "🎯 方案: 龙头战法-开盘A"
  7. 用户确认 → [🔍预检] → [确认下单]
```

### 4.3 刷新策略

| 数据 | 刷新策略 | 端点 |
|---|---|---|
| 持仓 | 每30s轮询 (盘中) | `GET /trade/position` |
| 订单 | 每30s轮询 (盘中) | `GET /trade/orders?date=today` |
| 行情 | 输入代码按需 | `GET /trade/quote?ts_code=xxx` |
| 账户 | 页面挂载 + 每60s | `GET /trade/account` |
| 盈亏曲线 | 挂载一次 | `GET /trade/pnl-history?days=30` |

## 6. 角色差异

| 子面板 | 操盘手 | 个人投资者 |
|---|---|---|
| **下单面板** | 完整表单 + 6项风控详细 + 大额确认弹窗 | 简化表单 + 风控只显示✅/❌ + 金额打码 ¥*** |
| **持仓监控** | 全部持仓 + 止损/加仓/减仓 + 一键清仓 + 批量止损 | 仅"我的持仓" + 只读 |
| **订单管理** | 全部订单 + 改单/撤单/批量 | 仅今日订单 + 只读 (无改单) |
| **账户总览** | 完整金额 + 盈亏曲线 | 金额打码 + 盈亏曲线概览 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 交易中心：账户、订单、持仓、成交全部按 tenant/account/user 隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 强私有交易数据。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | paper/QMT/多券商统一 BrokerAdapter。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
