- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `11.0 回测分析prd.md`

## 1. 定位

回测运行是回测分析的**默认 Tab**。回答核心问题：**"这个策略在过去能不能赚钱？"** 从参数配置 → 运行回测 → 权益曲线 + 核心指标 + 月度热力图，形成完整的策略验证闭环。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 策略年化多少？回撤多大？夏普如何？和基准比呢？ | 这个策略靠谱吗？大概能赚多少？ |
| **可见内容** | 全部参数 + 8项指标 + 权益曲线 + 月度热力图 | 简化参数(仅策略+日期) + 4项核心指标 |
| **操作** | 完整参数配置 + 开始回测 | 选择策略 + 开始回测 |

## 3. 核心指标定义

| 指标 | 公式 | 颜色规则 |
|---|---|---|
| 年化收益 | ((1+totalReturn)^(1/年数)) - 1 | 正→up, 负→down |
| 最大回撤 | max(1 - nav/peak) | always down |
| 夏普比率 | (年化收益 - 无风险利率) / 年化波动率 | >1→accent, >0.5→fg, <0.5→warn |
| 胜率 | 盈利次数 / 总交易次数 | >50%→up, else→warn |
| 盈亏比 | 平均盈利 / 平均亏损 | >1.5→accent, else→fg |
| 日均换手 | 日均交易金额 / 日均权益 | fg |
| Calmar | 年化收益 / abs(最大回撤) | >2→accent, else→fg |
| 交易次数 | 回测期间交易笔数 | fg |

## 4. 交互

- 策略下拉：从 `/backtest/strategies` 加载可回测策略列表
- 基准下拉：[沪深300] [中证500] [无]
- TopN 滑块：5-50，默认20，控制选股数量
- 日期选择：默认最近1年，可选范围受数据限制
- 运行回测：POST `/backtest/run` → 轮询进度 (2s/次) → 完成更新图表
- 进度条：显示运行% + 预计剩余时间
- 权益曲线：支持 dataZoom 缩放、tooltip 悬停查看每日数据
- 月度热力图：鼠标悬停显示具体收益

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 回测分析：回测引擎公共，参数、结果、报告默认私有。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共因子/行情 + 私有回测结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 复盘写回 Plan，不直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
