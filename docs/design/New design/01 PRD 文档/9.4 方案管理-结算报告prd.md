# PRD — 方案管理·结算报告

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

结算报告是 **closed（已结算）** 方案的盈亏分析视图。操盘手可查看已完成方案的完整表现复盘，支持按时间维度筛选历史结算方案。个人投资者仅展示简化版「赚了 +X 元」。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **可见性** | ✅ 全功能 | ✅ 简化版（仅总盈亏金额） |
| **核心问题** | 这个方案赚了多少？每只票各自收益如何？按周/月统计表现？ | 赚了还是亏了？ |
| **决策** | 方案策略复盘 → 参数调优 → 模型迭代依据 | 了解收益 |

## 2. 核心功能

### 2.1 方案选择

- 顶部下拉选择器：选择已结算方案
- 显示方案名称 + 结算日期
- 默认选中最近结算的方案

### 2.2 结算概览（Summary 卡片）

| 指标 | 说明 |
|---|---|
| 总盈亏 | 浮动盈亏金额 + 百分比 |
| 收益率 | 结算周期内总收益率 |
| 胜率 | 盈利标的数 / 总标的数 |
| 最大回撤 | 持仓期间最大回撤幅度 |
| 持仓天数 | 启动 → 结算自然日 |
| 交易次数 | 总买卖订单数 |

### 2.3 各标的盈亏明细

- 表格：代码、名称、方向、买入均价、卖出均价、持仓数量、个股盈亏、收益率
- 按盈亏降序排列
- 正收益标绿色高亮、负收益标红色高亮

### 2.4 收益曲线

- ECharts 折线图：方案从启动到结算的每日累计收益率曲线
- 零轴水平参考线
- 标注：最大回撤区间（红色阴影区域）、最高点/最低点标记

### 2.5 时间筛选

- 快捷筛选：`[本周] [本月] [本季] [全部]`
- 筛选后仅展示所选时间范围内结算的方案
- 默认选中「全部」

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 方案管理：Plan 是私有交易意图承载对象，可授权共享但默认仅本人可见。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 私有 Plan + 公共模型引用。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | Plan 启动前必须绑定账户/模式。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
