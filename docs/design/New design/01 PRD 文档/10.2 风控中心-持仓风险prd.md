# PRD — 风控中心·持仓风险

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `10.0 风控中心prd.md`

## 1. 定位

持仓风险回答：**"哪些持仓最危险？需要立即行动吗？"** 按综合风险评分降序排列，用止损进度条可视化危险程度，提供直接的止损/减仓操作入口。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 哪些持仓要处理？先处理哪个？ | 我的持仓安全吗？ |
| **可见内容** | 全部持仓 + 调整止损 + 减仓 | 仅我的持仓 + 只读 |
| **操作** | 止损/减仓/一键平仓 | 仅查看（跳转交易中心） |

## 3. 止损进度条规则

- **进度条填充比例** = 当前浮亏 / 止损阈值 × 100%
- **颜色渐变**：绿色(距止损>5%) → 黄绿(>3%) → 橙色(>1%) → 红色(<1%)
- **止损线标记**：竖线标识止损价位位置
- **Hover Tooltip**：显示当前价/成本价/止损价/距止损

## 4. 风险标签类型

| 标签 | 颜色 | 触发条件 |
|---|---|---|
| 距止损 < 1% | 🔴 红 | 当前价距止损线不足 1% |
| 距止损 < 3% | 🟡 黄 | 当前价距止损线不足 3% |
| 审计风险 | 🟡 黄 | 审计意见为非标 |
| 公告风险 | 🔴 红 | 公告含立案调查等关键词 |
| ST/退市风险 | 🔴 红 | ST 或 *ST 标识 |
| 正常 | 📘 蓝 | 无风险信号 |

## 5. 风险评分算法

```
距止损<1% +50分 · 距止损<3% +30分 · 公告/立案 +40分 · 审计非标 +20分 · 仓位>25% +15分 · 浮亏+接近止损 +20分

> **评分口径统一**（2026-08-06）：各文档风险评分算法此前存在不一致，现统一以 `10.0 风控中心详细设计.md` §7「风险评分算法（统一口径）」为准。
```

## 6. 交互

- 行按风险分降序排列（最危险的在最上面）
- 危险行红色背景高亮，警告行橙色背景高亮
- 点击行跳转个股诊断页
- [止损] 按钮：弹窗确认后调整止损价位
- [减仓] 按钮：弹窗输入减仓数量
- [一键平仓风险标的]：弹窗确认后批量平仓所有红色标签持仓

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 风控中心：规则分全局/租户/账户，RiskVerdict 按账户和上下文归档。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共规则 + 私有判定结果。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 所有实盘动作强制经过。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
