# PRD — K线预测·单股预测

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

单股预测是 K线预测的**默认主视图**。展示 Kronos 30日预测路径 + 关键价位 + 信号标记 + 模型透明度信息。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **核心问题** | 预测和信号一致吗？当前价在什么位置？预测可信吗？ | 会涨还是跌？现在能买吗？ |
| **决策** | 确认入场时机 + 设价格预警 | 按建议操作 |

## 2. 核心功能

- ECharts K线图：60日历史蜡烛 + 30日预测虚线 + 置信区间带
- 关键价位：阻力位/支撑位/止损位 水平线
- 信号标记：★买入/▼卖出/⚡Kronos拐点 叠加标记
- 预测详情：目标价/涨幅/置信度/信号一致性
- 因子贡献度：技术45%/资金28%/基本面15%/情绪12% 进度条
- 模型信息：Kronos版本+训练日期（折叠）
- 历史准确率：近30次方向正确率（折叠）

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | K线预测：公共 Kronos 预测能力与用户私有关注/对比任务分离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共预测快照 + 私有预测任务。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 预测不可绕过风控直接交易。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
