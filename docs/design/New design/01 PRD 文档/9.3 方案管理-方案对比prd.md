# PRD — 方案管理·方案对比

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

方案对比是**操盘手专用**功能。操盘手可任选 2 个方案进行横向对比，从多维度审视方案表现差异，辅助调仓决策。个人投资者**不开放**此功能（Tab 隐藏）。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **可见性** | ✅ 全功能 | ❌ Tab 隐藏 |
| **核心问题** | 两个方案谁更优？标的有没有重叠？收益曲线走势一致吗？ | — |
| **决策** | 调仓 / 方案优先级排序 / 风险再平衡 | — |

## 2. 核心功能

### 2.1 方案选择器

- 上方双下拉框：`[方案 A ▾] VS [方案 B ▾]`
- 下拉列出全部非 draft 方案（running / paused / closed）
- 默认选中最近两个运行中方案
- 切换方案后对比面板实时刷新

### 2.2 对比维度（7 指标横向网格）

| 指标 | 方案 A | 方案 B | 差异 Δ |
|---|---|---|---|
| 总盈亏 | +12,580 | +8,200 | +4,380 |
| 收益率 | +3.2% | +1.8% | +1.4% |
| 胜率 | 80%(4/5) | 60%(3/5) | +20% |
| 最大回撤 | -2.1% | -4.5% | +2.4% |
| 持仓天数 | 5 天 | 3 天 | +2 天 |
| 标的数量 | 4 只 | 3 只 | +1 只 |
| 夏普比率 | 1.85 | 1.22 | +0.63 |

### 2.3 标的重叠分析

- 对比两个方案的持仓标的列表
- 如有重叠股票，高亮告警：「⚠️ 两只方案都选了 **宁德时代** · 仓位重合 15%」
- 重叠标的列表：代码 + 名称 + 方案 A 仓位 / 方案 B 仓位

### 2.4 收益曲线叠加

- ECharts 折线图，X 轴 = 交易日，Y 轴 = 累计收益率 %
- 两条曲线分别代表方案 A 和方案 B
- 图例区分颜色：方案 A（蓝色 #3d8bff）、方案 B（橙色 #f5a623）
- 鼠标悬停显示 crosshair + 当日数值
- 零轴水平参考线（灰色虚线）

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 方案管理：Plan 是私有交易意图承载对象，可授权共享但默认仅本人可见。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 私有 Plan + 公共模型引用。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | Plan 启动前必须绑定账户/模式。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
