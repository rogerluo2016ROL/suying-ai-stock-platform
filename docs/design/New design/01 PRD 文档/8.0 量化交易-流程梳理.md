## 五、各子模块关系总结

```
8.1 策略广场 ──→ 浏览/发现策略 ──→ [一键跟单] → 自动创建副本 → 8.2
                                     [查看配置] → 跳转 8.2
                                     
8.2 策略配置 ──→ 创建/编辑策略参数 + 标的来源选择 + 标的级覆盖
                 [部署上线] → 策略进入 8.3/8.4
                 [回测]     → 跳转 11.0
                 
8.3 策略监控 ──→ 下拉选择已部署策略 → 查看净值+持仓+当日交易
                 [调参] → 回到 8.2 (版本+1)
                 
8.4 策略日志 ──→ 同8.3的下拉选择器 → 查看该策略的执行日志
```
