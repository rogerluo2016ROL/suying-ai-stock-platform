# PRD — 方案管理-方案详情

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft

## 1. 定位

方案详情是方案管理(menu 9)的二级子模块——点击方案卡片进入（或右侧面板），提供**单方案的深度视图**。操盘手在此完成标的配置审核、订单执行跟踪、风险监控和生命周期操作。

| 维度 | 操盘手 | 个人投资者 |
|---|---|---|
| **进入方式** | 方案列表点击方案卡片 → 右侧详情面板 (60/40) | 同上 |
| **核心操作** | 审核标的配置 → 风控检查 → 启动/暂停/结算 | 查看建议 → [去交易中心下单] |
| **关注指标** | 订单状态+实时盈亏+风险逼近告警 | 买什么/买多少/什么价 |
| **订单跟踪** | 15s 轮询订单状态+实时盈亏 | 不轮询，手动刷新 |

## 2. 功能板块

```
📊 方案详情
├── 📋 方案头       方案名+状态徽章+创建时间+来源
├── 📊 标的配置表   代码/名称/方向/计划价/仓位%/止损/止盈/实时盈亏
├── 📝 订单列表     时间/代码/方向/价格/数量/状态 (running/paused 显示)
├── 📊 风险摘要     总仓位/总风险/单票集中度/止损逼近告警
└── 🎛️ 操作区       启动/暂停/结算/编辑/手动下单(状态决定按钮)
```

## 3. 功能详述

### 3.1 标的配置表

| 列 | 说明 | 格式 |
|---|---|---|
| 代码 | ts_code | mono, 12px, accent色 |
| 名称 | 股票简称 | 14px |
| 方向 | 买入/卖出 | 买入↑红色, 卖出↓绿色 |
| 计划价 | targetPrice | mono, 右对齐 |
| 仓位% | allocationPct | 进度条 + 数字, accent色 |
| 止损 | stopLoss / stopLossPct | green, 负向显示 |
| 止盈 | takeProfit / takeProfitPct | red, 正向显示 |
| **实时盈亏** | **NEW** 当前价 vs 计划价/成交价 | 红涨绿跌, running 时 15s 刷新 |

### 3.2 订单列表

- **仅 running / paused 方案显示**（draft 无订单，closed 展示历史订单）
- 列：时间 / 代码 / 名称 / 方向 / 价格 / 数量 / 状态
- 状态标签：已成交✅ / 待成交⏳ / 部成🔄 / 已撤单❌
- running 状态下每 15s 轮询刷新订单状态
- 支持按状态筛选（全部/待成交/已成交）

### 3.3 风险摘要

| 指标 | 说明 | 告警阈值 |
|---|---|---|
| 总仓位 % | 各标的仓位合计 | > 60% 橙色警告, > 80% 红色 |
| 总风险 % | 加权止损亏损 | > -8% 橙色警告 |
| 单票集中度 | 最大单股的仓位占比 | > 25% 橙色警告 |
| **止损逼近告警** | **NEW** 当前价逼近止损价 < 2% | 🔴 红色闪烁, 推送风控通知 |
| 预估最大回撤 | 极端行情下的回撤估算 | — |

风控检查结论：✅ 通过 / ⚠️ 预警（预警原因列表）。

### 3.4 操作区

按钮由方案状态决定：

| 状态 | 可用按钮 |
|---|---|
| draft | [🚀 启动自动交易] primary · [✏️ 编辑标的] · [📤 手动下单] · [🗑 删除] danger |
| running | [⏸️ 暂停] · [🏁 结算] settle · [✏️ 编辑标的] (disabled, 只读) |
| paused | [▶️ 恢复] primary · [🏁 结算] settle |
| closed | [📋 查看结算报告] · [📋 查看回测记录] (只读模式) |

## 4. 操盘手 vs 个人投资者差异

| 板块 | 操盘手 | 个人投资者 |
|---|---|---|
| 标的配置表 | 完整 8 列含实时盈亏 | 简化 5 列：代码/名称/方向/建议价/建议仓位%（无止损/止盈/实时盈亏） |
| 订单列表 | 完整含数量/状态轮询 | 不显示（引导去交易中心查看） |
| 风险摘要 | 完整 5 指标 + 止损逼近告警 | 简化："预估总仓位 37% · 建议控制风险" |
| 操作按钮 | 全部(状态决定) | 简化：[去交易中心下单] / [删除(draft)] |
| 金额显示 | 完整金额 | 打码 ¥***（服务端按 JWT 角色打码，前端不传身份头） |
| 实时盈亏 | 百分比 + 金额, 15s 刷新 | 不显示 |

## 5. 与其他模块的交互

| 交互 | 方向 | 数据 |
|---|---|---|
| 方案详情 ← strategy-service | 读取 | GET /strategy/{id} → Plan + orders |
| 方案详情 → auto_trading_executor | 操作 | [启动] → 创建执行器 |
| 方案详情 → trade-service | 操作 | [结算] → 平仓卖出订单 |
| 方案详情 ← trade-service | 读取 | 订单状态/成交价 → 计算实时盈亏 |
| 方案详情 ← 风控中心 | 推送 | 止损逼近告警 → UI 红色闪烁 |

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 方案管理：Plan 是私有交易意图承载对象，可授权共享但默认仅本人可见。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 私有 Plan + 公共模型引用。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | Plan 启动前必须绑定账户/模式。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
