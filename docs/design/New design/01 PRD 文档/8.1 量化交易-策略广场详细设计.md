## 1. 页面定位

策略广场是量化交易**第一个 SubTab**（SubTab key: `market`）。作为策略发现入口，以**清单式表格**展示所有可用策略，支持按来源筛选和按指标排序。点击行在右侧详情面板中查看完整信息，并提供[一键跟单][查看配置][回测结果]操作。

## 3. 核心数据结构

```typescript
type StrategySource = 'public' | 'private' | 'system'
type StrategyType = 'trend' | 'mean_reversion' | 'grid' | 'dragon'
type SortField = 'annualReturn' | 'sharpeRatio' | 'winRate'
type SortDir = 'asc' | 'desc'

interface StrategyListItem {
  id: string
  code: string                     // "SYS-LT-V1"
  name: string                     // "龙头战法-强势突破"
  type: StrategyType
  typeLabel: string                // "趋势跟踪"
  icon: string                     // "🔥"
  tags: string[]                   // ["热门", "积极"]
  annualReturn: number             // 0.325 = 32.5%
  maxDrawdown: number              // -0.123 = -12.3%
  sharpeRatio: number              // 2.15
  winRate: number                  // 0.68 = 68%
  source: StrategySource
  sourceLabel: string              // "🔓 公开"
  desc: string
  config: {
    stopLoss: number
    takeProfit: number
    maxPositions: number
  }
}

interface MarketState {
  strategies: StrategyListItem[]
  filter: StrategySource | 'all'
  sortBy: SortField
  sortDir: SortDir
  selectedId: string | null
  showFollowModal: boolean
  followStrategyId: string | null
  followAmount: number
}
```

### 3.1 筛选与排序逻辑

```typescript
function filterAndSort(
  strategies: StrategyListItem[],
  filter: StrategySource | 'all',
  sortBy: SortField,
  sortDir: SortDir
): StrategyListItem[] {
  let result = strategies
  if (filter !== 'all') {
    result = result.filter(s => s.source === filter)
  }
  return [...result].sort((a, b) => {
    const va = a[sortBy]
    const vb = b[sortBy]
    return sortDir === 'desc' ? vb - va : va - vb
  })
}
```

## 4. 数据流

```
StrategyMarket mount
  │
  ├── GET /strategy/market?source=all&sort=annualReturn&dir=desc
  │   └── 返回 StrategyListItem[]
  │
  ├── 监听 filter 变化 → 重新请求 (source={filter})
  ├── 监听 sortBy/sortDir 变化 → 重新请求 (sort={sortBy}&dir={sortDir})
  │
  ├── 点击行 → setSelectedId(id) → DetailPanel 展开
  │   └── 从 strategies 中 find(id) → 渲染详情
  │
  └── [一键跟单] 点击
      ├── 打开 QuickFollowModal
      ├── 用户输入投入金额
      ├── 确认 → POST /strategy/market/{id}/follow { amount }
      └── 显示 toast "🚀 策略已部署 · 可在策略配置中管理"
```

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 量化交易：策略模板可公共，策略实例、参数和运行日志必须私有隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共模板 + 私有策略实例。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 自动执行绑定账户并经过 RiskGate。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
