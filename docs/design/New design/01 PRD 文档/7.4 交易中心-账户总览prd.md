# PRD — 交易中心·账户总览

- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **Estimated effort tier**: Medium（KPI 卡片 + ECharts 盈亏曲线 + 周期统计）

## 1. Background

账户总览是交易中心的**资产仪表盘**。操盘手在此总览账户资产状况与盈亏走势，评估整体投资表现。

当前痛点：
1. 缺少盈亏历史曲线——无法直观看到账户增长趋势
2. 缺少多周期统计（今日/本周/本月/累计）——只能手动计算
3. 个人投资者金额打码展示缺失

## 2. Goal & Non-Goals

**目标**：
- 4 张 KPI 卡片：总资产/可用资金/持仓市值/当期盈亏
- **周期筛选**：今日/本周/本月/本季/本年/自定义，切换后 KPI 数字+曲线同步更新
- ECharts 盈亏曲线随周期缩放
- 周期收益率对比表

**Non-Goals**：
- 不做资产配置饼图
- 不做资金流水明细
- 不做多账户对比

## 3. User Stories

| ID | As a | I want to | So that |
|---|---|---|---|
| US-1 | 操盘手 | 看到 4 张 KPI 卡片（总资产/可用/市值/日盈亏） | 快速了解账户概览 |

## 6. Technical Constraints

- 数据来源：`GET /api/v1/trade/account`（KPI）+ `GET /api/v1/trade/pnl-history?days=30`（曲线）
- ECharts 5.5 CDN，暗色主题
- A 股涨跌色：红涨(up=#ff4d4f)绿跌(down=#2ec27e)
- 收益率正数显示 + 号

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 交易中心：账户、订单、持仓、成交全部按 tenant/account/user 隔离。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 强私有交易数据。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | paper/QMT/多券商统一 BrokerAdapter。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
