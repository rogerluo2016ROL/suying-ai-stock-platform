- **Date**: 2026-06-27 | **Owner**: product-lead | **Status**: Draft
- **父级 PRD**: `15.0 数据更新prd.md`

## 1. 定位

同步调度是数据更新的**第三个 Tab**（管理员专属）。管理自动同步的 Cron 配置、调度任务查看、数据源状态监控。

| 角色 | 视图 | 操作 |
|---|---|---|
| 管理员 | 调度列表 + 配置面板 + 数据源状态 + 下次运行倒计时 | 增/删/改/启停调度 |
| 操盘手 | — | 不可见此 Tab |
| 个人投资者 | — | 不可见此 Tab |

> **角色映射（收口决策）**：管理员 → RBAC `admin`；操盘手 trader → `internal_analyst`；个人投资者 investor → `user`；`external_analyst` → 外部只读。Tab 可见性与写操作权限由服务端按 JWT 角色执行，前端禁止传 `X-User-Role` 等身份头。
>
> **调度任务数量口径（收口决策）**：文中调度任务为示例，实际任务清单以调度配置（`GET /api/v1/data-update/schedules`）返回为准，页面动态渲染。

## 3. 调度管理交互

- **新建调度**: 点击 [+ 新建调度] → 面板：Cron 表达式 + 名称 + 分类 + 启用状态
- **编辑**: 行内编辑或弹窗编辑 Cron/名称/分类
- **启停**: Toggle 开关，即时生效
- **删除**: 确认弹窗后删除

## 4. 倒计时逻辑

- 轮询当前时间与每个调度的 `next_run_at` 差值
- 颜色：绿色 `> 1h` / 橙色 `≤ 1h` / 红色 `≤ 5min`
- 到达 `next_run_at` 后自动刷新调度状态

## 平台化优化补充

> 继承自 `0.3 平台化云端多租户总体需求设计.md`、`0.4 平台化云端多券商架构设计.md`、`0.5 平台化详细方案设计.md`。

| 维度 | 设计要求 |
|---|---|
| 模块定位 | 数据更新：公共数据平台能力，普通用户只看简化新鲜度。 |
| 角色差异 | 操盘手保留专业工作台；个人投资者默认简化解释视图；系统管理员获得配置、审计和运行治理视图。 |
| 数据隔离 | 公共数据质量。所有私有对象必须写入 `tenantId / ownerUserId / accountId? / visibility / dataScope`。 |
| 云端部署 | API 必须从认证上下文恢复租户与用户身份，禁止前端传入越权租户；列表接口默认只返回当前身份可见数据。 |
| 券商/交易 | 不触达券商。凡涉及资金、订单、策略启停的动作必须经过 `RiskGate` 并写入 append-only 审计。 |
| 原型要求 | 页面顶部展示角色视图、数据域、账户隔离、券商模式和云端就绪状态；不得把公共行情数据与私有交易数据混在同一区块而不标识。 |
