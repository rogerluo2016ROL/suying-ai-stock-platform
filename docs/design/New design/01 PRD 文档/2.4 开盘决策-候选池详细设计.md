## 1. 页面定位

候选池是开盘决策的**决策收口**。多源 picks（竞价选股 + 竞价选债 + 信号确认 + 智能选股 + 自选共振）汇集于此，经共识排序 + 风险排除后，输出最终可执行标的。

操盘手在此 Tab 完成：**交叉验证 → 排除风险 → 确认 3-5 只 → 生成交易方案**。

| 顺序 | 操作 | 对应面板 |
|---|---|---|
| 步骤1 | 查看多源融合概况 | FusionSummary（来源统计卡片） |
| 步骤2 | 按共识度筛选标的 | ConsensusTable（共识列表 + 筛选器） |
| 步骤3 | 检查风险排除结果 | RiskExclusionPanel（审计/公告/ST/止损） |
| 步骤4 | 勾选确认标的 (3-5只) | ConsensusTable 批量勾选 |
| 步骤5 | 生成交易方案 | GeneratePlanModal → POST /strategy/generate-from-picks |

## 4. CandidatePoolManager 融合算法（核心逻辑）

### 4.1 Manager 定义

```typescript
// contexts/CandidatePoolManager.ts

class CandidatePoolManager {
  private sources: Map<CandidateSource, Map<string, SourceStock>>
  private watchlistCodes: Set<string>
  private excludedCodes: Set<string>      // 强制排除的 code
  private manuallyRestored: Set<string>   // 手动恢复的 code
  private manuallyExcluded: Set<string>   // 手动额外排除的 code

  // ========== 数据写入 ==========

  /**
   * 各 Tab 调用此方法将 picks 注入候选池
   */
  addSource(source: CandidateSource, stocks: SourceStock[]): void {
    const map = new Map<string, SourceStock>()
    for (const s of stocks) {
      map.set(s.code, s)
    }
    this.sources.set(source, map)
  }

  /**
   * 设置自选股列表 (初始化时从 watchlist 表加载)
   */
  setWatchlist(codes: string[]): void {
    this.watchlistCodes = new Set(codes)
  }

  // ========== 融合计算 ==========

  /**
   * 核心融合算法
   * 1. 取并集 (所有来源的 code 去重)
   * 2. 计算共识度 = 出现在几个来源中
   * 3. 计算综合评分 = 各来源评分的加权平均
   * 4. 风险排除: 强制排除标记 + 手动排除
   * 5. 排序: 共识度降序 → 综合评分降序
   */
  compute(): { candidates: CandidateStock[]; stats: FusionStats } {
    // 1. 取并集
    const allCodes = new Set<string>()
    for (const [_, map] of this.sources) {
      for (const code of map.keys()) {
        allCodes.add(code)
      }
    }

    // 2. 计算每个 code 的融合属性
    const candidates: CandidateStock[] = []

    for (const code of allCodes) {
      const sourceList: CandidateSource[] = []
      let auctionScore: number | null = null
      let signalScore: number | null = null
      let screenerScore: number | null = null
      let name = code
      let kronosDirection: 'up' | 'down' | 'flat' | null = null
      let kronosChgPct: number | null = null
      let kronosConsistency: 'confirmed' | 'conflict' | 'neutral' | null = null

      for (const [source, map] of this.sources) {
        const stock = map.get(code)
        if (stock) {
          sourceList.push(source)
          name = stock.name || name

          switch (source) {
            case 'auction':
            case 'auction-cb':
              auctionScore = stock.score
              break
            case 'signal':
              signalScore = stock.score
              kronosDirection = stock.kronosDirection ?? null
              kronosChgPct = stock.kronosChgPct ?? null
              kronosConsistency = stock.consistency ?? null
              break
            case 'screener':
              screenerScore = stock.score
              break
          }
        }
      }

      // 3. 计算共识度
      const consensusLevel = this.calcConsensusLevel(sourceList)

      // 4. 计算综合评分 (加权平均, 缺某维时权重重新归一化)
      const compositeScore = this.calcCompositeScore(
        auctionScore, signalScore, screenerScore
      )

      // 5. 自选标记
      const isInWatchlist = this.watchlistCodes.has(code)

      candidates.push({
        code,
        name,
        industry: '',           // 由详情加载补充
        price: 0,               // 由详情加载补充
        changePct: 0,
        sources: sourceList,
        consensusLevel,
        auctionScore,
        signalScore,
        screenerScore,
        compositeScore,
        kronosDirection,
        kronosChgPct,
        kronosConsistency,
        riskFlags: [],          // 由风险检查步骤补充
        isExcluded: false,
        excludeReasons: [],
        isInWatchlist,
        createdAt: new Date().toISOString()
      })
    }

    // 6. 排序: 共识度降序 → 综合评分降序
    candidates.sort((a, b) => {
      if (b.consensusLevel !== a.consensusLevel) {
        return b.consensusLevel - a.consensusLevel
      }
      return b.compositeScore - a.compositeScore
    })

    // 7. 计算统计
    const stats = this.calcStats(candidates)

    return { candidates, stats }
  }

  // ========== 共识度计算 ==========

  private calcConsensusLevel(sources: CandidateSource[]): ConsensusLevel {
    // 自选共振不算独立来源 (watchlist 不单独计入 sources 数量)
    const effectiveCount = sources.filter(s => s !== 'watchlist').length

    if (effectiveCount >= 3) return 3   // ★★★
    if (effectiveCount >= 2) return 2   // ★★☆
    return 1                             // ★☆☆
  }

  // ========== 综合评分计算 ==========

  private calcCompositeScore(
    auctionScore: number | null,
    signalScore: number | null,
    screenerScore: number | null
  ): number {
    // 默认权重
    const weights = {
      auction: 0.30,
      signal: 0.40,
      screener: 0.30
    }

    let numerator = 0
    let denominator = 0

    if (auctionScore !== null) {
      numerator += auctionScore * weights.auction
      denominator += weights.auction
    }
    if (signalScore !== null) {
      numerator += signalScore * weights.signal
      denominator += weights.signal
    }
    if (screenerScore !== null) {
      numerator += screenerScore * weights.screener
      denominator += weights.screener
    }

    if (denominator === 0) return 0
    return Math.round(numerator / denominator)
  }

  // ========== 统计计算 ==========

  private calcStats(candidates: CandidateStock[]): FusionStats {
    let totalRaw = 0
    let auctionCount = 0
    let auctionCbCount = 0
    let signalCount = 0
    let screenerCount = 0
    let watchlistOverlap = 0
    let consensus3 = 0, consensus2 = 0, consensus1 = 0

    for (const [source, map] of this.sources) {
      const count = map.size
      totalRaw += count
      switch (source) {
        case 'auction': auctionCount += count; break
        case 'auction-cb': auctionCbCount += count; break
        case 'signal': signalCount += count; break
        case 'screener': screenerCount += count; break
      }
    }

    for (const c of candidates) {
      if (c.consensusLevel === 3) consensus3++
      else if (c.consensusLevel === 2) consensus2++
      else consensus1++
      if (c.isInWatchlist) watchlistOverlap++
    }

    return {
      totalRawInputs: totalRaw,
      totalUnique: candidates.length,
      auctionCount,
      auctionCbCount,
      signalCount,
      screenerCount,
      watchlistOverlapCount: watchlistOverlap,
      consensus3Count: consensus3,
      consensus2Count: consensus2,
      consensus1Count: consensus1,
      excludedCount: 0,          // 风险检查后补充
      availableCount: candidates.length,
      suggestionText: ''         // LLM 生成后补充
    }
  }

  // ========== 风险排除 ==========

  /**
   * 应用风险排除规则
   * 强制排除 (一票否决, 不可撤销):
   *   - 审计: 无法表示意见/否定意见
   *   - 公告: 退市/暂停上市/立案调查
   *   - ST: ST/*ST/退市整理期
   * 警告排除 (默认标记, 可手动恢复):
   *   - 审计: 保留意见
   *   - 止损: 距止损 < 3%
   */
  applyRiskExclusion(
    candidates: CandidateStock[],
    riskCheckResults: RiskCheckResults
  ): CandidateStock[] {
    const excluded = new Set<string>()

    // 处理所有 risk items
    const allItems = [
      ...riskCheckResults.audit.details,
      ...riskCheckResults.announcement.details,
      ...riskCheckResults.stDelist.details,
      ...riskCheckResults.stopLoss.details,
    ]

    for (const item of allItems) {
      const candidate = candidates.find(c => c.code === item.code)
      if (!candidate) continue

      const flag: RiskFlag = this.itemToFlag(item)
      candidate.riskFlags.push(flag)

      // 强制排除
      if (item.isForceExclude) {
        excluded.add(item.code)
        candidate.excludeReasons.push(`[强制] ${item.description}`)
      }
      // 警告排除 (默认排除，除非手动恢复)
      else if (item.severity === 'warning') {
        if (!this.manuallyRestored.has(item.code)) {
          excluded.add(item.code)
          candidate.excludeReasons.push(`[警告] ${item.description}`)
        }
      }
    }

    // 应用手动排除/恢复
    for (const code of this.manuallyExcluded) {
      excluded.add(code)
    }
    for (const code of this.manuallyRestored) {
      excluded.delete(code)
    }

    // 标记排除状态
    for (const c of candidates) {
      c.isExcluded = excluded.has(c.code)
    }

    return candidates
  }

  /**
   * 手动恢复标的 (操盘手判断风险可接受)
   */
  manuallyRestore(code: string): void {
    this.manuallyRestored.add(code)
    this.manuallyExcluded.delete(code)
  }

  /**
   * 手动排除标的 (操盘手额外判断)
   */
  manuallyExclude(code: string): void {
    this.manuallyExcluded.add(code)
    this.manuallyRestored.delete(code)
  }
}
```

## 6. 交互规范

### 6.1 共识星级显示

| Level | 显示 | 颜色 | 业务含义 |
|---|---|---|---|
| ★★★ (3) | 实心三星 | `color: var(--up)` | 竞价+信号+选股 三源共振, 最高可信度 |
| ★★☆ (2) | 实心两星 + 空心一星 | `color: var(--warn)` | 两源共振, 中等可信度 |
| ★☆☆ (1) | 实心一星 + 空心两星 | `color: var(--muted)` | 单一来源, 需进一步验证 |

### 6.2 筛选行为

| 筛选 | 表格变化 | 说明 |
|---|---|---|
| 全部 | 所有 candidate | 含已排除 (置灰, 不可勾选) |
| ★★★ 高共识 | consensusLevel === 3 | 三源共振 |
| ★★ 中共识 | consensusLevel === 2 | 双源共振 |
| 自选共振 | isInWatchlist === true | 自选 + 任意来源 |
| 仅可用 | isExcluded === false | 已排除的不显示 |

### 6.3 风险排除交互

| 场景 | 操作 | 结果 |
|---|---|---|
| 强制排除标的 | 行置灰 + opacity:0.5 + riskFlags 红 Tag | 不可勾选, 不可手动恢复 |
| 警告排除标的 | 行正常 + riskFlags 橙 Tag | 默认不勾选, 可手动恢复 |
| 手动恢复 | RiskExclusionPanel [手动恢复] | 该标的重启可勾选 + 风险 Tag 变灰色(已忽略) |
| 手动排除 | RiskExclusionPanel [手动排除] | 正常标的也可手动排除 |
| [一键排除所有风险标的] | 按钮 bulk 操作 | 所有有 riskFlags 的标记 isExcluded=true |

### 6.4 方案生成门控

```
[生成方案] 按钮 disabled 条件:
├── selectedCodes.length < 3  → disabled + Tooltip "请至少选择 3 只"
├── selectedCodes.length > 5  → disabled + Tooltip "最多选择 5 只"
├── !candidates.filter(c => selectedCodes.includes(c.code))
│        .every(c => !c.isExcluded)
│   → disabled + Tooltip "已选标的中包含被排除的标的, 请取消勾选"
└── all checks pass → 启用按钮
```

### 6.5 状态处理

| 状态 | 处理方式 |
|---|---|
| **加载中** | 表格骨架屏 + FusionSummary Spin |
| **空态 (无候选)** | Empty "候选池暂无标的，请先从竞价分析/信号扫描中添加" |
| **风险检查加载中** | RiskExclusionPanel Spin + Text "正在检查 N 只标的..." |
| **风险检查失败** | Alert "风险检查失败" + 重试按钮, 表格正常显示但无风险标记 |
| **方案生成中** | Modal 内 Spin + 禁用按钮 + "正在生成方案..." |
| **方案生成失败** | message.error + Modal 保持打开可重试 |

### 6.6 键盘与可访问性

- 共识表行：`role="row"`, `aria-selected={checked}`, Tab 导航, Space 勾选
- 风险排除面板：Collapse `aria-expanded="true"/"false"`
- 筛选 Radio：`role="radiogroup"`, 每个 `aria-checked`
- [生成方案] 按钮：`aria-disabled="true"` 当 disabled
