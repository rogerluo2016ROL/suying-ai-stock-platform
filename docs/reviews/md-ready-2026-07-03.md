### 认可的设计

- **backend dispatch 重构干净**：把 7 个分支里的 `loop.run_in_executor(...)` 收口为先选 `_runner` 再单点 `await asyncio.wait_for(loop.run_in_executor(...))`，所有原有 mode 路由（leader/afternoon/cb/bi_trend/supply_chain/multifactor）一字不漏保留，下游 `result["elapsed"]` / sanitize / auto_save / cache / contract 全不受影响。属于低风险高收益重构。
- **测试 trade_date 唯一性**：`test_run_returns_503_on_timeout_instead_of_gateway_502` 用 `trade_date=2099-12-31` 绕开 Redis 缓存短路（`run_screening` 6115-6124 cache_key 含 trade_date，命中即 return 不进 dispatch），注释也写明了为何这么干。这种"知其所以然"的测试设计值得保留。
