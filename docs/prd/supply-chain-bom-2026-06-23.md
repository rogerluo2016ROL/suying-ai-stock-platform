# PRD — 大葱产业链 BOM 解构选股模型 V4

- **Date**: 2026-06-23
- **Owner**: product-lead
- **Status**: Draft
- **Estimated effort tier**: Large

## 1. Background

现有 `supply_chain` 模型已经完成产业链配置外置、研报覆盖广度、IC 校准工具和样本外验证框架，但核心仍是“行业关键词 + 财务/研报五维评分”。这套方法能做产业主题粗筛，不能回答更关键的问题：国家正在鼓励哪条产业链、这条产业链的瓶颈环节在哪里、瓶颈环节对应哪些产品和材料、哪些上市公司已经进入商业化放量阶段。

本次重构采用“政策牵引、BOM 拆解、企业映射、量产验证、交易信号”五步法。政策侧吸收用户指定的习近平《前瞻布局和发展未来产业》核心观点：未来产业具有前瞻性、战略性、颠覆性，要加强统筹谋划，科学论证技术路线，把握发展节奏，防止盲目跟风；科技突破决定未来产业发展的速度、广度和深度，模型必须围绕关键核心技术攻关、科技成果转化和企业主体作用来选股。十五五、新质生产力、科技自立自强、现代化产业体系、战略性新兴产业和未来产业是本模型的一级政策锚点。

文章明确把量子科技、生物制造、氢能和核聚变能、脑机接口、具身智能、第六代移动通信列为“十五五”时期未来产业发展的主攻方向。V4 模型把这六个方向作为首批强政策权重主题，并把“产业出题、科技答题”“投早、投小、投长期、投硬科技”“首台（套）、首批次推广应用”等政策信号转成可计算因子。

用户已经采购 Tushare 全量可用数据。本期要优先使用 Tushare 与国内券商/指数体系提供的政策、主题、板块、财务、公告、研报、资金和交易数据，补充 LLM 自动阅读政策/公告能力，并预留专利、招投标、产能投产公告等外部数据入口。

## 2. Goal & Non-Goals

**目标**:
- 将 `supply_chain` 升级为“政策产业链 BOM 选股模型”，输出政策主题、BOM 路径、企业映射、产品/材料标签、商业化阶段、卡脖子证据、评级、排序、评分和交易研究信号。
- 新增前端“产业链拆解”能力，支持从政策主题逐级下钻到产业链、板块、BOM 节点、上市公司、产品/材料、财务指标和护城河证据。
- 建立 LLM 图谱更新链路，自动阅读政策、公告、研报、互动问答和新闻，抽取主题、产品、材料、客户、产能、订单、量产、国产替代和卡脖子证据，并允许人工配置修正。
- KPI：`supply_chain` API 返回的 Top N 企业 100% 带有 `policy_theme`、`bom_path`、`company_product_map`、`commercialization_stage`、`chokepoint_level`、`rating`、`rank`、`trade_signal`、`evidence` 字段；前端能完成“政策主题 → BOM 节点 → 企业 → 产品/材料 → 财务/证据”下钻。

**Non-Goals**:
- 本期不执行真实交易，不把信号自动送入下单流程。
- 本期不承诺 LLM 自动抽取 100% 正确，所有抽取结果必须保留来源、置信度和人工覆盖入口。
- 本期不引入图数据库；先用 PostgreSQL + JSONB + 物化视图承载图谱。
- 本期不把消费升级、周期资源作为主模型核心主题，只保留观察和扩展口径。

## 5. Design

### 5.1 Model Philosophy

V4 模型从“找好公司”改为“找国家战略产业链里已经接近商业化爆发的关键环节公司”。A 股牛市常常承接产业政策、科技突破和资金偏好。模型不把政策当作口号，而是把政策拆成产业主题，把产业主题拆成 BOM 节点，再把节点映射到产品、材料、设备、工艺和上市公司。

核心判断链：

1. 国家鼓励方向：十五五、新质生产力、科技自立自强、未来产业、现代化产业体系。
2. 产业链 BOM：上游材料/设备/核心零部件，中游制造/系统/平台，下游应用/客户/场景。
3. 卡脖子环节：国产替代、唯一供应、进口受限、技术壁垒、客户验证、标准认证。
4. 商业化阶段：概念验证、样品、小批量、量产、订单放量、利润兑现。
5. 启动信号：政策、周期、业绩、资金和价格趋势共振。

从《前瞻布局和发展未来产业》抽象出五条建模规则：

1. 统筹谋划规则：主题必须同时满足国家战略需求、技术成熟度和要素支撑，不追单一地方热点。
2. 科技创新规则：关键核心技术、原创性突破、成果转化和产业创新融合是加分项。
3. 企业主体规则：科技领军企业、央企主责主业、专精特新、单项冠军、独角兽是重点候选池。
4. 政策环境规则：科技金融、长期资本、首台（套）、首批次推广应用是商业化催化。
5. 治理风险规则：技术伦理、数据安全、监管不确定性和标准规则风险进入扣分项。

### 5.2 Initial Policy Themes

首批只做硬核科技和新质生产力主线。消费升级、周期资源从主模型降级为观察主题。

| 政策主题 | 初始产业链 |
|---|---|
| 未来产业主攻方向 | 量子科技、生物制造、氢能和核聚变能、脑机接口、具身智能、第六代移动通信 |
| 新质生产力 | AI 算力、机器人、低空经济、智能制造、工业软件 |
| 未来产业扩展方向 | 未来显示、未来能源、未来材料、未来空间、未来健康 |
| 科技自立自强 | 半导体设备/材料/EDA/IP、工业母机、高端仪器、基础软件 |
| 现代化产业体系 | 高端制造、新型能源体系、先进材料、航空航天、国防军工 |
| 硬核科技 | 高壁垒核心零部件、专用设备、核心材料、国产替代平台 |

### 5.6 Scoring

总分 100：

| 维度 | 权重 | 说明 |
|---|---:|---|
| 政策强度 | 15 | 是否命中未来产业六大主攻方向、政策源级别、近期政策频次、主题一致性 |
| BOM 关键性 | 15 | 是否处于核心材料、核心设备、核心工艺、关键零部件 |
| 卡脖子稀缺 | 20 | 国产替代、进口受限、唯一/少数供应、客户认证 |
| 成长 | 15 | 营收增长、利润增长、业绩预告/快报 |
| 盈利质量 | 10 | ROE、毛利率、净利率、现金流 |
| 商业化阶段 | 15 | 技术路线成熟度、样品、小批量、量产、订单、产能投放、主营占比 |
| 资金/市场确认 | 10 | 板块强度、主力资金、北向、龙虎榜、趋势启动 |

评级：

| 等级 | 分数 | 含义 |
|---|---:|---|
| S | >= 85 | 政策、BOM、商业化、资金多维共振 |
| A | 75-84 | 产业地位明确，商业化或资金信号较强 |
| B | 65-74 | 候选观察，需等待业绩或市场确认 |
| C | 50-64 | 概念相关但证据不足 |
| D | < 50 | 剔除或风险回避 |

交易研究信号：

| 信号 | 条件 |
|---|---|
| 观察 | B 级以上，但商业化或市场确认不足 |
| 关注 | A 级以上，且政策/BOM/财务至少两项强 |
| 启动 | A 级以上，且板块强度、资金流或趋势突破出现确认 |
| 强启动 | S 级，且政策、业绩、资金、价格共振 |
| 风险回避 | 业绩恶化、质押/减持/解禁/公告风险或证据置信度不足 |

### 5.7 LLM Extraction

LLM 只做结构化抽取和证据归档，不直接给最终投资结论。抽取任务读取 `npr`、`cctv_news`、`major_news`、`news`、`anns_d`、`research_report`、`irm_qa_sh/sz` 等文本源，输出：

- 政策主题
- 产业链名称
- BOM 节点
- 产品/材料/设备/工艺
- 上市公司
- 客户/供应商
- 产能/订单/量产状态
- 国产替代/卡脖子证据
- 证据原文片段、来源、日期、置信度

人工配置优先级高于 LLM 抽取。LLM 输出默认进入 `pending_review`，模型可使用高置信度结果，但前端必须显示来源和置信度。

### 5.8 Frontend

新增“产业链拆解”视图，或在智能选股页内新增专用 Tab。优先使用现有 `echarts-for-react`，不新增图形依赖。

页面结构：

1. 顶部：政策主题矩阵，显示主题热度、政策强度、板块强度、候选企业数。
2. 中部：BOM 图谱，支持树图或 Sankey，从政策主题钻到产业链、节点、企业。
3. 右侧：节点详情，显示企业列表、评级、分数、交易研究信号。
4. 下方：企业明细表，展示产品/材料、财务指标、护城河证据、商业化阶段、风险。
5. 抽屉详情：点击企业后展示证据时间线、公告/研报/互动问答原文摘要和财务趋势。

## 6. Technical Constraints

- 遵守项目规则：微服务间 HTTP 调用不引入 `httpx`/`aiohttp`。
- LLM 接入按 `agf-wiring-multi-llm-sdk` 执行，优先复用 DeepSeek 接入模式。
- 前端图谱优先用 ECharts，不引入 React Flow 等新依赖，除非 tech-lead 批准。
- Tushare 文本数据和 LLM 抽取结果必须保留来源、时间、接口名和置信度。
- `trade_date` 历史回测必须防未来数据泄露。
- 所有交易信号均为研究信号，不得自动下单。
- 专利、招投标、产能投产公告适配器必须可降级；缺数据时降低分项置信度，不中断选股。

## 7. Cost Estimate

- 预估 LLM token / 月：取决于公告和研报增量。按每日 500-2000 条文本、每条摘要和抽取 1-2K tokens 粗估，月度输入 1500万-1.2亿 tokens，需加队列、去重、摘要缓存和只处理增量。
- 预估 Agent Team 开发 token：Large。
- 成本档位：Large。
- 降本策略：先对政策/公告标题和摘要做轻量规则筛选，只把高相关文本送 LLM；抽取结果按 source hash 去重。

## 8. Out of Scope / Future Work

- 图数据库迁移。
- 自动交易联动。
- 对专利、招投标平台做全网爬虫。
- 对所有产业链一次性做到产品级完全覆盖。
