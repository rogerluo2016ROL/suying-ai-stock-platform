# OBV + WR 实战交易信号系统

> 数据来源：全 A 股 Top 300 市值股票，2021-06 ~ 2026-06（5年）
> WR 格式：**国内券商格式 (0-100)**，非 Tushare 国际格式 (-100~0)

---

## 一、指标定义

| 指标 | 公式 | 范围 | 说明 |
|------|------|------|------|
| **OBV** | 累加(价涨+量, 价跌-量) | 无界 | 能量潮，反映资金进出 |
| **OBV_MA10** | OBV 的 10 日均线 | — | 资金趋势线 |
| **WR(14)** | (14日最高-收盘)÷(14日最高-14日最低)×100 | **0~100** | 威廉指标 |
| **ATR(14)** | 14日平均真实波幅 | — | 波动率，用于动态止损 |

### WR 区间含义（国内券商格式）

| WR 值 | 区间 | 含义 |
|:--|------|------|
| **0~20** | 超买区 | 强势股，价格接近近期高点 — 🟢 持有/加仓 |
| **20~40** | 偏买区 | 回踩结束，趋势健康 — 🟢 买点确认 |
| **40~60** | 中性区 | 回踩中，洗盘阶段 — 🟡 黄金买点 |
| **60~80** | 偏卖区 | 深踩中，趋势偏弱 — 🟠 谨慎 |
| **80~100** | 超卖区 | 弱势股，价格接近近期低点 — 🔴 回避 |

| 信号 | 条件 | 5日后收益 | 结论 |

| **S1 高位破位** | OBV下穿MA10 + WR<20 | +0.82% | 涨速放缓 — 减仓 1/2 |

## 五、实战规则

### 买入规则

```
1. 候选池: B2_趋势确认 或 B4_强势突破 信号触发
2. 确认: 成交量 ≥ 10日均量 × 0.8（排除无量假突破）
3. 定价: 次日开盘价 ± 0.5% 限价单
4. 仓位: 首次 ≤ 总仓位 30%
5. 加仓: 持仓盈利 > 5% 后，再次出现 B1~B4 任一信号 → 加仓到 50%
```

### 持有规则

```
1. OBV > MA10 → 持有
2. WR 在 20~60 区间 → 正常持有
3. WR < 20 + OBV ≥ 15天 → 强势持有，不加仓也不减仓
4. 每日检查：OBV 是否仍在 MA10 上方
```

### 卖出规则

```
1. 止盈:
   - 盈利 10% → 卖出 1/3
   - 盈利 15% → 再卖 1/3
   - 盈利 20% → 清仓

2. 止损:
   - 收盘价 < 买入价 - ATR(14) × 2 → 立即清仓
   - 单日跌幅 > 7% → 立即清仓

3. 时间止损:
   - 持仓 > 20 个交易日 且 收益 < 3% → 清仓

4. 指标止损:
   - OBV 连续 3 日 < MA10 → 清仓
   - S2_弱势破位 (OBV下穿 + WR>80) → 清仓
```

### 成交量确认

| 状态 | 条件 | 含义 |
|------|------|------|
| **放量** | 3日均量 > 10日均量 × 1.3 | 主力活跃，信号可靠 |
| **正常** | 0.7 ~ 1.3 倍 | 常规行情 |
| **缩量** | < 0.7 倍 | 洗盘/冷清，需等待放量确认 |
