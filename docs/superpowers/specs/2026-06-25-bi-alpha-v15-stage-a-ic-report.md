# 毕师傅 V15 阶段A — 因子 IC 速测报告

> Date: 2026-06-25
> Stage: A（因子验证，门控）
> 口径: 硬科技池 / 2024-01~2025-12 月末截面 / 20日前向收益 / RankIC / 后复权
> 工具: `tools/factor_ic_probe.py`，复用 `backtest/supply_chain_ic.py` 的 IC 框架
> 产物: `outputs/factor_ic_probe.json`（首轮6因子）+ `outputs/factor_ic_probe_v2.json`（扩展10因子）

## 背景

bi_trend（OBV+WR+ADX 技术规则）样本外确定性亏（Sharpe -3.178）。V15 改换信号源前，
先用 IC 速测确认数据库里"已存在但未用"的横截面因子是否真有 alpha。**门控护栏**：
只有通过的因子才投入完整策略实现，避免重蹈"花整个策略成本实现无 alpha 策略"覆辙。

**门控判据**：|ICIR| ≥ 0.3 且 正IC月占比 ≥ 55%。

## 关键发现

1. **唯一稳健 alpha 因子：低换手反转**（ICIR 0.422，IC +0.082，24个月全覆盖）。
   逻辑成立——低换手=被市场冷落 → 后续补涨，A股冷门反转效应。
2. **低PB反转**是次优辅助（正IC月占比62%最高，但 ICIR 0.281 略低于门控）。
3. **数据受限的潜力因子**（无法采信）：
   - 北向持股变化：`hk_holdings` 2024-09 才有数据，仅5个截面，样本太小。
   - 营收增长：`financial_indicator.revenue_growth` 每季仅~220只非空（回填不全，疑似 memory
     记录的列名映射缺陷残留），15个月且硬科技子集更少。
4. **明确无效/反向**：
   - 资金流类（主力净流入 IC≈0、融资余额反向）→ 资金流是滞后指标，alpha 已消化。
   - 股东增持**反向**（-0.379）→ 硬科技增持后反跌（增持护盘=基本面转弱信号？）。
   - ROE 无效 → 硬科技成长股市场不看当期盈利能力。

## 结论与建议

- **硬科技池内可用的横截面 alpha 很薄**：1 个稳健因子（低换手）+ 1 个边缘因子（低PB）。
- 单因子 IC 0.082 属"中等偏弱"，扣 14bp 成本后能否样本外转正存在真实不确定性，
  但方向远好于 OBV+WR 的负 ICIR。
- **数据短板已定位**：北向（2024-09起）和营收增长（回填不全）受数据源限制，
  本轮不可用；若后续补全数据，营收增长（IC 0.099 最高）值得重测。

## 下一步选项

1. **低换手 + 低PB 双因子**做成 bi_alpha_v15，进阶段C样本外验证（最快出结论）。
2. **先修复 revenue_growth 回填**，再把营收增长纳入（数据工程，但 IC 最高值得）。
3. 扩到全市场池重测（硬科技池太小可能限制了因子表现）。

## 补充：营收增长数据修复后复测（2026-06-25）

按选项2修复了 `revenue_growth` 回填：根因是 `backfill_financial.py` 之前只回填 chain
（产业链池，~1900股），硬科技池子集稀疏（每季~220非空）。给脚本加 `--codes hardtech`
选项，跑 2023Q1-2025Q4 回填（460股×12季度，写入5433行），硬科技池营收增长非空率从
~25% → **~97%**（每季~450只）。

**修复后复测结果**（`outputs/factor_ic_probe_v3.json`）：

| 因子 | 修复前 | 修复后 |
|---|---|---|
| 营收增长 | IC +0.099 / ICIR 0.328 / 15月 | **IC +0.040 / ICIR 0.271 / 正月58% / 24月** |
| ROE | -0.012 / 24月 | +0.006 / 24月（仍无效） |

**关键教训**：修复前的 IC +0.099 是**幸存者偏差**——只有~220只有数据的票（多为大盘绩优股）
IC 偏高；补全到全硬科技池后 IC 回落到 +0.040。这印证了"先验证数据质量再下结论"的价值，
避免基于偏差样本误判因子有效性。

**阶段A最终结论（数据已修复）**：
- **稳健通过门控**：低换手反转（ICIR 0.422）—— 唯一
- **边缘候选**（单独不达标，组合可能互补）：低PB反转（0.281/62%）、营收增长（0.271/58%）
- 硬科技池横截面 alpha 确实薄，但"低换手 + 低PB + 营收增长"三因子组合值得进阶段B/C验证。
