📈 第一层：价格走势 (K线 + MA5/MA10)

🟠 第二层：同花顺 WR (0 ~ 100) — 你看到的

WR_同花顺 = (HH - C) / (HH - LL) × 100

● WR < 20 = 价格在高位，超买 → 卖出
● WR > 80 = 价格在低位，超卖 → 买入
● WR 线 ↓ 下跌 = 价格 ↑ 上涨（WR线走势与价格同向）
📌 你图中的"WR 急跌" = 线条从 90+ 快速掉到 30- = 价格冲高

🔴 第三层：国际标准 WR (-100 ~ 0) — 毕师傅代码里用的

WR_国际 = (HH - C) / (HH - LL) × (-100)

● WR > -20 = 价格在高位，超买 → 卖出
● WR < -80 = 价格在低位，超卖 → 买入
● WR 线 ↓ 下跌 = 价格 ↓ 下跌（WR线走势与价格反向）
📌 代码里的"WR 急跌" = 从 -30 快速掉到 -80 = 价格回踩（洗盘）
