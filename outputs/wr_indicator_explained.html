🧠 WR 指标核心理解

WR 全称 Williams %R（威廉指标），由 Larry Williams 发明。它衡量的是：当前收盘价在近 N 日价格区间中的相对位置。


WR = (N日最高价 - 当日收盘价) / (N日最高价 - N日最低价) × -100


📌 关键解读：

• WR = -10 → 收盘价接近 N 日最高价（涨了很多，超买）

• WR = -50 → 收盘价在 N 日区间中间（中性）

• WR = -90 → 收盘价接近 N 日最低价（跌了很多，超卖）


📌 注意！WR 是负值指标，越小（越接近 -100）越超卖，越大（越接近 0）越超买。这与 RSI 不同。


📌 毕师傅战法中的关键用法：不是看 WR 绝对值，而是看 WR 的"急跌"——

• WR 急跌（2-3 天内从 -30 跌到 -80）→ 价格快速回踩 → 洗盘特征 → 买点

• WR 急涨（2-3 天内从 -80 涨到 -30）→ 价格快速拉升 → 追高风险 → 卖点

🛠️ WR 实战口诀

场景 WR 表现 操作
📈 上升趋势中 WR 从 -100 附近快速回升 🟢 趋势确认，继续持有
📉 上升趋势中突然 WR 急跌 2-3 天内从 -30 → -80 🟢 洗盘回踩！最佳买点
📊 下跌趋势中 WR 钝化 持续在 -80 以下不反弹 🔴 弱势！不能抄底
🚀 快速拉升中 WR 从 -100 飙升到 -20 以上 🔴 追高风险，考虑止盈
🔄 高位横盘 WR 在 -20~0 之间反复 🔴 涨势衰竭，警惕回调

💡 最重要的原则：WR 不能单独用，必须配合 OBV（资金流向）和量价关系。WR 告诉你"跌够了没"，OBV 告诉你"资金还在不在"。
